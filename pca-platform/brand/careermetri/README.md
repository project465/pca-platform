# 커리어메트리 로고

| 파일 | 쓰는 자리 |
|---|---|
| `logo.svg` · `logo-navy.png` | 밝은 바탕. 아임웹 머리글이 여기다 |
| `logo-dark.svg` · `logo-light.png` | 어두운 바탕. 네이비 띠 위, 결과지 표지 |
| `mark.svg` · `mark-512.png` · `favicon-32.png` | 작게 쓰는 자리. 파비콘, 프로필 사진 |

PNG 는 배경이 비어 있습니다. 어느 색 위에 얹어도 흰 네모가 생기지 않습니다.

## 어떻게 만들었나

글자는 폰트가 아니라 **획**입니다. 폰트가 깔리지 않은 자리에서도 같은 모양으로
서고, 학교 공문과 인쇄물에 그대로 얹힙니다.

커리어메트리 플러스와 **같은 획을 씁니다.** 같은 집안임을 글자가 말합니다.
갈리는 곳은 마감과 색입니다.

| | 커리어메트리 | 커리어메트리 플러스 |
|---|---|---|
| 획 마감 | 각지게 자름 | 둥글림 |
| 강조색 | 금색 `#C9A227` | 앰버 `#E07B39` |
| 부호 | 금색 막대 | 호와 플러스 블록 |
| 읽는 사람 | 대학 담당자 | 중·고등학생 |

**금색 막대는 장식이 아닙니다.** 홈페이지의 모든 절 제목 아래에 같은 막대가
있습니다. 로고와 화면이 같은 부호를 씁니다.

## 그리면서 고친 것 넷

- 획 끝을 `square` 로 두니 10 씩 늘어나 **A 의 가로획이 다리 밖으로 삐져
  나왔습니다.** `butt` 으로 잘랐습니다
- R 의 다리가 그릇 끝(60)에서 출발해 **이음새에 흰 쐐기가 남았습니다.**
  잉크 안쪽(196,60)에서 출발시켰습니다
- A 와 M 의 꼭짓점은 각이 좁아 마이터가 글자높이의 3분의 1 만큼 위로 솟아
  **뷰박스 밖으로 잘렸습니다.** `stroke-miterlimit: 2` 로 그 둘만 평평하게
  자르고, E·T·I 의 직각(비 1.41)은 날카롭게 남겼습니다
- T 는 아래가 비어 있어 같은 간격이어도 벌어져 보입니다. 그대로 두면
  **CAREERME 와 TRI 로 끊겨 읽혀서** T 부터 오른쪽을 6~16 씩 당겼습니다

## 바꿀 때

색은 CSS 변수로 덮습니다.

```css
svg { --logo-ink: #0F1B2D; --logo-gold: #C9A227; }
```

획 굵기는 20 입니다(글자높이 92 의 22%). **더 굵히지 마십시오** — A·R·E 의
속공간이 막혀 열한 글자가 덩어리로 읽힙니다.
