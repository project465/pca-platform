## 2. 오늘 켜려면 반드시 있어야 하는 것 — 아직 없다

### 2-1. 결제를 받으려면

| 막는 것 | 누가 | 걸리는 시간 |
|---|---|---|
| **PG 가맹점 심사** | PortOne + 카드사 | 영업일 3~10일. 오늘 안 됨 |
| **통신판매업 신고** | 관할 구청 | 3~5일. 사업자등록증·구매안전서비스 확인증 필요 |
| **해외카드 채널 계약** | PortOne | 국내 채널과 별도 심사 |

심사가 끝나면 코드에서 할 일은 `.env` 다섯 줄뿐이다.

```
PAYMENTS_PROVIDER=portone
PORTONE_STORE_ID=...
PORTONE_CHANNEL_KEY=...            # 국내
PORTONE_CHANNEL_KEY_GLOBAL=...     # 해외 Visa·Mastercard
PORTONE_API_SECRET=...
PORTONE_WEBHOOK_SECRET=...
```

> **`PAYMENTS_PROVIDER=mock` 인 채로 운영에 올리면 서버가 뜨지 않는다.**
> 돈을 안 받고 좌석이 나가는 사고는 코드가 거절한다.

### 2-2. 사업자 정보 — 지어낼 수 없어서 비워 뒀다

전자상거래법 제10조가 "소비자가 알아보기 쉽게" 표시하라고 정한 것들이다.
`marketing/src/content/kr.ts` 의 `legal` 절을 채우면 푸터에 바로 나온다.
**비어 있으면 푸터에 금색 "확인 필요" 로 찍힌다** — 빈칸으로 두면 그대로
런칭되기 때문에 일부러 눈에 띄게 했다.

- 상호 · 대표자 성명
- 영업소 주소 · 전화 · 이메일
- 사업자등록번호
- 통신판매업 신고번호
- 개인정보 보호책임자

직업정보제공사업 신고번호(J1700020220007)만 이미 들어 있다.

### 2-3. 문서 검토

`/terms` · `/privacy` · `/refund` 세 화면을 만들어 뒀다. 내용은 **코드가
실제로 하는 일에 맞춰** 썼다 — 보유기간, 파기 절차, 환불선(응시 시작 전/후),
5명 미만 칸 차단까지 전부 구현과 일치한다.

**그래도 법률 자문이 아니다.** 게시 전에 변호사 또는 개인정보 전문가의
검토를 받아야 한다. 각 화면 위에 그 경고가 박혀 있다.

## 3. 운영 환경

| 항목 | 상태 | 비고 |
|---|---|---|
| PostgreSQL | 미정 | 관리형(RDS·Supabase·Neon) 권장. 백업·시점복구 켤 것 |
| 배포 | 미정 | Next.js 두 앱 — 플랫폼 `src/`, 소개 `marketing/` |
| 도메인 | 미정 | `metri.co.kr`(소개) · `app.metri.io`(플랫폼)로 원고에 적혀 있음 |
| HTTPS | 필수 | 쿠키가 세션이므로 없으면 안 된다 |
| `AUTH_SECRET` | 필수 | `openssl rand -base64 32`. 개발용 값을 그대로 쓰지 말 것 |
| 웹훅 주소 | 필수 | PortOne 콘솔에 `https://.../api/payments/webhook` 등록 |

## 4. 켠 다음에 바로 해야 하는 것

1. **첫 결제를 실제 카드로 한 번 해 본다.** 테스트 모드와 운영은 다른 길이다.
2. **웹훅이 들어오는지 본다.** `payment_events` 에 행이 쌓이는지.
3. **결과지를 한 장 인쇄해 본다.** A4 로 뽑아 잘리는 곳이 없는지.
4. **첫 100명 검증을 건다.** 채점 산식의 계수와 레벨 사다리는 아직 추정치다
   (`docs/metri/04_matching.md`). 100명이 쌓이면 그 값을 실측으로 바꾼다.

## 5. 아직 안 만든 것 (런칭을 막지는 않는다)

- 운영사 관리자 화면 일부 (기관 목록·전체 응시 현황)
- 학과 단체 리포트 PDF 내보내기
- 전공 확장 — 지금 문항은 **기계공학과 한 벌**이다. 전기전자·컴퓨터는
  Skill Tree 만 있고 문항이 없다
- 고교판 검사지(`HS_V1`)
- 보유기간 만료분 자동 파기 (지금은 본인 탈퇴만. 5년 지난 주문 정리는 수동)

## 결론

**오늘 켤 수 있는 것** — 소개 사이트 네 나라 판, 그리고 학과 계약 기반
플랫폼(결제 없이 좌석을 계약으로 발급하는 경로)은 오늘 올려도 된다.

**오늘 켤 수 없는 것** — 개인 결제(B2C). PG 심사와 통신판매업 신고가
끝나야 한다. 코드는 기다리고 있고, 바꿀 것은 `.env` 다섯 줄이다.
