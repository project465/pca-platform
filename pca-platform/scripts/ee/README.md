# 전기전자 Core 초안 (배선 전)

`taxonomy.py` 는 **아직 어느 코드도 읽지 않는 초안**이다. 등록부
(`content/major-cores.json`)에 줄이 없고, `v3:*` 어느 검사도 이 폴더를
보지 않는다. 돌려도 제품이 바뀌지 않는다.

**왜 남겨 두는가.** 전기전자는 기계공학 파일을 베껴서 만들 수 없다.
영역이 아홉이고 ME 의 열둘과 맞추지 않는 것이 이 초안의 요지다(판단축
여덟과 소유 넷은 공통 엔진이라 그대로다). 지우면 그 판단을 다시 한다.

**지금은 멈춰 있다.** 기계공학을 다른 전공의 기준 UX 로 마감하는 것이
먼저라, 이 Core 의 제작은 시작하지 않았다. 다시 열 때는 이 파일을 돌리는
것이 아니라 `docs/metri/major-authoring/` 의 01~04 를 따라
`content/ee-*.json` 네 벌로 옮기고 등록부에 줄을 더한다. **파일을 더하는
일이지 엔진을 고치는 일이 아니다**(`npm run v3:extend` 가 그것을 센다).
