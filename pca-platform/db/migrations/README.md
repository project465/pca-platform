# 마이그레이션

`db/schema.sql` 은 **빈 데이터베이스에 한 번** 넣는 것이다. 처음 배포할 때
그것을 쓰고, 그 뒤로는 여기에 번호를 붙인 파일을 하나씩 더한다.

```
db/migrations/001_...sql
db/migrations/002_...sql
```

## 규칙

1. **한 번 배포한 마이그레이션은 고치지 않는다.** 이미 돈 데이터베이스가
   있으므로, 고쳐도 그쪽에는 반영되지 않는다. 새 파일을 더한다
2. **schema.sql 도 함께 고친다.** 새 데이터베이스는 schema.sql 하나로
   지금 상태가 되어야 한다. 두 파일이 갈리면 검사 환경과 운영이 달라진다
3. 표를 지우거나 컬럼 이름을 바꾸는 것은 두 단계로 나눈다 — 먼저 새 것을
   더해 양쪽을 쓰게 하고, 다 옮긴 다음 판을 올려 지운다
4. 돌리기 전에 백업한다. `pg_dump` 한 줄이면 된다

## 지금 상태

아직 배포한 적이 없으므로 마이그레이션 파일이 없다. `schema.sql` 이 곧
현재 상태다. **첫 배포가 끝나는 순간부터** 이 규칙이 적용된다.
