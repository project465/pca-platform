# 수익모델 — 대학 · 학생 · 기업

한국 기준이다. 숫자는 **제안**이고, 근거를 같이 적었다.

---

## 0. 먼저 답해야 하는 질문

> **고용24 잡케어가 무료인데 왜 돈을 내나?**

이 질문에 답 못 하면 나머지 가격표는 의미가 없다.

| | 고용24 잡케어 | ECI |
|---|---|---|
| 대상 | 전 국민 | **공학 전공 특화** |
| 산출 | 개인에게 직업 추천 | 개인 + **학과 단위 집계** |
| 근거 | 직업사전 기반 | **실제 채용공고 통계** ("공고 132건 중 89건이 요구") |
| 처방 | 훈련과정 안내 | **그 대학의 개설 과목·비교과** |
| 사는 사람 | 없음 (무료) | **학과** |

**핵심은 "무료 검사와 경쟁하지 않는다" 는 것이다.**
개인 학생에게 3만 원짜리 검사를 팔아 무료 검사를 이기려는 게 아니다.
**학과가 자기 학생 500명의 상태를 알기 위해 돈을 낸다.** 그 시장에는 무료 대체재가 없다.

## 1. 대학 (B2B) — 주력

### 가격

| 상품 | 인원 | 1인 단가 | 연 계약가 | 용도 |
|---|---|---|---|---|
| 파일럿 | 100 | 48,000 | **480만** | 첫 학기, 검증용 |
| **학과 연간** | 500 | 28,000 | **1,400만** | 주력 상품 |
| 공대 패키지 | 3,000 | 22,000 | **6,600만** | 2년차부터 |
| 고교 (학년 단위) | 300 | 15,000 | 450만 | 3차 |

**파일럿 단가가 더 비싸다.** 할인은 규모에서 나오지 시작이라서 나오지 않는다.
파일럿을 싸게 주면 본계약에서 그 가격이 기준이 된다.

### 돈이 어디서 나오나 — 이게 영업의 전부다

학과 자체 예산으로 1,400만 원은 큰돈이다. **자체 예산으로 팔면 실패한다.**

| 예산 출처 | 규모 | 명분 |
|---|---|---|
| **RISE / 앵커 사업비** | 2026년 2조 1,403억, 이 중 **약 4,000억이 성과 인센티브** | 평가 항목에 "학생·인재에 대한 충분한 고려". 성과지표에 지역정주 취업률 |
| 대학혁신지원사업비 | 대학당 수십억 | 교육과정 개선 근거 데이터 |
| 학과 특성화 사업비 | 학과당 수천만 | 교육과정 개편 |
| 대학일자리플러스센터 | 고용노동부 | 재학생 진로지도 |

**제안서의 첫 장에 "이 지출은 어느 예산 항목에서 나갑니다" 를 쓴다.**
담당자가 가장 먼저 막히는 곳이 그것이고, 대신 풀어주면 계약이 빨라진다.

### 영업 캘린더

한국 대학 예산은 시기가 정해져 있다. **이걸 놓치면 1년을 기다린다.**

```
9~10월   차년도 예산 편성 시작   ← 여기서 항목에 들어가야 한다
11~12월  예산 확정
1~2월    집행 계획 수립          ← 파일럿 계약이 여기서 난다
3월      1학기 집행              ← 응시
7~8월    2학기 준비
9월      2학기 집행 / 다음 해 편성 ← 재계약과 신규가 겹치는 성수기
```

**지금 해야 할 일은 9~10월 편성 시즌에 담당자 책상에 제안서를 올리는 것이다.**

### 단위경제 (학과 1개 · 500명)

| 항목 | 금액 |
|---|---|
| 매출 | 14,000,000 |
| 변동비 (리포트 생성·검사 인프라·CS, 1인 약 1,000원) | −500,000 |
| **매출총이익** | **13,500,000 (96%)** |
| 계약 획득 비용 (방문 3회·제안·인건비 배분) | −3,000,000 |
| **공헌이익** | **10,500,000 (75%)** |

**변동비가 거의 없다.** 원가는 전부 초기 구축(Skill Tree·문항·JD 파이프라인)에 있고,
그건 학과가 늘어도 안 늘어난다. **두 번째 학과부터가 진짜 이익이다.**

## 2. 학생 (B2C) — 학과 계약 위에 얹는 층

**광고로 학생을 사지 않는다.** 획득 비용이 매출을 먹는다.
이공계 취업 키워드는 클릭 단가가 높다. 대신 학과 계약이 채널이 된다.

| 상품 | 가격 | 무엇 |
|---|---|---|
| 무료 간이 진단 | 0 | 12문항 · 1위 직무만 |
| **전체 리포트** | **29,000** | 단건. 상위 8직무 · Skill Gap · 공고 매칭 |
| 커리어 팩 | 월 9,900 / 6개월 49,000 | 공고 알림 · 이력서 첨삭 · 면접 질문 |
| 1:1 컨설팅 | 15만~30만 | **기존 사업으로 넘긴다.** 플랫폼은 리드만 |

### 전환 구조

```
학과 계약 500명 (획득비용 0)
   └→ 8% 가 전체 리포트 결제 → 40명 × 29,000 = 116만 원 / 학과
        └→ 그중 15% 가 커리어 팩 → 6명 × 49,000 = 29만 원
             └→ 그중 일부가 컨설팅 → 기존 사업 매출
```

**학과 하나당 B2C 가 약 145만 원 더 붙는다.** B2B 매출의 10% 수준이지만
**획득 비용이 0이라 거의 전부 이익**이고, 졸업 후에도 남는 계정이 된다.

전환율 8% 는 보수적 가정이다. 무료로 1위 직무를 다 보여주고 나머지를 잠그는 구조에서
**교육 서비스의 일반적 무료→유료 전환은 3~10%** 다. 검증에서 실측한다.

## 3. 기업 (B2B) — 학생 수가 임계에 닿은 다음

**초기에는 팔 게 없다.** 인재풀에 학생이 1,000명은 있어야 기업이 돈을 낸다.
2차 이후 상품이다.

| 상품 | 가격 | 조건 |
|---|---|---|
| 인재풀 열람 구독 (중소) | 연 600만 | |
| 인재풀 열람 구독 (중견) | 연 1,500만 | |
| 인재풀 열람 구독 (대기업) | 연 3,000만 | |
| **채용 성공 수수료** | **150만 / 명** | 정액 |
| 지역기업 패키지 | 연 3,000만 (20~50개사 묶음) | **지자체·RISE 예산** |
| 직무 소개 콘텐츠 | 건당 300만 | 기업 브랜딩 |

**성공 수수료를 연봉 %가 아니라 정액으로 잡는 이유.**
신입 채용은 연봉 편차가 작다. %로 하면 협상이 길어지고, 기업이 연봉을 숨긴다.
정액이면 계약서가 한 장이다.

**지역기업 패키지가 실질적으로 가장 크다.** 개별 중소기업은 연 600만 원을 쓰기 어렵지만,
지자체가 관내 기업 30곳을 묶어 사는 건 앵커사업 예산으로 가능하다.
**이때 파는 대상은 기업이 아니라 지자체다.**

### 대학 채널을 지키는 규칙

기업 매출이 대학 채널보다 작다. **충돌하면 대학을 지킨다.**

- 학생 이름·연락처를 검색 결과에 띄우지 않는다. **열람 요청 → 학생 동의 → 공개**
- 학과 담당자가 자기 학생에게 어떤 기업이 접근했는지 볼 수 있다
- 학생이 언제든 인재풀에서 빠질 수 있다

이걸 어기면 대학이 계약을 끊는다. 한 번 끊기면 그 지역 전체가 막힌다.

## 4. 교육 (부가)

Skill Gap 이 나오면 **무엇을 팔아야 할지가 데이터로 나온다.**

| 상품 | 가격 | 예산 출처 |
|---|---|---|
| 학과 맞춤 캠프 (3일 · 30명) | 1,200만 | 학과 비교과 예산 |
| 제휴 부트캠프 리퍼럴 | 수강료의 15~20% | 학생 개인 |
| 기업 맞춤 교육 | 별도 | 기업 |

**"GD&T 충족률 31%" 라는 숫자가 곧 견적서다.**
학과가 이미 문제를 인정한 상태에서 해결책을 파는 것이라 전환이 높다.

## 5. 3년 시나리오

**가정을 밝힌다** — 학과 평균 500명, B2C 전환 8%, 재계약률 70%.

| | 1년차 | 2년차 | 3년차 |
|---|---|---|---|
| 전공 | 기계 | +전기전자·컴퓨터 | +고교 |
| 계약 학과 | 8 | 25 | 60 |
| B2B 매출 | 1.1억 | 3.5억 | 8.4억 |
| B2C 매출 | 0.09억 | 0.36억 | 0.87억 |
| 기업 매출 | 0 | 0.5억 | 2.0억 |
| 교육 매출 | 0.1억 | 0.4억 | 1.2억 |
| **합계** | **약 1.3억** | **약 4.8억** | **약 12.5억** |

**1년차 8개 학과가 관문이다.** 이걸 넘기면 2년차는 재계약 + 소개로 굴러간다.
못 넘기면 가격이 아니라 제품(Top-3 수용률)을 의심해야 한다.

## 6. 가격을 정할 때의 원칙

1. **학생에게 비싸게 팔지 않는다.** 학생은 돈이 없고, 무료 대체재가 있다
2. **학과에는 좌석으로 판다.** 구독은 학교 회계와 안 맞는다. 좌석은 물품 구매로 처리된다
3. **기업에는 구독 + 성공보수 둘 다.** 구독만 하면 안 쓰고 해지하고, 성공보수만 하면 매출이 안 잡힌다
4. **할인은 규모로만 한다.** 첫 계약 할인은 다음 계약의 천장이 된다
5. **무료 구간을 정직하게 준다.** 1위 직무는 다 보여준다. 흐리게 가리면 신뢰를 잃고 결제도 안 된다
