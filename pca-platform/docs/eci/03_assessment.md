# 검사 문항 설계

**만드는 검사지는 두 벌이다.** 고교판(`HS_V1`)과 대학판(`UNIV_V1`).
트랙이 넷이어도 대학 1학년과 졸업예정자는 같은 문항을 푼다. 다른 건 채점 가중치뿐이다.

> 기존 `CLAUDE.md` 는 문항 수와 내용을 "정해지지 않은 것" 으로 두고 임의로 정하지 말라고 적어 두었다.
> 아래는 **확정이 아니라 제안**이다. 숫자마다 근거를 붙였으니 그 근거를 보고 바꾸면 된다.

---

## 1. 측정하는 축

### 1-1. 공학 활동 선호 8축 (새로 만드는 것)

기존 PCA 의 업무 성향 6축은 **일하는 방식**을 잰다. 공학 직무를 가르려면
**어떤 활동을 즐기는가**가 필요하다. "협력형" 은 CAE 와 생산기술을 못 가른다.

| 축 | 뜻 | 이 축이 높으면 |
|---|---|---|
| `ANALYZE` 해석·계산 | 현상을 수식과 모델로 푼다 | CAE, 통신, 소자 |
| `DESIGN` 설계·구상 | 요구조건에서 형상을 만든다 | 기계설계, 회로설계, 프론트엔드 |
| `BUILD` 제작·실험 | 만들고 측정해 확인한다 | 시험·신뢰성, 로봇, 임베디드 |
| `CODE` 구현·프로그래밍 | 코드로 동작을 만든다 | SW 전반, RTL, 펌웨어 |
| `FIELD` 현장·설비 | 설비가 있는 데서 돌아가게 한다 | 생산기술, 장비, 전력 |
| `OPTIMIZE` 개선·효율 | 있는 걸 더 낫게 만든다 | 품질, 수율, SRE |
| `RESEARCH` 탐구·이론 | 원리를 파고든다 | R&D, 소자, ML |
| `ORCHESTRATE` 조율·관리 | 사람·일정을 맞춘다 | PM, 품질보증, 생산관리 |

### 1-2. 업무 성향 6축 (기존 유지)

독립 · 협력 · 도전 · 안정 · 속도중시 · 품질중시.
기존 PCA 결과지의 육각형을 그대로 쓴다. **바꾸면 기존 응시자와 비교가 끊긴다.**

### 1-3. 선호 (산업·지역·기업형태)

점수가 아니라 **선택**이다. 매칭 산식의 P 항으로 들어간다.

### 1-4. 역량 자기평가

`questions.competency_id` 가 붙은 문항. "ANSYS 를 어느 정도 다루나" 를 직접 묻는다.
**신뢰도 0.5 로 가장 낮게 가중한다** — 자기보고이기 때문이다.
과목·자격이 있으면 그쪽이 이긴다.

## 2. 문항 구성

### 대학판 `UNIV_V1` — 140문항 · 약 26분

| 구분 | 문항 수 | 형식 | 비고 |
|---|---|---|---|
| 공학 활동 선호 | 64 | 5점 리커트 | 축당 8문항 (역채점 3 포함) |
| 업무 성향 | 36 | 5점 리커트 | 축당 6문항 |
| 양자택일 | 12 | 강제선택 | 리커트의 중앙 쏠림 보정 |
| 산업·근무 선호 | 16 | 선택 | 점수 아님 |
| 역량 자기평가 | 9 | 5점 | 전공별로 다른 문항이 나간다 |
| 주의 확인 | 3 | 리커트 | "이 문항은 3번을 고르세요" |
| **합계** | **140** | | |

**축당 8문항인 이유.** 5문항 아래면 내적 일관성(α)이 0.7 을 못 넘기고,
10문항이 넘으면 8축 × 10 = 80문항이라 응답 피로가 온다. 8이 실무적 하한선이다.

**역채점 3문항의 이유.** 전부 정방향이면 직선 응답(전부 4번)이 고득점으로 나온다.

### 고교판 `HS_V1` — 96문항 · 약 18분

| 구분 | 문항 수 | 비고 |
|---|---|---|
| 공학 활동 선호 | 48 | 축당 6문항. 고교생 어휘로 다시 씀 |
| 업무 성향 | 24 | 축당 4문항 |
| 관심 대상 선택 | 12 | "관심 가는 것" 사물·현상 |
| 지역·진로 선호 | 9 | 정주 의향 포함 |
| 주의 확인 | 3 | |
| **합계** | **96** | |

**성적을 묻지 않는다.** 고1 성적으로 공학 적합을 판정하면 결과지가 성적표의 재탕이 되고,
학교가 사지 않는다. 취업형(`goal=job`)은 여기에 **이수한 NCS 능력단위와 자격증**을 추가로 받는다
— 성적이 아니라 증거다.

### 무료 간이판 `LITE_V1` — 12문항 · 약 3분

B2C 입구. 활동 8축에서 각 1문항 + 양자택일 4문항.
**정밀도가 낮으므로 1위 직무만 보여주고 점수는 안 보여준다.**
12문항으로 뽑은 순위에 점수를 찍으면 그건 거짓말이다.

## 4. 응답 품질 — 못 믿을 응답을 골라낸다

500명이 단체로 보면 **성의 없는 응답이 반드시 섞인다.** 이걸 못 거르면
학과 리포트의 집계가 오염되고, 그 리포트로 계약을 갱신할 수 없다.

`attempt_quality` 에 네 가지를 남긴다.

| 지표 | 판정 | 임계 |
|---|---|---|
| `straightline_run` | 같은 보기를 연속으로 고른 최대 횟수 | 15 이상이면 경고 |
| `fast_ratio` | 1.5초 미만 응답 비율 | 0.25 이상이면 경고 |
| `attention_pass` | 주의 확인 문항 통과 수 | 3개 중 2개 미만이면 경고 |
| `evidence_fill` | 증거 충실도 (과목·프로젝트를 얼마나 채웠나) | 낮으면 구간을 넓힌다 |

**중요 — 신뢰도로 점수를 깎지 않는다.**

깎으면 학생 간 비교가 깨진다. 대신 **결과지의 구간 폭(`band_width`)을 넓힌다.**

```
증거 충실   82 (±4)   ← 과목·프로젝트·자격이 다 있다
증거 부족   82 (±12)  ← 검사 응답만 있다
```

같은 82점인데 하나는 신뢰할 만하고 하나는 아니라는 걸 **화면이 정직하게 말한다.**
경고가 뜬 응시는 학과 리포트 집계에서 빼고, 그 사실을 리포트에 적는다
("487명 중 12명 제외 — 응답 품질").

## 5. 규준 — 점수를 무엇과 비교하나

원점수는 의미가 없다. "설계 성향 4.2점" 이 높은 건지 낮은 건지 알 수 없다.

```
raw   → 문항 수로 정규화 → 0~100
      → 규준집단 대비 z  → T = 50 + 10z  (20~80 절단)
```

규준집단(`norm_groups`)은 **트랙 · 전공 · 학년 · 국가** 넷으로만 나눈다.

**성별과 출신 학교를 넣지 않는다.** 넣으면 "여학생 기준으로 상위 20%" 같은 값이 나오고,
그건 차별이면서 동시에 쓸모도 없다 — 학생이 취업할 시장은 성별로 나뉘어 있지 않다.

초기에는 규준이 없다. 100명 검증 전까지는 **전문가 설정 기준점**을 쓰고,
`norm_groups.n_size` 가 200을 넘으면 실측 규준으로 자동 교체한다.
결과지에는 그때까지 "잠정 기준" 이라고 적는다.

## 6. 문항을 고칠 때

**절대로 기존 문항을 수정하지 않는다** (기존 설계 원칙 4).

```
v1.0 published  ─→  응시자 500명의 결과가 여기 묶여 있다
v1.1 draft      ─→  문항 12개 교체
     published  ─→  이후 응시자만 여기로
```

작년 응시자의 결과가 올해 문항 수정으로 바뀌면, 학과가 작년 리포트를 못 믿게 된다.
축(`indicator_axes`)만 버전을 건너뛰어 유지되므로 **비교는 계속 가능하다.**
