# Common Core 착지 권한 범위 (CC-000 개정안)

| | |
|---|---|
| 결정 | 사업주 2026-10-20: Core 를 **검토 창구에서 착지 담당으로** 바꾼다 (대화 기록 · 이 문서는 그 결정을 범위로 옮긴 것) |
| 상태 | **범위 PROPOSED** — 총괄 PM 확인 전에는 Core 가 아래 2구역 파일을 고치지 않는다 |
| 바뀌지 않는 것 | 측정 동결 · 채점 · 문항 은행 · 결과 모델 · 학생 공개 상태 · 운영 DB · 운영 배포. Core 는 여전히 **승인하지 않고** 운영 가지에 **직접 올리지 않는다** |

**착지의 뜻.** 전에는 Core 가 문제를 재현하고 계약을 제안하는 데서 멈췄다. 이제는 공통 파일에 대한
**실제 패치와 그것을 증명하는 테스트**를 만들어 *승인만 하면 합칠 수 있는 상태*까지 가져간다.
합치는 일(운영 가지 반영)과 배포는 지금처럼 승인자가 한다.

## 1. 세 구역

### 1구역 · Core 소유 — Core 가 쓰고 Core 가 합친다

| 경로 | 내용 |
|---|---|
| `src/lib/shared-core/**` | 기관 프로필 읽기 · 해석 · 검증 (`tenant/`) |
| `scripts/shared-core/**` | Core 회귀 · 재현 · 벤치마크 · 보호 묶음 |
| `docs/shared-core/**` | 계약 · 보고 · 회신 · 증거 |
| `content/tenants/**` (만들 때) | 기관 프로필 한 벌씩 |
| `db/proposed/**` (만들 때) | 승인 전 마이그레이션 초안 — **체인에 넣지 않는다** |

조건: 보호 묶음 전후 같음 · 다른 구역 파일 diff 0. 승인 불필요(지금과 같다).

### 2구역 · 공통 파일 — Core 가 쓰고, **총괄 PM 승인 뒤** 합친다

계약 하나에 파일이 묶인다. 목록에 없는 파일은 2구역이 아니다.

| 계약 | 파일 | 무엇을 | 함께 알릴 기관 |
|---|---|---|---|
| **CC-009 파기 · 기한** | `src/lib/erasure.ts` · (새) 기한 집행 명령 `scripts/purge-expired.ts` 와 `deploy/ops/package.json` 한 줄 | `REMOVE`/`KEEP` 분류 · `v3_experiences` 등 미분류 표 · `purge_after` 집행 | 전부 · 사업주(개인정보) |
| **CC-002 1단계 학교 학생 신원** | `src/lib/campus/students.ts` · `src/lib/campus/manage.ts` | `(university_code, student_id)` 로만 찾기 · 남의 손잡이 거절 (`proposed/sc2-p0.patch`) | 배재(파일 사용자) · 전주 · 세종 |
| **CC-002 2단계 로그인** | `src/lib/auth.ts` 의 `authorize()` · `src/lib/login-throttle.ts` · 학교 로그인 폼이 넘기는 값 | 기관 코드를 함께 받아 `(기관, 학번)` 으로 찾기 · 시도 제한 열쇠에 기관 | 본체(인증) · 배재 |
| CC-002 부수 | `src/app/password/forgot/actions.ts` | `LIMIT 1` 에 차례 지정 | 본체 |
| CC-001 기관 프로필 연결 | `src/lib/campus/registry.ts` 의 읽는 자리 한 곳 | 프로필을 실제 진입에 연결 | 배재 · 전주 · 세종 |
| CC-005 기관 격리 | 격리 검사 스크립트가 부르는 **읽기 함수**에 한해 | 남의 기관 줄이 섞이지 않는지 | 전부 |
| DB (위 계약이 요구할 때만) | **새** 마이그레이션 파일 하나 + `deploy/db-chain.json` 맨 뒤 **한 줄 추가** | 칸 · 제약 · 인덱스 추가만 | 전부 |

### 3구역 · Core 가 손대지 않는다

| 영역 | 주인 |
|---|---|
| 채점 · 문항 은행 · 측정 동결 파일 · 결과 모델 · 결과 문장 | 측정 동결 · 본체 |
| 검사 · 결과지 · 작업공간 화면 (`src/app/**` 의 화면) | 각 화면 동결 |
| `campus-universities.json` 의 학교 블록 내용 | 그 학교 세션 (배재 블록은 배재) |
| GM · PDF (`report-gm/**`) · 결제 · 가격 · 이용권 | 배재 · 본체 |
| `Dockerfile` · Railway · 볼륨 · 도메인 · CI 워크플로 | 배포 담당 |
| `package.json` · lockfile (CC-000 에 적힌 두 줄 밖) | 본체 |
| 기존 마이그레이션 파일 내용 · 운영 DB · 운영 배포 · `open_to_students` | 총괄 PM · 사업주 |

## 2. 2구역 착지 차례

| # | 걸음 | Core 가 남기는 것 |
|---|---|---|
| 1 | 계약 개정 (`CONTRACTS.md`) — 바뀌는 것 · 안 바뀌는 것 · 영향 기관 | 계약 줄 |
| 2 | Core 가지에 패치 + **실행 테스트** (일회용 PostgreSQL · 재현 테스트가 고치기 전 FAIL · 고친 뒤 PASS) | 테스트 파일 · 로그 |
| 3 | 보호 묶음 전후 같음 · 측정 동결 다시 적지 않은 채 통과 · 3구역 diff 0 | `protect/{before,after}` |
| 4 | 기관별 영향표 + 되돌림 방법 + 배포 차례(마이그레이션 먼저인지) | 착지 요청서 |
| 5 | **총괄 PM 승인** — `CONTRACTS.md` 상태 표의 `승인 증거` 칸에 일자 · 승인자 · 커밋 SHA | 승인 기록 |
| 6 | 합치기: 승인자가 Core 커밋을 운영 가지로 가져간다 (또는 승인자가 요청하면 Core 가 PR 을 연다). **Core 는 운영 가지에 직접 푸시하지 않는다** | 합친 SHA |
| 7 | Staging 확인 → 운영 배포는 PM | Staging 증거 |

**한 계약 = 한 커밋 묶음.** 섞으면 하나만 되돌릴 수 없다.

## 3. 넘으면 멈추는 선

- 측정 동결 · 화면 동결 기록을 **다시 적어야** 통과한다면 그 패치는 2구역 밖이다 → 멈추고 보고
- 기존 마이그레이션을 고쳐야 한다면 → 멈추고 보고 (새 파일로만 더한다)
- 저장된 응답 · 점수 · 결과의 **뜻**이 바뀐다면 → 멈추고 보고
- 다른 기관 가지에서 같은 파일이 갈라져 있다면 → 영향표에 적고 그 기관과 차례를 맞춘다 (덮어쓰지 않는다)
- 운영 · Staging 에서만 확인되는 동작은 `NOT VERIFIED` 로 둔다
