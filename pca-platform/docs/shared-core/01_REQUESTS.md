## 1. 전주대 (JJU) — 계획서 §8 E1~E7

전주대 세션의 계획서 원문(scratchpad 의 `JJU_CAMPUS_PLAN.md`)은 그 세션의 컨테이너 안에 있어 이 세션에서
열 수 없다. 아래는 그 세션이 사용자에게 보고한 일곱 갈래다. 번호는 이 문서의 것이고, 원문 E1~E7 과의
짝은 그 세션이 확인해 주어야 한다.

## 3. 세종일자리경제진흥원 — 공식 요청 없음 (추정)

사실에서 이 세션이 추정한 것**이고, 세종 세션의 확인을 받기 전에는 구현 근거로 쓰지 않는다.

## 4. 배재대

공통 Core 에 올린 요청이 없다. 공통 Core 가 지켜야 할 조건만 있다.

- GM 경로(`00_BASELINE.md` §5)를 건드리지 않는다.
- R35 의 `CM_V3_CAMPUS_PRO` 상품 줄은 Staging·운영 `db:upgrade` 대기다. 운영 DB 작업이라 Common Core 가 하지 않는다.
- GM 을 운영에 잇는 일은 배재 세션이 Human Review 뒤에 `RESULT_UI_VERSION` 을 올려 한다. SC-4 의 `template_key` 는
  그때 쓸 자리만 비워 둔다.
