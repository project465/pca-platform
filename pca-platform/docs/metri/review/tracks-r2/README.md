# CareerMatri PCU · 5개 트랙 2차 통합 현황 (2026-10-20)

PM 통합 검수(CONDITIONAL PASS)의 차기 지시를 트랙마다 처리했다. **자동 검사와 브라우저 검증을 섞지 않는다.** 이 환경은
npm 레지스트리(DNS) · `www.pcu.ac.kr` · `app.careermatri.com` 이 막혀(`B/logs/pcu-reach.log`) Next 를 빌드할 수 없고 운영을
열 수 없다. 그래서 아래 PASS 는 **서버 함수 · 서버 액션 · 실제 PostgreSQL(따로 띄운 5433 클러스터 포함) · 실제 node-postgres 드라이버 ·
실제 PDF 렌더(Chromium)** 기준이고, 화면 · 쿠키 · 모바일 · 운영은 NOT VERIFIED 로 적는다.

## 변경 금지 준수

공통 Q1~Q92 측정·채점 · DB/API 계약 · 공통 인증 · 공통 PDF 엔진 · 운영 배포 · 브랜치 병합을 **바꾸지 않았다**. 측정 동결은
기록을 다시 적지 않은 채로 14/14 통과한다(`REGRESSION/logs/v3-measurement-freeze.log`). 예외로 적어 둘 것이 하나 있다:

- **Track C 의 저장 경로 변경**(`runtime/session.ts`): 측정·채점 규칙은 한 줄도 바뀌지 않았고 바뀐 것은 저장과 제출의 **잠금 순서**다.
  실제 드라이버로 재현한 P0(제출 중 늦은 저장이 굳은 판정과 어긋남)를 막는 고침이고, DB 스키마 · API 모양은 그대로다
  (`answerAction` 이 늘 돌려주던 `{ ok }` 가 거절일 때 `false` 가 된다). **API 계약 변경으로 보실지 판단을 요청한다**:
  그렇게 보시면 이 커밋만 되돌려도 다른 트랙은 영향이 없다(트랙별 브랜치 · 커밋이 갈려 있다).
