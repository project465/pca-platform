## 계보 후보 (등록부 `lineage_candidates` 그대로 · 확정 아님)

- 전기전자공학과(2026) → 전기공학과(2027). 명칭 유사성만으로 계보를 확정할 수 없다
- 소프트웨어공학부 4전공(2026) → AI소프트웨어공학부 4전공(2027) + 인공지능전공 신설
- 드론로봇공학과(2026) → 피지컬AI공학부 드론로봇공학전공(2027). 같은 Core 를 쓸 수 있는지는 따로 판단한다
- 공연예술학과 음악·영화영상 트랙(2026) → 공연예술학부 실용음악·영화영상학 전공(2027). 학과와 전공의 레벨이 같은지 확인이 필요하다
- 평생교육융합학부 라이프케어(2026) → 사회복지상담(2027) · 지역소상공비즈니스(2026) → 농산업비즈니스(2027) · 시니어운동처방(2026) → 시니어운동처방·파크골프(2027)
- 글로벌융합학부 아트컬처비즈니스(2026) → K컬처비즈니스(2027) · 글로벌IT(2026) → 글로벌IT·AI(2027) · K푸드테크(2027) 신설

## 응시 목록에서 뺀 조직 (`excluded_units`)

- 교직과 — 교원양성 교육과정 조직으로 보인다. 학생이 자기 전공으로 고르는 자리인지 확인 전이라 응시 목록에 넣지 않았다
- 주시경교양대학(기초교육부·중점교육부) — 교양 교육조직이고 전공이 아니다

## 남은 물음 (`open_questions`)

- 두 Catalog 의 공식 쪽을 이 작업 환경에서 직접 열지 못했다(네트워크 정책이 `pcu.ac.kr` 의 HTTPS 를 CONNECT 403 으로 막는다). 구조는 전달받은 근거 파일을 옮긴 것이고 `verified_at` 은 비어 있다
- `교직과` 가 학생이 고르는 전공인지 교원양성 조직인지 확인 전이라 응시 목록에서 뺐다
- 평생교육융합학부(성인학습자)와 글로벌융합학부(외국인 유학생)의 계약 범위와 학생 계정 대상이 정해지지 않았다. 지금은 공식 편제대로 전부 싣고 학생 화면에도 세운다
- 2026 과 2027 사이의 개편 계보를 공식 자료가 적어 주지 않아 `replaces` 를 한 줄도 적지 않았다. 후보는 `lineage_candidates` 에 있다
- 2027 입학안내 랜딩은 `철도건설학과` 로도 적는다. 연도별 탭과 정시 모집요강의 `철도건설공학과` 를 따랐다
- 스마트배터리학과의 Core 는 에너지공학·화학공학·신소재 셋이 후보라 고르지 않았다
