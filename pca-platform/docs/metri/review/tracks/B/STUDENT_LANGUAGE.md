# Track B · 학생 언어 사전을 스무 Core 로 (2026-10-20)

`src/lib/me-v3/student/copy.ts` 의 `STUDENT_COPY` · `EXPERIENCE_EXAMPLE` · `EXPERIENCE_FLOW` 가 여섯 Core(BIZ · NURSING · PUBADM · CS · EE · MEDIA)만 들고 있었다.
나머지 열넷은 결과지 현재 상태 카드에 taxonomy `subareas` 토막(`domainSub`)이 서고, 경험 추가의 예시와 걸음 말이 전공을 가리키지 않는 중립 문구로 떨어졌다.
이번에 **열넷 × 영역 열둘 = 168자리**를 손으로 적어 콘텐츠가 선 스무 Core 전부를 덮었다(71 → 239자리).

**바뀌지 않은 것**: 문항 은행 · taxonomy · domains JSON · 채점 · 결과 모델 · 등록부 · DB. 측정 동결(`v3-measurement-freeze`)은 기록을 다시 적지 않은 채로 14/14 통과한다.
활동 구와 남는 것의 이름은 그 Core 의 `*-domains.json` 이 적은 산출물(artifacts)과 일하는 차례(workflow 3·4단)를 보고 적었고, `subareas` 를 가운뎃점으로 잇지 않았다.

## 규칙(`scripts/v3-student-check.ts` 가 센다)

- 활동 구는 움직씨 구(`…기`, 띄어쓰기 있음) · 16자 안 · 가운뎃점 없음 · 한 Core 열둘에서 한 끝맺음이 절반을 넘지 않음
- 남는 것의 이름은 8자 안(공백 제외)이고 안쪽 용어(`산출물` · `증거` · `확인된 판단` …)가 없음
- 활동 구와 남는 것의 이름이 **Core 를 건너** 글자까지 같은 줄이 없음(239자리 전체)
- 경험 예시는 수업 · 실습 · 팀 과제에서 나오는 장면이고 현업 경력을 전제하지 않음. 스무 개가 서로 다름

검사의 덮는 범위를 넓혔다: 전에는 여섯을 글자로 적어 두고 셌고, 지금은 등록부에서 taxonomy 파일을 든 Core 전부를 센다(Core 를 하나 더 지은 날 목록이 따라온다). 한도는 하나도 늘리지 않았다.

## 하지 않은 것

- **경험 번역 열 단계 보기(`TRANSLATE_MENU`)는 넓히지 않았다.** `student/translate.ts` 는 검사 화면 동결(`ui-lock.json`)이 덮는 파일이라 고치면 `ASSESSMENT_COPY_VERSION` 을 올리고 검사 화면 동결을 다시 적어야 한다. 이번 작업 범위(결과지·작업공간 문장) 밖이라 ME · BIZ 두 벌 그대로 두고 나머지는 중립 벌이다.
- 적은 168줄이 그 전공에서 자연스러운 말인지는 **그 전공을 아는 분이 읽어야 한다.** 기계가 세는 것은 꼴과 길이와 겹침까지다.
