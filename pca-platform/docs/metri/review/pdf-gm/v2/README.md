## 4. 지켜 둔 선

- **직업정보 제공이며 알선이 아니다.** `추천 기업` 을 쓰지 않고 `진로 탐색 기업 · 직무 연관 기업` 으로 쓴다.
  채용 여부는 전부 미확인이고 기업이 학생을 선발한다는 뜻이 아니라고 장마다 적는다.
- **수치를 만들지 않는다.** 적합도 · 점수 · 순위 · 합격 가능성 0건. 성과·수치·기간은 `직접 기입` 칸이다.
- **KODATA 는 제3자 자료다.** 공식 자료와 같은 층으로 적지 않고 재무표·신용등급·주주·거래처·임원 개인정보를
  옮기지 않았다. 원본 보고서(Drive `[대외비]` 폴더)는 저장소에 넣지 않았다. 기존 13곳과 사업자번호·법인명으로
  견줘 **겹치는 곳은 0** 이다. 젬백스앤카엘은 본점 이전 보도로 지역을 `전국` · 검증 `CONFLICTING` 으로 두었다.
- **무관한 기업을 억지로 싣지 않는다.** 연결 근거가 없는 기업은 빠지고, 세종 소재 확인 기업이 없다는 것을 적는다.

## 5. 사람이 봐 주셔야 하는 것 (Human Review)

1. 표지·차례·장 머리의 활자와 여백이 상품으로 읽히는가(Pretendard 1.3.9 · OFL-1.1 · 네 굵기 서브셋 임베드, `pdffonts` 로 확인)
2. 02장 레이더와 강점 지도가 그림만 보고 뜻이 서는가
3. 08장 기업 카드의 `확인된 사실 / 분석적 해석 / 추가 확인 필요` 구분이 충분한가
4. KODATA 기반 사실을 이 수준으로 외부 배포용 PDF 에 써도 되는지(이용허락 범위 확인 필요)
5. 공식 원문 미열람 기업(`OFFICIAL_CROSSCHECKED` = 검색 결과 대조)을 학생 결과지에 실어도 되는지
6. CONTRA 처럼 근거 없이 높게 답한 학생에게 03장의 `확인 필요` 문장이 지나치게 단정적이지 않은지

## 6. 아직 아닌 것
