## 70쪽에 못 미치는 사례가 둘이다 — 채워 넣지 않았다

POOR 는 고른 근거가 0개이고 근거가 선 영역이 없다. 그 학생에게 근거 원장 · 강점 활용 · 행동에서 결과물까지 쪽을 세우면
빈 표가 서거나 지어낸 문장이 선다. 그래서 **조건이 맞지 않는 쪽은 빼고, 빠진 까닭과 필요한 자료를 마지막 쪽(설계 80)에 적었다.**
CONTRA 도 같은 까닭으로 66쪽이다. 70쪽을 맞추려고 같은 내용을 되풀이하거나 다른 쪽으로 채우지 않았다.

## 쪽 안 검사

- **잘림**: 쪽마다 본문 아래로 넘친 높이를 잰다. 넘치면 그 쪽의 글만 줄여(최대 17%) 맞춘다. 세 사례 모두 넘친 쪽 0.
- **기업 숫자**: 공시 쪽(설계 43·44·45)의 매출·영업이익·순이익과 계산한 영업이익률은 `data/region/dart-checks.v1.json` 을 읽기만 한다.
  리가켐 1,415.5 / −1,064.9 / −915.5억 · −75.2%, 중앙백신 490.7 / 64.8 / 61.6억 · 13.2% 를 쪽 그림에서 다시 확인했다.
  공시 개황이 없는 회사(라미랩·플랜아이·엠티지)는 ‘공시 개황 없음(검증되지 않음)’ 으로 적고 숫자를 세우지 않는다.
- **검증 수준 표시**: 쪽마다 근거 줄이 `공식 원문 직접 확인 · 제3자 자료 · 검색만 · 상충 · 검증되지 않음 · 일반 안내 · 응답에서 읽음` 가운데
  하나를 든다. 채용 여부는 전부 ‘미확인’ 이고 적합도 숫자·합격 가능성·순위는 없다.
- **고친 결함**(쪽 그림을 읽고 찾은 것): 공시 개황이 없는 회사의 빈 괄호 · 기업 쪽 세 장의 같은 머리말 · 면접 쪽 셋의 같은 ‘답의 뼈대’ ·
  판본 칸의 `null` · ‘관심은 관심이 높다고…아래 그림에서’ 문장 · 반쪽만 찬 전략 쪽 넷 · 0으로 서던 ‘여러 회사에 함께 쓰이는 근거’ ·
  열이 되풀이되던 포트폴리오 표.

## 다시 뽑기

```bash
service postgresql start
CASES=RICH:1,POOR:2,CONTRA:3 npx tsx scripts/lab/gm-full6.ts   # → 이 폴더. 넘친 쪽이 있으면 1 로 끝난다
```

글꼴은 `var/pdf-gm/fonts/pretendard/`(Pretendard 1.3.9, OFL)를 쓰고 없으면 나눔고딕으로 떨어진다. 글꼴 파일은 저장소에 없다.
공시 자료는 `dart-verify.mjs` · `dart_overview.py` 가 만든 파일을 읽기만 하고, 여기서 OpenDART 를 부르지 않는다.

## 하지 않은 것

- 운영 PDF(`/v3/{id}/result/pdf`) 연결 · Production 배포 · 학생 공개.
- 직무·기업 안내 자료(R12)와 KODATA 줄(R10)의 학생 배포 권리 확정 — 사람의 판단이 남아 있다.
