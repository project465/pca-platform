# 출처 접근과 공식 대조 (2026-10-20)

## 1. 이 환경에서 열리는 출처

`curl` 로 첫 쪽을 두드린 결과다(000 = 연결 거절). 열리지 않은 출처는 쓰지 않았고 짐작으로 채우지 않았다.

**열쇠는 환경변수에서만 읽는다.** 결과 파일과 스크립트에 열쇠와 요청 주소가 0건인 것을 확인했다. Node 의 `fetch` 는 프록시 환경변수를 저절로 읽지 않아 `NODE_USE_ENV_PROXY=1` 을 함께 준다(없으면 연결이 끊겨 ‘응답 없음’ 으로 적힌다).

### 읽은 것

- **KODATA 에서 온 9곳의 사업자등록번호와 법인등록번호가 DART 와 모두 같다.** 기업 식별은 공식 원문으로 확인됐다(사업 설명·재무는 별개).
- **(주)제이오텍: 상충.** v2(KODATA)는 본점을 대전 유성구로 적었는데 DART 기업개황은 경기도 김포시다. 어느 쪽이 지금 맞는지 이 환경에서 가릴 수 없어 `CONFLICTING` 으로 둔다. 대전 지역 기업으로 소개하기 전에 확인해야 한다.
- 골프존 · 삼성디스플레이 · 에어로케이항공: DART 본점이 다른 시도다. v2 가 이미 ‘사업장’ 기준으로 적은 곳이라 틀린 것은 아니지만, 리포트에는 **본점과 사업장을 갈라 적는다**(39쪽).
- 라미랩 · 국가철도공단 · 한국조폐공사 · 대전관광공사: DART 고유번호 목록에 없다. 공공기관은 ALIO(R5), 비상장사는 KODATA 뿐이다.
- 상장 7곳은 가장 최근 사업보고서(2025.12, 2026년 3월 접수)의 주요 계정과 사업부문별 직원 수를 받았다. **숫자는 받은 그대로(원 단위) 두고 고치지 않았다.**

## 3. ‘사업의 개요’ 원문 발췌

`scripts/lab/dart_overview.py` → `data/region/dart-overview.v1.json`. 상장 7곳의 사업보고서 원문에서 ‘사업의 개요’ 앞 900자를 **요약·의역 없이** 옮겼다. 리포트에서는 인용 표시와 접수번호를 함께 적고, 회사 설명을 우리 말로 바꿔 쓰는 일은 사람이 한다(문장은 모델이 쓰지 않는다).

## 4. ‘공식 원문 직접 확인 0건’ 표기는 이렇게 바뀐다

- v2 기업 자료의 **식별 칸**(사업자·법인등록번호 · 본점 · 상장 구분)과 **상장사 공시 수치**는 `OFFICIAL_DIRECT` 로 올릴 수 있다.
- **사업 설명 · 직무 · 채용**은 그대로다: 사업 설명은 원문 인용으로만 올리고, 직무는 공고 원문(R8)을 읽기 전까지 `SEARCH_ONLY`, 채용 여부는 **계속 미확인**이다.
- v4 대표 5쪽의 ‘공식 원문은 직접 열람하지 못했습니다’ 문구는 이 회차에서 고치지 않았다(5쪽 승인 대상 문서라 그대로 둔다). 80쪽 설계의 기업 쪽부터 새 표기를 쓴다.

## 5. KODATA

학생 배포 권리가 확정되지 않았다(R10). 비상장 기업 쪽(52~54쪽)은 KODATA 외 근거가 없어 **권리가 확정되기 전에는 학생 배포본에 싣지 않는다.** 재무표·신용등급·주주·거래처는 옮기지 않는다.
