## 4. 기업 자료 — 부족한 것과 확보 방법 (먼저 보고)

**실명 기업을 넣었지만 공식 확인은 0줄이다.** 이 작업 환경에서 기관 공식 홈페이지 ·
전자공시(DART) · 공공기관 경영정보 공개시스템(ALIO)을 열 수 없어(네트워크 정책,
`ENOTFOUND`) 검색 결과(채용정보 사이트 · 언론 · 커뮤니티)로만 13곳을 적었다. 모든
줄에 출처 URL · 확인 수준 · 확인일(2026-10-19)을 붙였고, 종이에도 그대로 적힌다.

- **채용 여부는 한 줄도 확인하지 않았다** → 전부 `미확인`. `현재 채용 중` 0건.
- **근무지를 적지 않았다** → 본사·사업장·거점만, 근무지는 `확인하지 않았습니다`.
- **출처끼리 다른 줄**(골프존: 대전 사업장 vs 서울 주소)은 `출처끼리 다름` 으로 적고
  후보 차례에서 한 칸 뒤로 둔다.
- **약한 출처**(코레일·국가철도공단 = 커뮤니티 글)는 그대로 `커뮤니티 글` 로 적었다.
- **세종·충남 기업 실명은 1곳**(삼성디스플레이 아산 사업장)뿐이다. 대덕특구 기술기업은
  이름이 0곳이고 종이가 그 사실을 적는다.

**운영에 넣기 전에 필요한 것** (사람이 할 일):
1. 13곳 각각 공식 홈페이지·DART·ALIO 에서 주소·사업을 확인하고 `verification` 을
   `OFFICIAL` 로 올린다(확인한 사람·날짜).
2. 지역 후보를 늘린다: 대학 취업지원처 기업 목록 · 대전·세종·충남 공공기관 목록(ALIO) ·
   지역 상공회의소 회원사 · 대덕특구 입주기관 공개 목록. **이름이 비슷하다는 까닭으로
   늘리지 않는다.**
3. 채용 여부는 공고 수집 없이 `미확인` 으로 둔다. 공고를 쓰려면 이용약관 검토가 먼저다
   (CLAUDE.md: 공고 수집은 저작권·약관 검토 전).

## 5. 법적 표현 (판단 요청)

요청서의 `기업 추천` 은 CLAUDE.md 법적 범위(직업정보제공사업 신고만, 알선 불가)와
부딪힌다: 저장소는 `추천 기업` 을 쓰지 않기로 정했다. 그래서 종이는 **`검토할 직무·기업
후보`** 로 부르고, 장 머리에 `직업정보 제공이며 취업 알선·추천이 아닙니다. 기업이 이
직무를 모집한다는 뜻이 아니고, 채용 여부는 확인하지 않았습니다.` 를 적었다. `적합도` 숫자도
만들지 않았다(이어지는 까닭을 글자로만 적는다). **노무사·행정사 확인을 받을 자리다.**
