# BIZ 진로·직무 리포트 4차 2판 — 매거진형 편집 지침 (STYLE_GUIDE)

4차 1판(`v10-editorial`)은 구조를 다시 세웠지만 화면이 행정 문서처럼 읽혔다. 2판은 **같은 결과 모델 위에서 쪽 문법·위계·문장·흐름을 다시 짰다.**
코드: `src/lib/me-v3/report-gm/editorial8.ts`(쪽 내용 모델 `edit8`) · `render8.ts`(A4 매거진 렌더러 `pages8`/`html8`) · `scripts/lab/gm-ed8.ts`(뽑기·검사).
12쪽 시안과 전체 결과지는 **같은 렌더러**에서 나온다(`PROTO8` 은 전체 쪽 목록에서 열쇠로 고른 부분집합이다).

## 0. 참고 이미지

4차 명령이 말한 “사용자가 전달한 참고 이미지”는 **이 세션에 첨부되지 않았다.** 이미지 대조는 하지 못했고, 명령문 §2 의 글(큰 섹션 번호 · 넓은 여백 ·
한 쪽 한 메시지 · 비대칭 그리드 · 차분한 고급 색 · 본문 고딕 + 제목 표시 글꼴 하나)만 기준으로 삼았다. 이미지를 받으면 그 기준으로 한 번 더 돈다.

## 1. 원칙

1. **한 쪽 한 메시지.** 쪽 제목(`.hl`, 세리프 25pt)이 그 쪽의 결론 문장이다. 제목만 읽어도 리포트가 읽힌다.
2. **결론 → 근거 → 행동.** 쪽 안의 차례가 늘 같다: 큰 문장 → 짧은 덱(12pt) → 근거 묶음 → 맨 아래 띠(할 일·이어지는 쪽).
3. **아래 절반을 비우지 않는다.** 근거가 없는 쪽은 채우는 말 대신 **학생이 직접 쓰는 칸**(점선 쓰기 줄 `.wl`)을 둔다. 장식으로 채우지 않는다.
4. **글을 줄여 맞추지 않는다.** zoom·축소 인쇄 없음. 넘치면 검사가 실패하고 쪽을 나눈다(면접 2쪽 · 실행 계획 촘촘 모드).
5. **학생 응답을 사실로 올리지 않는다.** 근거의 층 넷(응답 확인 · 학생 자기기록 · 일반 직무 안내 · 분석 제안)을 정리 쪽에 적는다.
6. **공시·재무·지역 통계·기업 실명·확인 수준 배지를 쓰지 않는다.** 조직은 유형까지. 점수·순위·적합도·합격 가능성·연봉 없음.

## 2. 종이와 격자

- A4 세로. 여백 위 14 · 아래 12 · 왼 18 · 오른 16mm(본문 폭 176mm). `@page margin:0` 에 쪽 상자가 여백을 든다.
- 격자 셋만: **비대칭 7:4**(본문:주석), **3단**(셋을 나란히), **2단 1:1**(비교·대비 전용). 2단은 비교가 필요한 쪽에만 쓴다.
- **띠(`.band`)**: 쪽 아래를 좌우 여백 밖까지 채우는 모래색(`--sand`) 또는 남색 면. 그 쪽의 행동이나 다음 쪽으로 이어지는 말만 든다. 한 쪽에 하나.
- 쪽 머리: 큰 장 번호(세리프 30pt, 남색) + 장 이름 · 오른쪽 학교·학과. 쪽 꼬리: 제품 이름 · `장 이름 · 쪽 번호`.
- 세로 리듬: `.sp`(flex 1, 최소 7mm)가 본문과 맨 아래 묶음(`.push`) 사이의 남는 높이를 받는다. 그래서 맨 아래 묶음은 쪽 바닥에 붙고 빈 곳이 중간에 생긴다.

| 이름 | 값 | 쓰는 곳 |

| 잉크 | `#17191d` / `#3a3d44` / `#73767e` | 제목·본문 / 덱 / 주석 |
| 선 | `#d6cfc2` · `#e7e1d6` | 묶음 머리 아래선 · 표 줄 |
| 남색 | `#1d2b48` (+ 옅은 `#e8ebf1`) | 장 번호, 묶음 머리, 표지·정리의 띠 |
| 모래 | `#f0eadf` | 행동 띠 |
| 강조색 하나 | `#a8471b` | 큰 번호(1·2·3), 인용 왼쪽 선, 표지 머리말, 자기소개서 빈칸 |

## 4. 글꼴과 크기

| 역할 | 글꼴 | 크기 / 줄 사이 |
|---|---|---|
| 표지 제목 | Noto Serif KR Bold | 34pt / 1.3 |
| 차례 큰 번호 · 큰 숫자 | Noto Serif KR Bold | 40~44pt |
| 장 번호 | Noto Serif KR Bold | 30pt |
| 쪽 제목(결론 문장) | Noto Serif KR Bold | 25pt / 1.32 |
| 인용(`.pq`) | Noto Serif KR SemiBold | 16pt / 1.55 |
| 덱 | Pretendard Medium | 12pt / 1.62 |
| 본문 | Pretendard | 10.5pt / 1.62 |
| 묶음 머리 · 주석 · 쪽 꼬리 | Pretendard SemiBold / Regular | 9pt · 8.5pt |

- **두 글꼴 모두 SIL Open Font License 1.1** 이라 묶어 배포할 수 있다. Pretendard 1.3.9(`var/pdf-gm/fonts/pretendard/`) · Noto Serif KR 2.003 SubsetOTF/KR
  Bold·SemiBold·Medium(`var/pdf-gm/fonts/notoserif/`, 라이선스 동봉). `var/pdf-gm/` 는 저장소에 넣지 않는다. 운영 렌더러에 넣는 일은 Core 승인 요청(E-1)이다.
- **8.5pt 아래 글자 0.** 검사가 렌더된 쪽에서 계산된 글자 크기를 센다(세 사례 가장 작은 값 8.5pt).
- 한글 자간을 벌리지 않는다. `word-break: keep-all`, 제목은 `text-wrap: balance`.

## 6. 문장 규칙

- 쓰는 꼴: “먼저 볼 직무는 OOO입니다.” “지금 강한 쪽은 OOO입니다.” “관심은 분명하지만 결과물은 아직 부족합니다.” “다음 단계는 이 결과를 문서와 프로젝트로 바꾸는 일입니다.”
- 쓰지 않는 꼴(검사가 센다): “~로 해석할 수 있습니다”, “~를 확인할 필요가 있습니다”, “현재 결과에서는”, “~의 가능성을 보여줍니다”, “활용할 수 있습니다” 반복, 정의문·사전식 문장, 그리고 앞 회차의 상투 문장 14개.
- 조사는 `withJosa` 로 받침을 보고 붙인다. 따옴표·괄호 뒤 조사도 검사한다.
- 영어 낱말은 0이 원칙(POOR 의 `SNS` 한 자리만 남는다 — 학생이 고른 산출물 이름이다).

## 7. 사례마다 다른 리포트

RICH(EVIDENCE) · POOR(EARLY) · CONTRA(MIXED)는 같은 틀의 값만 바뀐 것이 아니다.

- 강점 쪽 제목: `지금 강한 쪽 세 가지` / `출발점 세 가지` / `이미 가진 것 세 가지`.
- RICH 만 영역 상세 쪽(최대 2)이 선다. POOR 만 `첫 4주` 쪽이 선다. CONTRA 만 `어긋나는 곳` 쪽이 서고 두 직무 쪽의 제목이 “목표는 인사이지만, 지금 근거가 더 많은 쪽은 영업·사업개발입니다.” 가 된다.
- 쪽 수: RICH 19 · POOR 18 · CONTRA 17.
