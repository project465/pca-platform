# BIZ 진로·직무 분석 결과지 4차 — 편집 지침 (STYLE_GUIDE)

v9 를 고친 판이 아니다. 구조·색·글꼴·문장·쪽 차례를 새로 정했다. 코드는
`src/lib/me-v3/report-gm/editorial.ts`(쪽 모델) · `render7.ts`(A4 렌더러) · `scripts/lab/gm-ed.ts`(뽑기·검사).

## 1. 원칙

1. **쪽마다 물음 하나.** 제목이 그 쪽의 물음이거나 답이다(“여덟 가지 판단을 어디까지 해 봤나”, “정하는 것과 남기는 것이 다릅니다”).
2. **근거가 없으면 쪽을 세우지 않는다.** 직접 정한 것·해 본 것·남긴 것이 하나도 없는 영역은 상세 쪽이 없다(POOR 는 2장 상세 쪽 0). 빈 쪽을 채우려고 다른 말을 넣지 않는다.
3. **글을 줄여 맞추지 않는다.** 렌더러에 zoom 이 없다. 넘치면 검사가 실패하고, 쪽을 나눈다.
4. **학생 응답을 사실로 올리지 않는다.** 줄마다 근거의 층을 하나 적는다(§5).
5. **기업 자료를 쓰지 않는다.** 공시·재무 수치·접수번호·사업자번호·기업 개요·‘확인 수준’ 표시를 넣지 않는다. 조직은 유형(대기업 본사·중견중소·공공기관·스타트업)까지만 적는다. KODATA 는 읽지 않는다.
6. **점수·순위·적합도·합격 가능성·연봉을 만들지 않는다.** 묻지 않은 영역은 ‘이번 검사에서 묻지 않음’이고 0 이 아니다.

## 2. 종이와 격자

- A4 세로, 여백 위 14 · 아래 12 · 왼 18 · 오른 16mm. 본문 폭 176mm.
- 격자: 2단(1:1), 3단, 7:4 비대칭 세 가지만 쓴다. 표는 가로 전폭.
- 쪽 머리: 왼쪽 `장 · 쪽 제목`, 오른쪽 학교·학과. 쪽 꼬리: 제품 이름 · 쪽 번호. 8.5pt.

## 4. 글꼴과 크기

- **Pretendard 하나**(SIL Open Font License 1.1, `var/pdf-gm/fonts/pretendard/LICENSE.txt` · 묶어 배포 가능). 표시용 글꼴을 따로 두지 않는다.
- 본문 10.5pt/1.62 · 표 9.5pt · 작은 본문 9.5pt · 주석 8.5pt(바닥) · 쪽 제목 17pt · 진단 문장 24pt · 표지 34pt.
- 8.5pt 아래 글자 0(검사가 센다). 한글 자간을 벌리지 않는다. `word-break: keep-all` 로 낱말 중간에서 줄을 끊지 않는다.

## 5. 근거의 층 (배지 대신 작은 주석)

| 주석 | 뜻 |
|---|---|
| 응답 확인 | 검사에서 고른 답과 체크리스트 항목 |
| 학생 자기기록 | 학생이 직접 적은 경험 기록. 확인하지 않음 |
| 일반 직무 안내 | 특정 기업이 아닌 직무 일반 서술 (`data/report-gm/biz-editorial.v1.json`) |
| 분석 제안 | 응답을 읽고 결과지가 권하는 것 |

줄 목록에서는 줄 오른쪽 21mm 칸에 8.5pt 회색으로, 표·장면에서는 쪽 아래 한 줄로 적는다.

## 6. 문장

- 짧게, 현장 말로. 한 문장에 한 가지.
- 쓰지 않는 말(검사가 센다): ‘이 보고서는’ · ‘보여줍니다’ · ‘연결될 수 있습니다’ · ‘중요합니다’ · ‘확인해볼 필요’ · ‘역량을 강화’ · ‘성장 방향’ · ‘핵심 포인트’ · ‘강점이 드러납니다’ · 영어 소제목(Evidence·Insight·Summary).
- 조사는 `withJosa` 로 붙인다(학생 문장·영역 이름 뒤에 글자로 박지 않는다).
- 쪽마다 네 물음 가운데 하나 이상에 답한다: 어느 응답에서 나왔나 · 목표 직무의 어떤 실제 일과 이어지나 · 바로 쓸 결과물은 무엇인가 · 아직 무엇을 모르나.

## 7. 쪽 유형 (편집 패턴)

| 유형 | 쓰는 쪽 |
|---|---|
| 표지(결론을 표지에) | 1 |
| 한 쪽 진단 + 확인/모름 2단 + 목표·첫 행동 띠 | 한 문장 진단 |
| 관심×깊이 행렬(묻지 않음은 빗금 칸) | 열두 영역 지도 |
| 강조 상자 하나(첫 행동) | 목표 직무와 첫 행동 |
| 판단 막대 행렬 | 여덟 판단 |
| 일의 흐름 8단계 + 3단 | 영역 상세 |
| 장면 타임라인(장면·정하는 것·남기는 것) | 목표 직무의 한 주기 |
| 세 장면 / 두 직무 나란히 / 세 직무 비교표 / 대비 2단 | 직무 현장 |
| 주장→문제→결정→결과물→비교→쓰인 곳 사슬 | 증거 |
| 빈 칸 양식 + 검토 질문 | 포트폴리오 |
| 판단별 질문 ↔ 재료 표 | 면접 |
| 3열 시간 보드 | 90일 |

## 8. 사례마다 다른 줄거리

| | RICH (근거 많음) | POOR (근거 거의 없음) | CONTRA (경험과 목표 불일치) |
|---|---|---|---|
| 진단 | 기준을 직접 정한 두 영역 | 관심은 분명, 해 본 일은 적음 | 해 본 일과 가려는 일이 다른 곳 |
| 영역 상세 쪽 | 3 | 0 (근거 없음 → 뺌) | 0 (고른 문장 없음 → 뺌) |
| 직무 대비 쪽 | 경영기획 vs 재무·회계 | 마케팅 vs 영업·사업개발 | 인사 vs 총무·경영지원 |
| 면접 | 확인된 판단 3 + 빈 판단 1 | 모두 ‘아직 장면 없음’ + 만들 결과물 | 빈 판단 + 실행 과제 |
| 쪽 수 | 22 | 18 | 19 |
