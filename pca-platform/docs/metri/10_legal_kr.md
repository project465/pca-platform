# 법적 범위 — 한국 · 터키 · 카자흐스탄

> **이 문서는 법률 자문이 아니다.** 아래는 공개 자료로 확인한 내용이고,
> 사업을 확정하기 전에 **노무사 또는 행정사 확인을 반드시 거친다.**
> 법제처 원문(law.go.kr)은 확인 시점에 접근이 막혀 2차 출처로 확인했다.

## 0. 결론 한 줄

**지금 보유한 직업정보제공사업 신고(J1700020220007호)만으로 1차 MVP 매출은 전부 가능하다.
막히는 것은 기업 채널의 "인재 추천 + 채용 성공 수수료" 하나뿐이다.**

---

## 1. 두 사업은 다른 제도다

| | 직업정보제공사업 | 유료직업소개사업 |
|---|---|---|
| 절차 | **신고** (고용노동부) | **등록** (국내는 시·군·구) |
| 하는 일 | 신문·간행물·방송·**컴퓨터통신 등으로 구인·구직 정보를 제공** | 구인·구직 신청을 받아 **고용계약 성립을 알선** |
| 우리 상태 | **보유** — J1700020220007호 | 없음 |

**가르는 기준은 "알선(중개)을 하느냐"다.**
정보를 띄우고 구직자가 스스로 지원하면 정보제공,
우리가 사이에 들어가 붙여주면 소개다.

### 유료직업소개사업 등록 요건 (국내)

| 항목 | 내용 |
|---|---|
| 등록처 | 특별자치도·시·군·구 |
| 법인 자본금 | 납입자본금 **5천만 원 이상** |
| 인력 | 임원 **2명 이상**이 직업상담사 1·2급 또는 직업소개·직업상담 등 **관련 업무 2년 이상 경력** |
| 시설 | 전용면적 **10㎡ 이상** 독립 사무실 |
| 요금 | 고용노동부 장관이 결정·고시한 요금 외 금품 수취 금지. **고급·전문인력은 예외로 당사자 간 정한 요금을 구인자에게서 받을 수 있다** |

## 2. 직업정보제공사업자가 하면 안 되는 것 (시행령 제28조 준수사항)

**이게 설계에 직접 걸린다.**

| 금지·의무 | 우리 설계에서 걸리는 곳 |
|---|---|
| **구직자의 이력서 발송을 대행하지 않는다** | GRAD 트랙의 "서류" 기능. 첨삭은 되고 **대신 보내주는 것은 안 된다** |
| **구직자에게 취업추천서를 발부하지 않는다** | 기업 채널의 "추천" 이라는 말 자체를 쓰지 않는다 |
| 구인자 신원(업체명·사업자등록증 등) 확인 불가한 구인광고를 게재하지 않는다 | JD 파이프라인에 기업 식별 검증 단계가 필요하다 |
| 구인·구직 광고에 **구인·구직자의 연락처를 기재**하고, **직업정보제공사업자의 연락처는 기재하지 않는다** | 공고 화면에서 **우리를 거치게 하면 안 된다.** 기업 연락처·원문 링크로 바로 보낸다 |
| 최저임금 미달·성매매업소 구인광고 게재 금지, 체불사업주는 표시 | 수집한 공고를 거르는 필터가 필요하다 |

## 3. 그래서 우리 설계를 이렇게 고친다

### 3-1. 할 수 있는 것 — 지금 신고만으로

| 기능 | 근거 |
|---|---|
| 진단·채점·결과지 | 직업안정법 규율 대상이 아니다 |
| 학과 익명 집계 리포트 | 위와 같다 |
| Skill Gap · 교육 처방 | 위와 같다 |
| **공고를 보여주고 학생이 직접 지원** | 직업정보제공 그 자체 |
| 공고에서 뽑은 요구 역량 통계 | 정보 가공 |
| 이력서·면접 **준비 도움** (첨삭·연습) | 발송 대행이 아니다 |

**1차 MVP 매출(학과 B2B + 개인 B2C)은 전부 이 안에 있다.**

### 3-2. 못 하는 것 — 등록 없이는

| 하려던 것 | 왜 막히나 | 등록 전 대체안 |
|---|---|---|
| 기업이 학생을 검색 → 열람 요청 → 우리가 연결 | **알선에 해당할 소지가 크다** | 방향을 뒤집는다. 기업은 **공고를 올리고**, 학생이 자기 결과지에서 보고 **직접 지원**한다 |
| **채용 성공 수수료 150만 원/명** | 소개요금이다. 등록 + 요금 고시 적용 | 등록 전에는 **뺀다.** 구독·노출·콘텐츠로 받는다 |
| 기업에 인재 "추천" | 취업추천서 발부 금지에 걸린다 | "추천" 이라는 말을 쓰지 않는다 |
| 이력서 대신 보내주기 | 발송 대행 금지 | 학생이 내려받아 **본인이** 보낸다 |

### 3-3. 기업 채널을 다시 짠다

```
[등록 전 — 지금]                        [등록 후 — 선택]
기업이 공고를 올린다                     기업이 인재를 검색한다
   ↓                                        ↓
그 공고가 적합한 학생의                   학생 동의 후 연결
결과지에 노출된다                           ↓
   ↓                                     채용 성공 수수료
학생이 기업에 직접 지원
   ↓
기업이 받는 것 = 노출 + 익명 집계 리포트
                + 직무 콘텐츠
```

**등록 전 기업 과금은 "매칭"이 아니라 "노출과 데이터"로 받는다.**

## 4. 등록을 추가할지 판단

업계 표준은 **둘 다 갖는 것**이다. 리멤버는 직업정보제공사업 신고(서울강남 제2019-11호)와
유료직업소개사업 등록(2020-3220237-14-5-00003)을 **함께** 보유하고 있다.

| | 등록 안 함 | 등록 함 |
|---|---|---|
| 준비 | 없음 | 자본금 5천만·임원 2명 자격·사무실 10㎡ |
| 기업 매출 | 구독·노출·콘텐츠만 | + 채용 성공 수수료 |
| 리스크 | 없음 | 요금 고시 규제를 받는다 |

**권고 — 1차에는 등록하지 않는다.** 기업 채널 자체가 2차 이후이고,
인재풀에 학생 1,000명이 차기 전에는 팔 것이 없다.
**기업 매출을 실제로 붙일 때 등록을 같이 준비한다.**

단, 고급·전문인력 예외 조항이 있어 **공학 석·박사 채용은 요금 규제가 느슨하다.**
JOBINDUSTRY(STEM 석·박사) 브랜드와 묶으면 등록의 값어치가 커진다. 그때 다시 계산한다.

---

## 5. 화면에 반영할 것

- [ ] 푸터에 **직업정보제공사업 신고번호 J1700020220007호** 를 표기한다
- [ ] 공고 카드에서 지원 버튼은 **기업 원문 링크**로 나간다. 우리 폼으로 받지 않는다
- [ ] "추천 기업" 문구를 **"적합도가 높은 기업"** 으로 바꾼다 (추천서 발부 금지 조항 회피)
- [ ] 이력서 기능은 **작성·첨삭까지**. "보내기" 버튼을 만들지 않는다
- [ ] 수집 공고에 최저임금 미달·신원 미확인 필터를 건다

## 6. 터키 — İŞKUR özel istihdam bürosu

**한국보다 기준이 빡빡하다.** 면제 조건이 좁다.

İŞKUR 이 밝힌 **면제 요건**은 이렇다.

> 검색엔진이나 분류광고 형태이면서, **지원 버튼·회원제·어떠한 등록 절차도 없이**
> 개인이 채용 공고의 연락처에 자유롭게 접근할 수 있게 하는 인터넷 사이트는
> İŞKUR 의 허가를 받을 필요가 없다.

**METRI 는 이 면제에 안 들어간다.** 우리는 로그인이 있고, 결과지 안에서 공고를 보여준다.
회원제가 있는 순간 면제가 깨진다.

| 항목 | 내용 |
|---|---|
| 근거법 | 4904 sayılı Türkiye İş Kurumu Kanunu 제17조 |
| 허가 | İŞKUR 시도 지국(il müdürlüğü) 신청, 30일 내 심사 |
| **담보(teminat)** | **2026년 660,600 TL** (임시근로 권한은 6,606,000 TL) |
| 비용(masraf) | 2026년 43,841.19 TL, 갱신 25,981.45 TL |
| 자격 | 대표자 4년제 학사 학위, 파산·화의 없음 증명 |
| 무허가 제재 | 4904호 제20조 행정 제재. 별도로 취업허가 없는 외국인 알선은 1인당 5,000 TL 과태료 |

**판단** — 터키는 **공고 기능을 켜지 않고 진단·리포트만으로 출시한다.**
기업 채널이 없어졌으므로 알선 요소는 이미 없고, 남는 것은 "회원제 화면 안에서 공고를 보여주는가" 하나다.
그것만 빼면 허가 없이 운영된다. 공고 대신 **집계 통계**(이 직무 공고 412건에서 뽑은 요구 역량)를 쓴다 —
통계는 구인정보 제공이 아니라 노동시장 정보다.

## 7. 카자흐스탄 — ЧАЗ (частное агентство занятости)

**규제가 지금 바뀌고 있다.** 확정된 자리에 들어가지 말고 지켜본다.

| 항목 | 내용 |
|---|---|
| 근거법 | 「Халықты жұмыспен қамту туралы」 (고용에 관한 법, Z1600000482) |
| ЧАЗ 정의 | **노동 중개 서비스(услуги трудового посредничества)를 제공**하고 법령이 정한 절차로 **등록된** 자연인·법인 |
| 현재 | 등록부(реестр) 운영. **국가 통제와 면허제(лицензирование) 도입이 추진 중** |
| 국외 알선 | 카자흐 국민의 해외 취업 알선은 별도 규정. 60여 개 업체가 등록돼 있다 |
| 공공 플랫폼 | **Enbek.kz** (전자노동거래소)가 국가 채널이다 |

**판단** — 면허제가 도입되는 중이라 **기업·알선 쪽은 아예 건드리지 않는다.**
진단·리포트·학과 집계만으로 출시하고, Enbek.kz 와의 연계는 등록 요건이 확정된 뒤에 본다.

## 8. 세 나라를 한 장으로

| | 한국 | 터키 | 카자흐스탄 |
|---|---|---|---|
| 보유 자격 | **직업정보제공사업 신고** J1700020220007호 | 없음 | 없음 |
| 진단·리포트·학과 집계 | ✅ | ✅ | ✅ |
| 공고를 화면에 보여주기 | ✅ 신고 범위 | ❌ 회원제라 면제 불가 | ⚠️ 확인 필요 |
| 공고 **집계 통계**만 보여주기 | ✅ | ✅ | ✅ |
| 기업에 인재 추천 | ❌ 등록 필요 | ❌ 허가 필요 | ❌ 면허 도입 중 |

**코드에 미치는 것 하나** — `jd_sources` 에 이미 나라별 설정이 있다.
여기에 **나라별 공고 노출 스위치**를 둔다. 한국은 개별 공고까지, 터키·카자흐스탄은 집계 통계까지.
화면을 나라마다 새로 만들지 않는다.
