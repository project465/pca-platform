# 19. 학년 사다리 — 전략 문서를 플랫폼 구조로

2026-09-14. 「이공계 중·고등학생 사업전략」 인수인계 자료를 받아, **무엇이
이미 있고 · 무엇이 구조만 있으면 되고 · 무엇은 데이터가 없어 못 만드는지**
를 갈라 적는다.

## 0. 먼저 확인한 것 — 첫 MVP 는 이미 만들어져 있다

전략 문서가 첫 출시로 꼽은 것은 **"고1 이공계 전공·선택과목 진단"** 이고,
핵심 흐름을 이렇게 적었다.

> 희망직업 → 전공 → 대학 → 관련 고교과목 → 현재 선택과목 → 추가 확인사항

커리어메트리 플러스가 지금 하는 일이 정확히 그것이다. 방향만 반대다 —
현장 직무에서 **거꾸로** 내려와 고교 과목에 닿는다(`16_career_chain.md`).
문서의 광고 문구 *"과목을 선택하고 학과를 정하지 마세요. 학과를 정하고
과목을 선택하세요"* 와 같은 주장이고, 그것을 48줄기로 따질 수 있게 해 둔
것이 차이다.

| 전략 문서가 요구한 것 | 지금 상태 |
|---|---|
| 진단 문항 30~50개 | **115문항** (8계열 × 14 + 성실도 3) |
| 점수구조·추천 로직 | 있다. 가중치는 전부 테이블 |
| 결과지 10~20페이지 목차 | 있다. 8절 + 무료/유료 경계 |
| 대학·학과·권장과목 데이터 구조 | 있다. 74과목 · 서울대 권장 대조 |
| 랜딩페이지 카피 | 있다. `sites/metri-plus/` |
| 베타테스트 방법 | `18_plus_validation.md` |

**그래서 이 문서가 하는 일은 "만들자" 가 아니라 "사다리를 얹자" 다.**

## 1. 사다리를 어떻게 넣었나 — 학년은 상품의 속성이다

학년마다 코드를 새로 파지 않는다. 검사지가 늘 때 범위를 명시하라는
설계 원칙 8 과 같은 이유다.

```
무엇을 푸는가   products.track_code   → HS_V1 · UNIV_V1
누구에게 파는가 products.grade_band   → m2 · m3 · h1 · h2 · h3 · any
얼마나 열리는가 products.duration_days → NULL(단품) · 365(PASS)
```

**PASS 는 좌석이 아니라 기간이다.** 좌석(`seats`)은 쓰면 없어지고 PASS
(`entitlements`)는 날짜가 지나면 없어진다. 사라지는 방식이 다르면 테이블이
다르다. 한 테이블에 섞으면 "1년 PASS 하나로 115문항을 몇 번 풀 수 있는가"
에 답할 수 없다 — 답은 회차마다 발급하는 좌석 수가 정하고, PASS 는 정하지
않는다.

### PASS 로 결과지가 열리는 규칙

경계는 여전히 한 함수에만 있다(설계 원칙 10). 순서에 한 단이 늘었다.

```
1. report_grants  — 무료로 보고 나중에 결제
2. 계약 좌석      — 학교가 산 것
3. PASS           ← 새로 들어온 자리
4. 상품의 report_level
5. free
```

PASS 판정에서 두 가지를 일부러 그렇게 했다.

**기준 시각은 지금이 아니라 응시 시각이다.** 지금 시각으로 보면 만료된 날
결과지가 닫힌다. 돈을 낸 기간에 받은 문서를 잃는 셈이고, 그건 기간제 상품이
파는 것이 아니다. 기간 동안 판 것은 **그 기간에 검사할 권리**이지 그 기간에만
읽을 권리가 아니다.

**시작일은 보지 않는다.** 무료로 먼저 풀어 보고 PASS 를 산 학부모의 결과지가
안 열리면, 방금 79만원을 낸 사람이 자기 아이 문서를 못 보게 된다. 만료
이후에 새로 본 응시는 끝날 조건에서 걸리므로 새는 곳은 없다.

> 이 규칙은 처음에 "응시 시점에 살아 있던 PASS" 로 짰다가, `metri:tier` 의
> 6절이 바로 잡아냈다. 검사를 먼저 쓴 덕에 79만원짜리 사고를 코드에서 막았다.

### 이어 붙이기

이미 살아 있는 PASS 가 있으면 **그 끝에서 이어 붙인다.** 지금부터 1년으로
덮어쓰면 남아 있던 기간이 사라져 산 것을 뺏는 셈이 된다.

## 2. 상품표 — 전부 꺼진 채로 들어갔다

전략 문서의 학년별 가격을 `products` 에 넣되 **전부 `active = false`** 다.

| 코드 | 학년 | 가설가 | 검사지 | 상태 |
|---|---|---:|---|---|
| `M2_DISCOVERY` | 중2 | 69,000 | 없음 | 꺼짐 |
| `M3_ROADMAP` | 중3 | 199,000 | 없음 | 꺼짐 |
| `H1_REPORT` | 고1 | 99,000 | `HS` | 꺼짐 |
| `H1_PASS` | 고1 | 790,000 / 365일 | `HS` | 꺼짐 |
| `H2_ADMISSION` | 고2 | 99,000 | 없음 | 꺼짐 |
| `H3_STRATEGY` | 고3 | 299,000 | 없음 | 꺼짐 |
| `HS_FREE` | — | 0 | `HS` | **켜짐** |
| `HS_UPGRADE` | — | 19,000 | `HS` | **켜짐** |

**꺼 둔 이유는 값이 가설이기 때문이다.** 전략 문서 스스로 "확정가가 아니라
MVP 시장검증용 가설" 이라고 적었고, 확정되지 않은 값으로 결제를 받을 수는
없다. 값이 정해진 줄만 켠다.

### 지금 값과 전략 값이 어긋난다 — 결정이 필요하다

| | 지금 파는 값 | 전략 문서 |
|---|---:|---:|
| 고1 진단(저가) | **19,000** | 39,000 ~ 69,000 |
| 고1 상세 리포트 | 위와 같음 | 99,000 |

19,000원은 "규준이 없으니 지표를 무료로 열고 사슬만 판다" 는 판단에서 나온
값이다(`17_plus_product_line.md`). 전략 문서의 39,000~99,000원은 컨설팅까지
묶은 값에 가깝다. **둘 중 하나를 고르는 것이 아니라 무엇을 묶어 파는지를
정하면 값이 따라온다.**

- 19,000원 — 사슬 + 과목 처방만. 사람이 붙지 않는다
- 69,000원 — 위 + 학부모용 해설 리포트. 여전히 사람이 안 붙는다
- 299,000원 — 위 + 1:1 상담 60분. **여기서부터 사람이 붙는다**

사람이 붙는 순간 원가 구조도 법적 성격도 달라진다(4장).

## 3. 무엇이 없어서 못 만드는가

### 3-1. 중2·중3 — 문항이 없다

`HS_V1` 115문항은 고등학생의 하루에서 나온 장면으로 썼다. 중2에게 그대로
주면 학년이 달라 문장이 안 맞는 것이 아니라, **결정이 다르다.**

| 학년 | 답해야 하는 질문 | 결과지가 내야 하는 것 |
|---|---|---|
| 중2 | 이과가 맞나 | 계열 방향 + 해 볼 활동 |
| 중3 | 어느 고등학교 | **고교 유형 비교** (일반계 / 과학고 / 마이스터고) |
| 고1 | 무슨 과목 | 과목 신청서 ← **지금 되는 것** |

중3 결과지의 뒷부분(어느 고등학교를 볼 것인가)은 이미 `sites/metri-plus/`
의 "아직 없는 것" 에 적혀 있다. 만들려면 **고교 유형별 교육과정·전형 자료**
가 새로 필요하고, 그건 과목표와 다른 자산이다.

### 3-2. 고2·고3 — 데이터가 통째로 없다

전략 문서의 고2 `STEM Admission Map`, 고3 `Admission Simulation` 은
**대학·학과·전형 데이터와 합격선 자료** 위에 선다. 지금 이 저장소에는
그 데이터가 한 줄도 없다.

**그리고 이건 "나중에 넣으면 되는 데이터" 가 아니다.**

- 합격 가능성 시뮬레이션이 틀리면 학생이 지원을 잘못 한다. 과목 처방이
  틀린 것과 무게가 다르다
- 배치표·합격선은 매년 바뀌고, 출처가 공개되지 않은 것이 많다
- `18_plus_validation.md` 의 중단 기준을 그대로 적용하면, **예측 정확도를
  검증하지 못한 합격 시뮬레이션은 팔 수 없다**

> 권고: 고2·고3 은 사다리에 자리만 잡아 두고, 데이터 확보 계획이 서기
> 전에는 만들지 않는다. 상품표에 꺼진 채로 있는 이유다.

### 3-3. 무료 3분 진단 — 만들 수 있지만 권하지 않는다

전략 문서의 퍼널 2단계는 "무료 3분 이공계 전공진단" 이다. 지금 무료 구간은
**115문항 15분**이다.

3분짜리를 따로 만들면 문항이 12~15개가 되는데, 그 길이로는 8계열을 가를 수
없다(계열당 2문항이면 신뢰도 α 가 .5 도 안 나온다). 그러면 결과가 부정확한
채로 "무료 진단 결과" 라는 이름을 달게 되고, 그건 `18_plus_validation.md`
가 막으려는 것이다.

**대신 권하는 것:** 3분 도구를 *검사*가 아니라 **소개 사이트의 질문 위젯**
으로 만든다. 점수를 내지 않고 "당신이 고민하는 것은 이것입니다 → 115문항
무료 진단으로 갑니다" 로 보낸다. 채점하지 않으면 검증 의무도 없다.

## 4. 법과 표현에서 먼저 확인할 것

전략 문서에 **1:1 컨설팅**과 **연간 PASS** 가 들어 있다. 소프트웨어가
아니라 사람이 붙는 상품이라 성격이 다르다.

**① 유료 상담을 반복 판매하면 학원법이 걸릴 수 있다.**
「학원의 설립·운영 및 과외교습에 관한 법률」상 진학상담·입시컨설팅이
교습에 해당하는지, 교육청 등록 대상인지 **행정사·변호사 확인이 먼저다.**
이건 우리가 판단할 수 있는 문제가 아니다. `10_legal_kr.md` 에 직업정보
제공사업 범위를 정리해 둔 것처럼, 여기도 근거를 받아 적어야 한다.

**② PASS 는 계속거래다.** 1년짜리 선불 상품은 방문판매법상 계속거래에
해당할 소지가 크고, 그러면 **중도해지권과 잔여기간 정산 환불** 의무가 붙는다.
지금 환불 정책(`refund`)은 단품 기준으로만 적혀 있다. PASS 를 켜기 전에
정산식을 적어야 한다.

**③ 전략 문서의 주의사항은 이미 코드가 지키고 있다.**

| 전략 문서의 주의 | 지금 |
|---|---|
| "이 과목 없으면 지원 불가" 로 일반화하지 않는다 | 계열 요구와 대학 권장을 **근거가 다르므로 섞지 않는다**고 적어 둔다 |
| 대학별 반영·권장은 매년 확인 | `18_plus_validation.md` 4-3. 연 1회 + 제도 발표 때마다 |
| 심리검사로 과장하지 않는다 | 규준 생기기 전 **"상위 몇 %" 금지** |

## 5. 브랜드 — STEM 이름을 쓸 것인가

전략 문서는 `STEM Discovery / Roadmap / PASS / Index` 라는 이름 줄을 쓴다.
지금 쓰는 이름은 **커리어메트리 플러스**다.

설계 원칙 9 는 커리어메트리와 커리어메트리 플러스가 서로를 설명하지 않는다는 것이지,
커리어메트리 플러스 안에서 학년별 상품 이름을 갖지 말라는 것이 아니다. 그래서
**커리어메트리 플러스를 브랜드로 두고 그 안에 학년 상품 이름을 두는 쪽**을 권한다.

```
커리어메트리 플러스            ← 브랜드 (딥네이비 + 앰버)
 ├ 계열 찾기   (중2)
 ├ 고교 고르기 (중3)
 ├ 과목 정하기 (고1)   ← 지금 파는 것
 └ …
```

STEM 을 전면에 쓰면 이름이 하나 더 늘고, 학부모에게 영문 약어는 설명이
한 단계 더 필요하다. 다만 **이건 취향이 아니라 영업에서 답이 나오는
문제**라, 학교 설명회에서 어느 쪽이 덜 설명해도 되는지 보고 정하면 된다.

## 6. 순서 — 무엇부터

전략 문서의 우선순위를 **지금 가진 것** 기준으로 다시 놓으면 이렇다.

| | 무엇 | 왜 지금 |
|---|---|---|
| 1 | **담당자 연락처 채우기** | 배포 자료가 인쇄돼 있는데 연락할 곳이 없다 |
| 2 | **학교 한 곳 베타** (고1 한 학급) | 값도 규준도 여기서 나온다. 계약이라 PG 가 필요 없다 |
| 3 | 사슬 48줄기 현직자 검수 | 유료로 파는 부분인데 검수가 안 됐다 |
| 4 | 고1 값 확정 → `H1_REPORT` 켜기 | 2번에서 나온 반응으로 정한다 |
| 5 | PASS 환불 정산식 + 법 확인 → `H1_PASS` 켜기 | 4장 ②가 먼저다 |
| 6 | 중3 확장 (고교 유형 자료) | 문항과 자료를 새로 만든다 |
| 7 | 고2·고3 | 데이터 확보 계획이 선 다음 |

**1·2번은 오늘 할 수 있고 나머지는 순서가 있다.** 전략 문서도 같은 말을
한다 — "처음부터 중2~고3 전 상품을 만들지 않는다".

## 7. 확인하는 방법

```bash
npm run metri:tier
```

7절로 늘었다. 6절이 PASS 를 본다.

- PASS 가 **좌석을 주지 않는가** (문항을 무한히 풀 수 없다)
- 무료로 먼저 풀고 PASS 를 사도 그 결과지가 열리는가
- 기간 밖에서 본 응시는 열리지 않는가
- **기간이 끝나도 그때 본 결과지는 계속 열리는가**
