# L. BASIC · STANDARD · PRO 재정의

가격은 그대로 둔다. BASIC 무료 · STANDARD 14,900원 · PRO 21,900원.
바꾸는 것은 **무엇을 받아서 어디까지 판단하는가**다. 문항 수와 쪽수로
가르지 않는다.

## 1. 가르는 기준 다섯

등급마다 다섯 가지를 적는다.

1. 어떤 질문을 해결하는가
2. 어떤 데이터를 받는가
3. 어떤 판단까지 가능한가
4. 어떤 결과는 보여 주면 안 되는가
5. 아래 등급보다 무엇이 실제로 더 값있는가

---

## 2. BASIC (무료)

| | |
|---|---|
| **해결하는 질문** | 내 수업과 프로젝트 경험이 **어느 기술영역으로 읽히는가** |
| **받는 데이터** | 선별 36문항(영역 12 × 관심 1 + 경험 1, 역할 선호 6, 환경 선호 6). 걸리는 시간 10분에서 12분 |
| **가능한 판단** | 영역 묶음 넷(Z1~Z4) · 영역마다 확인된 판단 축의 **개수** · 지금 할 일 한 줄 |
| **보여 주지 않는 것** | 영역별 비어 있는 축의 **이름과 채우는 조건** · 직무 비교 · 조직별 차이 · 경험 번역 · 90일과 365일 |
| **아래보다** | 아래가 없다 |

**무료의 설계 의도**를 적어 둔다. 지금 BASIC 은 20분에서 30분을 받고
관심 차례를 돌려준다. 바뀐 BASIC 은 10분을 받고 **영역 묶음과 비어 있는
축의 개수**를 돌려준다. 받는 시간이 줄고 돌려주는 것이 분명해진다.

그리고 **무료에서 경험 입력을 요구하지 않는다.** 선별 36문항만으로 묶음이
나오게 설계한다. 지금은 경험 입력을 건너뛰면 결과의 절반이 비는데, 무료
응시자는 대부분 건너뛴다.

---

## 3. STANDARD (14,900원)

| | |
|---|---|
| **해결하는 질문** | 후보 영역 둘셋 가운데 **어디로 갈 것인가**, 그리고 **무엇이 비어 있는가** |
| **받는 데이터** | 선별 36 + **심화 24**(고른 3영역 × 현장직무역량 8축) + 구조화된 경험 입력(판단 체크리스트 · 산출물 체크 · 검증 선택). 추가로 15분에서 20분 |
| **가능한 판단** | 영역별 확인·부분·미확인 **축 이름** · 비어 있는 축을 채우는 조건 · 공고 직무명 둘셋의 차이와 가르는 질문 · 조직환경별 성과 이름의 차이 · 30일과 90일 |
| **보여 주지 않는 것** | 연구 경험의 열 단계 번역 · 지원서 문장 초안 · 365일 · 목표 직무 요구 대조 |
| **아래보다** | 개수에서 **이름**으로 바뀐다. `확인된 축 4 / 8` 이 `비어 있는 것은 공차 배분과 결과 검증이고, 채우는 조건은 이것` 으로 바뀐다 |

---

## 4. PRO (21,900원)

| | |
|---|---|
| **해결하는 질문** | 내 연구와 프로젝트 경험을 **직무 언어로 옮겨 지원 재료로 만들려면** 무엇을 어떻게 적어야 하는가 |
| **받는 데이터** | STANDARD + **연구 번역 12문항**(열 단계 + 영역 태깅) + 목표 직무·산업 입력 + 조직환경 선택 |
| **가능한 판단** | 연구 경험을 영역 둘셋의 판단 축으로 번역한 표 · 그 번역에서 나온 **지원서 문장 초안** · 목표 직무의 요구와 내 근거의 대조표 · 365일 · `근거 한 쪽` PDF |
| **보여 주지 않는 것** | 합격 가능성 · 기업 추천 · 상위 몇 퍼센트 · 나라별 임금과 비자 |
| **아래보다** | **번역이 붙는다.** STANDARD 는 비어 있는 것을 알려 주고, PRO 는 이미 가진 것을 꺼내 쓸 문장으로 만들어 준다 |

## 5. 이 분할이 맞는지 검증

그대로 답으로 쓰지 않고 반증 조건을 적는다.

| 가정 | 맞는지 보는 방법 | 틀리면 |
|---|---|---|
| 무료 10분이면 끝까지 답한다 | 파일럿에서 선별 완료율 | 36을 24로 줄이고 영역 경험 문항을 뺀다 |
| 개수에서 이름으로 바뀌는 것이 14,900원의 값이다 | 파일럿의 지불 의향 문항과 실제 전환 | STANDARD 에 목표 직무 대조를 내린다 |
| 번역이 21,900원의 값이다 | 대학원생 참가자의 가치 차이 문항 | PRO 에 모의 면접 질문 생성을 더한다 |
| 심화 3영역이면 충분하다 | 네 번째 영역을 더 연 비율 | 기본을 4영역으로 올린다 |
| 학부생도 번역에서 값을 본다 | 학부 참가자의 PRO 가치 문항 | 학부는 캡스톤 번역으로 문면을 갈라 쓴다 |

**등급이 서로 구별되는지를 검사로 둔다.** 지금 `tiersDistinct()` 가 받는
것의 겹침을 세는데, 새 기준에서는 **판단의 종류**를 센다. 아래 등급과
같은 종류의 판단만 더해지면 실패로 떨어뜨린다.

| 등급 | 판단의 종류 |
|---|---|
| BASIC | 묶음과 개수 |
| STANDARD | 이름과 조건, 직무 사이의 차이 |
| PRO | 번역과 문장, 목표와의 대조 |

## 6. 무료에서 유료로 넘어가는 자리

유료를 권하는 문장을 결과지 안에 두되, **무료 결과를 깎아서 권하지
않는다.** 비어 있는 축의 **개수**를 보여 준 다음에 이렇게 적는다.

> 비어 있는 축이 넷입니다. 그 축의 이름과 각각을 채우는 조건은 견주기
> 등급에서 엽니다.

개수를 먼저 주는 것이 요점이다. 개수는 그 자체로 쓸모가 있고, 이름과
조건은 다음 단계의 값이다.
