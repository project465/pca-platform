# R27 DESIGN CONTRACT — 레퍼런스에서 재어 온 값

재는 그림은 `docs/metri/shots/reference/reference-home-desktop.png`
(1448×1086) 하나다. 같은 시안의 807×610 판보다 재는 오차가 작다
(2.51 → 1.42).

**배율.** 데스크톱 판의 창 그림이 1012 화소이고 그것을 1440 CSS 로 본다
(`DS = 1.4229`). 손전화 판의 화면이 345 화소이고 그것을 390 CSS 로 본다
(`MS = 1.1304`).

**잉크 높이로 재지 않는다.** 올려 그린 그림은 가장자리가 번져 글자가 한
단 커 보인다. 글자는 **가로 잉크 ÷ 그 글의 진폭(em)** 으로만 잰다.

## A. 가운뎃점의 진폭은 0.34em 이다

`r26_ref.py` 의 `adv()` 가 `·` 를 1.0em 으로 잡고 있었다. 그 값으로 재면
가운뎃점이 든 줄이 통째로 어긋난다. 같은 자리의 두 글로 풀면 값이 나온다.

```
시험·계측          잉크 66   → 4 + m − 0.1
구조·내구 해석      잉크 101  → 6 + m + 0.25 − 0.1
101 / 66 = (6.15 + m) / (3.9 + m)   →   m = 0.343
```

그래서 **0.34** 로 고쳤다. 고친 뒤 세 타일의 제목이 22.1 · 21.8 · 22.1 로
모이고, 고치기 전에는 45.0 · 21.6 · 5.8 로 흩어져 있었다.
