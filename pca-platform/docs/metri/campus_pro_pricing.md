# 대학·기관용 PRO 진단 가격표 (2026-10-21 사업주 확정)

대학·기관은 **PRO 진단 단일 상품**으로 운영하고, 계약 인원에 따라 1인당 가격을 차등 적용한다.
대학·기관 계약용 정가이며 **부가가치세 별도**다.

| 계약 인원 | 1인당 가격 |
|---|---|
| 1~49명 | 20,000원 |
| 50~100명 | 18,000원 |
| 101~299명 | 16,000원 |
| 300~499명 | 15,000원 |
| 500~999명 | 14,000원 |
| 1,000명 이상 | 12,000원 |

## 모든 인원 구간에 똑같이 들어가는 것

- PRO 전체 진단
- 학생별 심층 분석과 맞춤형 PDF 결과보고서
- 전공·산업·직무 연계 분석
- 개인별 역량과 보완 영역 분석
- 진로·취업 실행 전략
- 기관별 참여 현황과 기본 집계

## 덧붙는 조건 (제안서 문구 그대로)

- 계약 인원과 운영 기간에 따라 단가 조정 가능
- 대학 전용 사이트 구축, 추가 개발, 운영 지원은 별도 견적
- 최소 계약금액과 부가가치세 적용 여부는 최종 견적서에 적는다

## 문항 수를 가격표에 적지 않는 까닭

받은 표에는 `PRO 진단(92문항)` 이라고 적혀 있었다. 92 는 옛 검사(ME_V2)의 PRO 문항
수다. 지금 학교 경로가 여는 검사(ME_V3 계열)는 **전공마다 문항 수가 다르다**. 전주대
자리(컴퓨터·소프트웨어 Core) 학부 PRO 가 108문항(심화 영역이 넷 열리면 121), 약 31~34분이다
(`CORE=CS_CORE_V1 npm run v3:length`). 그래서 대외 자료에는 `PRO 전체 진단` 으로 적고 문항
수는 그 기관 전공 기준으로 각주에 단다.

## 이 표가 코드에 들어가지 않는 까닭

학교 계약 응시는 학생이 결제하지 않고 서버가 PRO 로 연다(`openAttempt`). 그래서 이 가격은
`products` 표가 아니라 **계약(견적서)** 에 들어가는 값이다. 개인 B2C 가격(무료 · 14,900 ·
21,900 · AI 취업비서 4,900 / 39,000)은 따로이고 `products` 가 정본이다.
