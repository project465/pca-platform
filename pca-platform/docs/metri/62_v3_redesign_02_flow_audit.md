# 지금 검사가 실제로 어떤 경험인가 · 화면 기준 감사

날짜 2026-10-08 · 대상 `ME_V3_ASSESSMENT_UI_V1.1` · **구현 전 감사**

문항 하나씩이 아니다. **응시자가 앉아서 지나는 순서**로 본다. 좋은 문항을
모아 놓아도 순서가 틀리면 검사는 설문으로 읽힌다.

## 2 · 단계마다

### 2-1 · 기본 정보 (1화면)

| 물음 | 답 |
| --- | --- |
| 왜 필요한가 | 문항 장면과 분기를 정한다 |
| 사용자가 알아야 하는 것 | 단계가 평가 기준을 바꾸지 않는다 |
| 다음에 어떻게 쓰이는가 | `scene_by_axis` 가 문면의 장면을 바꾼다 |
| 진단 가치 | 있다 |
| 설문 같은가 | 아니다 |
| 전문성 | 해당 없음 |
| 산업·직무로 이어지는가 | 아니다 |

**남는 문제.** 여기서 묻지 않는 것이 둘 있다. 지금 상태(재학·구직·재직)와
**관심 산업**이다. 둘 다 뒤에 쓸 장면을 정하는 값인데 검사 끝에 가서야
묻거나(목표 3문항) 아예 묻지 않는다.

### 2-2 · 영역 격자 (12화면 · 36문항)

| 물음 | 답 |
| --- | --- |
| 왜 필요한가 | 어느 영역을 깊게 볼지 고르는 선별이다 |
| 사용자가 알아야 하는 것 | 여기는 아직 재는 자리가 아니라는 것 |
| 다음에 어떻게 쓰이는가 | 상위 2~4영역이 선별 심화와 경험 심화로 간다 |
| 진단 가치 | **선별로는 있고 진단으로는 없다** |
| 설문 같은가 | **그렇다. 이 회차 지적의 원인이 여기다** |
| 전문성 | 줄에 적힌 영역 설명은 전문적이고, 묻는 방식은 전문적이지 않다 |
| 산업·직무로 이어지는가 | 아니다 |

**여기가 핵심이다.** 무료 응답 54개 가운데 36개(67%)가 이 블록이고, 화면
32개 가운데 12개(38%)다. 그런데 이 36개가 재는 것은 **관심과 빈도와
의향뿐**이고, 판단도 산출물도 검증도 묻지 않는다.

그래서 무료로 들어온 사람의 첫 10분이 `하고 싶다 / 해 봤다 / 배우겠다` 를
열두 번 반복하는 경험이 된다. 전공자가 읽으면 **영역 설명 줄은 전문적인데
묻는 방식은 흥미검사**라서, 그 어긋남이 제품을 얕게 보이게 한다.

**선별에 열두 화면이 필요한가.** 아니다. 선별이 답해야 하는 것은
`어느 영역을 깊게 볼까` 하나이고, 그것은 한 화면짜리 격자와 짧은 강제
선택으로 끝난다. 열두 화면으로 늘어난 까닭은 `한 화면에 한 가지를 묻는다`
규칙을 격자에도 그대로 적용했기 때문이고, 그 규칙은 판단 문항을 위한
것이지 선별을 위한 것이 아니다.

**배울 뜻 12개는 특히 자리를 잘못 잡았다.** 아직 어느 영역을 볼지도 모르는
상태에서 열두 번 묻는다. 깊게 볼 두세 영역이 정해진 뒤에 거기서만 물으면
같은 값을 3문항으로 얻는다.

### 2-3 · 일하는 방식 (4화면)

| 물음 | 답 |
| --- | --- |
| 왜 필요한가 | 영역과 무관한 일하는 방식을 본다 |
| 다음에 어떻게 쓰이는가 | **결과지 본문에 한 줄도 안 쓰인다.** 응답 품질에만 쓰인다 |
| 진단 가치 | 낮다 |
| 설문 같은가 | 그렇다. `~하는 편이다` 가 둘이다 |
| 전문성 | 없다 |

`선택지를 둘 이상 놓고 같은 기준으로 견주었다` 는 열두 영역의 J6 이 이미
묻는 말이다. **같은 것을 영역 없이 한 번 더 묻는다.**

### 2-4 · 학위 분기 (4~8화면)

| 물음 | 답 |
| --- | --- |
| 왜 필요한가 | 학부와 대학원이 겪은 장면이 다르다 |
| 다음에 어떻게 쓰이는가 | 여덟 축의 일부를 채운다 |
| 진단 가치 | 있다 |
| 설문 같은가 | 아니다 |
| 전문성 | 보통. **영역이 없어서 어느 영역의 근거인지 모른다** |
| 산업·직무로 이어지는가 | 아니다 |

`과제나 실험에서 조건이나 치수를 내가 정해 진행한 적이 있다` 는 좋은
문항이지만 **어느 영역의 치수인지 적히지 않는다.** 그래서 결과지에서
그 사람의 영역 근거로 못 쓰고, 축 수준만 올린다.

### 2-5 · 선별 심화 (영역당 4화면)

| 물음 | 답 |
| --- | --- |
| 왜 필요한가 | 해 본 영역에서 실제 판단을 묻는다 |
| 다음에 어떻게 쓰이는가 | 축 수준 · 근거 · 빈자리 · 할 일 |
| 진단 가치 | **높다. 지금 검사에서 가장 쓸모 있는 자리다** |
| 설문 같은가 | 아니다 |
| 전문성 | 높다 |
| 산업·직무로 이어지는가 | 간접으로만 |

**여기가 검사의 주인공이어야 하는데 지금은 전체의 15%다.** BASIC 응답
54개 가운데 8개다.

### 2-6 · 경험 심화와 근거 고르기 (STANDARD)

| 물음 | 답 |
| --- | --- |
| 진단 가치 | 높다 |
| 전문성 | 높다. 근거 칩이 영역마다 20~30개로 구체적이다 |
| 남는 문제 | **J4 축 열넷 가운데 넷이 도구 사용만 묻는다.** `상용 도구로 돌려 본 경험` 은 무엇을 정했는지 말하지 않는다 |

### 2-7 · 역할·조직 선호 (2화면 · 14문항)

| 물음 | 답 |
| --- | --- |
| 다음에 어떻게 쓰이는가 | **결과지 본문에 한 줄도 안 쓰인다** |
| 진단 가치 | 낮다 |
| 설문 같은가 | **그렇다.** 5점 척도 일곱 줄이 이어져 일직선 응답이 나온다 |

받아 놓고 쓰지 않는 자리가 열넷이다. 설계 원칙으로 적어 둔
`받고 쓰지 않는 자리 0` 이 지켜지지 않고 있다.

### 2-8 · 경험 번역 (PRO · 12화면)

| 물음 | 답 |
| --- | --- |
| 진단 가치 | 높다 |
| 전문성 | **가장 높다. 은행에서 가장 좋은 묶음이다** |
| 남는 문제 | PRO 끝자락이라 **대부분의 응시자가 보지 못한다** |

### 2-9 · 산업 (PRO · 고르기 + 6화면)

| 물음 | 답 |
| --- | --- |
| 왜 필요한가 | 내 경험이 그 산업에서 어떻게 읽히는지 보여 준다 |
| 다음에 어떻게 쓰이는가 | 결과지 산업 절 하나 |
| 진단 가치 | 있지만 얕다 |
| 설문 같은가 | 아니다 |
| 전문성 | **산업 자료는 전문적이고 묻는 양이 모자라다**(산업당 6문항) |
| 산업·직무로 이어지는가 | 여기서 끝난다 |

**이 회차 지적 그대로다.** 산업은 검사의 **맨 마지막 두 단계**이고,
BASIC·STANDARD 응시자는 **산업을 한 번도 만나지 않는다.** 검사를 다 푼
뒤에 붙는 여섯 문항이라 `본체 뒤에 붙은 부가 Pack` 으로 느껴지는 것이
맞다.

### 2-10 · 직무 (PRO · 고르기 + 6화면)

산업과 같다. 더해서 구조 결함이 둘 있다.

- **역할 일곱과 직무팩 일곱이 다른 집합이다.** taxonomy 의 RF5(운전·보전)를
  가리키는 팩이 하나도 없고, RF3(시험·검증)을 가리키는 팩이 둘이다.
- **CAE 팩과 R&D 팩 열두 문항에 `technical_domain` 이 비어 있다.** 그래서
  그 응답이 어느 영역의 근거로도 읽히지 않는다.

## 3 · 흐름 전체의 문제 다섯

1. **선별이 본체를 밀어냈다.** 관심·빈도·의향 36개가 앞 12화면을 차지하고,
   실제 판단을 묻는 자리는 8개다.
2. **산업과 직무가 맨 뒤에 있고 PRO 전용이다.** 응시자의 대부분이 자기
   경험이 산업에서 어떻게 읽히는지 한 번도 보지 못한다.
3. **영역에 묶이지 않은 문항이 44개다**(일하는 방식 4 · 학위 분기 26 ·
   역할·조직 선호 14). 이 가운데 18개는 결과지가 쓰지도 않는다.
4. **설계한 사슬이 검사에 드러나지 않는다.** 영역 사전에는 여덟 단계
   업무 흐름과 산출물과 검증 대상이 다 적혀 있는데, **문항은 그것을 묻지
   않고 결과지만 그것을 보여 준다.** 응시자 입장에서는 묻지 않은 것을
   결과가 말하는 셈이다.
5. **`해 봤다` 가 `무엇을 정했다` 보다 앞에 온다.** 격자가 먼저 빈도를
   묻고 난 뒤에야 판단을 묻는다. 순서가 거꾸로다.
