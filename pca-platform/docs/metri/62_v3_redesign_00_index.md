## 한 줄 진단

**영역 사전은 전문적인데 문항이 그 사전을 묻지 않는다.**

`me-v3-domains.json` 에는 영역마다 여덟 단계 업무 흐름과 대표 산출물과
검증 대상과 축마다의 L2·L3 정의가 적혀 있다. 그런데 응시자가 받는 첫
10분은 `하고 싶다 / 해 봤다 / 배우겠다` 를 열두 번 반복하는 것이고,
사전에 적힌 것은 **결과지에서만 나온다.** 묻지 않은 것을 결과가 말하는
구조라서, 전공자가 보면 검사가 얕고 결과가 갑작스럽다.

## 고치는 방향 다섯

1. 선별(격자)을 12화면 36문항에서 **2화면 24문항**으로 접는다.
2. 그 자리에 **판단 문항**을 넣는다. 판단 문항 비율 15% → 55%.
3. **산업을 맨 앞으로 옮기고 세 자리에 나눈다**(고르기 · 장면 · 심화).
   세 등급이 모두 산업을 만난다.
4. 영역에 묶이지 않은 문항 44개를 영역에 묶거나 버린다.
5. 받고 쓰지 않는 입력 25~29개를 쓰거나 버린다.

## 숫자

| | 지금 | 새로 |

| 은행 문항 | 294 | 300 안팎(산업 +50 · 직무 +7 · 격자 −12 · 흡수 −30) |
| BASIC 응답 | 54 | 38~48 |
| BASIC 가운데 판단 문항 | 8 (15%) | 22~28 (55%) |
| BASIC 화면 | 32 | 22~26 |
| 산업을 만나는 등급 | PRO 만 | 셋 다 |
| 결과지가 안 쓰는 입력 | 25~29 | 0 |

**문항 수를 목표로 잡지 않았다.** 위 수는 필요한 판단을 다 묻고 나서
나온 결과이고, 1단계에서 문항을 실제로 써 보면 달라진다.
