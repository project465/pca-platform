# PSY_CORE_V1 — 심리학 (2026-10-13)

PHASE 2 의 다섯 번째 Core 다. `src/` 아래에서 바뀐 파일이 **한 벌**이고 그것도
더하기만 했다(`result/chains.ts` · 영역 열둘의 작성 차례 · 판정 로직 0줄).
채점과 결과 판정과 Workspace UI 와 DB 스키마가 한 줄도 바뀌지 않았고 앞 여덟
Core 의 지문이 그대로다.

```
영역 12 · 문항 369 (Core 233 · 팩 136) · 산업팩 8 · 역할팩 8 · 갈래 0
종이 PRO 9쪽 · 배재대 자리 56 → 58
```

## 성격 유형을 재지 않는다

이 Core 에서 가장 먼저 지킨 자리다. 묻는 것은 `사람을 좋아한다` 나 `공감을
잘한다` 가 아니라 **무엇을 직접 정했고 그것이 어디까지 갔는가**다. 문서에
적는 것으로는 지켜지지 않으므로 둘이 막는다: 짝 표
(`src/lib/me-v3/measurement/registry.ts`)가 `PREFERENCE × OWNERSHIP_4` 를
거절하고, 문항마다 primary construct 를 적어 두어(`psy-v1-constructs.json`)
추론으로 지나갈 수 없다.

## 영역 열둘

| 코드 | 이름 | 확정하는 것 | 필수 축 |
|---|---|---|---|
| TD01 | 연구 설계 | 무엇과 무엇을 견줄지 | J1 · J6 |
| TD02 | 측정·척도 | 무엇으로 재고 그 값을 믿을 수 있는지 | J2 · J6 |

| TD04 | 통계 분석 | 쓸 분석 방법과 그 가정 | J4 · J6 |

| TD06 | 사례 개념화 | 무엇이 그 문제를 유지하는지 | J3 · J6 |
| TD07 | 상담·개입 운영 | 그 회기에서 할 것과 멈출 것 | J3 · J7 |
| TD08 | 위기 대응·의뢰 | 안전 조치의 범위와 보낼 곳 | J3 · J5 |
| TD09 | 프로그램 설계·평가 | 회차 구성과 효과를 볼 방법 | J2 · J5 |
| TD10 | 조직·인사 심리 | 사람을 볼 항목과 자르는 선 | J2 · J6 |
| TD11 | 사용자·소비자 조사 | 누구에게 무엇을 어떻게 물을지 | J2 · J4 |
| TD12 | 윤리·기록·수퍼비전 | 알릴 범위와 남길 기록 | J5 · J7 |

**측정·척도와 심리 평가를 나눈다.** 앞엣것은 재는 도구가 믿을 만한지를 보고
뒤엣것은 그 값을 **한 사람의 소견으로 옮긴다.** 같은 까닭으로 **사례
개념화와 상담 운영을 나눴다**: 앞엣것은 무엇이 그 문제를 유지하는지 세우고
뒤엣것은 그 틀로 **이번 회기에서 할 것을 고른다.** 상담 운영과 위기 대응도
나눴다: 정해진 회차 안에서 과제를 고르는 일과 **안전을 먼저 끊고 어디로
보낼지 가르는 일**이 다른 판단이다.

**열둘은 앞 Core 들의 수를 맞춘 값이 아니다.** `공감하며 듣기` 와 `논문 읽기`
같은 일하는 방식은 영역으로 두지 않았다. 그런 것은 열두 영역 전부에 걸쳐
있어서 영역으로 두면 같은 자리를 두 번 센다. 들어간 자리는 축(J4 방법·도구 ·
J6 비교·검증)과 역할팩이다.

**필수 축을 영역의 성질에서 골랐다.** 연구 설계와 측정과 통계와 평가와
개념화와 조직·인사 쪽은 비교·검증이 걸린다. 값과 설명은 다른 것에 대어 보기
전까지 근거가 아니다. 상담 운영과 윤리·기록 쪽은 실패·수정이 걸린다. 자료
수집과 위기 대응과 프로그램 쪽은 산출물이 걸린다: **절차와 조치는 기록으로
남지 않으면 되돌릴 수 없다.**

## 축과 역할기능과 조직환경은 같은 코드다

J1~J8 과 RF1~RF8 과 OC1~OC7 이 기계공학 Core 와 **같은 코드**다. 이름은
심리·상담계열의 말로 바꿨다: 도면 자리에 **척도와 사례 보고서와 평가 소견**이
선다. 공통 판단 여섯과 학위 묶음 스물넷의 문항 번호도 같게 둔다.

## 산업팩 여덟

상담·심리치료 · 병원·임상 · 학교·청소년 · 공공·복지 · 기업 인사·조직 ·
사용자 조사·제품 · 검사·평가 기관 · 대학·연구기관.

**`심리상담` 을 산업으로 두지 않는다.** 그것은 하는 일의 이름이지 서는 자리가
아니고, 같은 일을 놓고 사설 센터와 병원과 학교와 공공기관이 서로 다른 판단을
묻는다. 상담·심리치료와 병원·임상을 따로 둔 것도 같은 까닭이다: 앞엣것은
**그 사람이 다음 주에도 오는지가** 기준을 정하고 뒤엣것은 **다른 전문직과
판단을 맞추는 일이** 기준을 정한다.

**용어를 모른다고 부적합으로 적지 않는다.** 여든 문항 전부에 그 판단을 일반
심리·상담 말로 바꿔 적은 줄이 붙는다.

## 역할팩 여덟

프로그램·제도 설계(RF1) · 분석·해석(RF2) · 평가·판정(RF3) ·
도구·콘텐츠 제작(RF4) · 현장 운영(RF5) · 사례·과제 관리(RF6) · 연구(RF7) ·
윤리·품질 관리(RF8).

**수퍼바이저를 따로 두지 않고 윤리·품질 안에 둔다**: 수퍼바이저가 내리는
판단은 무엇을 지적하고 어디까지 맡길지를 가리는 일이고, 그 권한과 범위가
품질 관리 쪽과 같은 자리에 있다. 별칭으로 적어 그 공고를 찾는 사람이 닿게 했다.

## 갈래는 두지 않았다

배재대 심리상담학과는 두 Catalog 모두 트랙을 두지 않아 갈래 없이 Core 로 바로
간다. **쓰이지 않는 갈래를 미리 적어 두지 않는다**: 상담·임상 갈래와 산업·조직
갈래는 그 자리를 가리키는 학과나 트랙이 생기는 날 그 전공을 아는 분이 쓴다.
`사회복지학과` 와 `아동가족학과` 도 별칭에 넣지 않았다. 그 두 이름이 묻는
판단은 제도와 자원을 잇는 쪽이고 이 Core 가 묻는 것은 재고 판정하고 개입하는
쪽이라, 확인 전에는 비워 둔다.

## 자동 검사가 잡은 자리 여섯

눈으로는 여섯 다 멀쩡해 보인다. 영역 둘이 **글자까지 같은 선별 문항**을 들고
있었고(심리 평가와 사용자 조사의 `더 볼지 멈출지` · 1.00), 산업팩 둘이 영역의
심화 문항과 같은 말로 묻고 있었고, 역할팩 셋이 산업팩이나 영역과 같은 꼴로
서 있었다. 팩이 Core 의 칸을 다시 읽는 것은 설계지만, **같은 말로 묻는 것은
응시자가 같은 질문을 두 번 받는 일**이라 팩이 파는 것이 사라진다.
