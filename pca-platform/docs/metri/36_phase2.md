# 36. 사람 없이 한 바퀴 — 셀프 서비스와 ME_V2 플랫폼 연결

2026-10-04. 규격
`CAREERMATRI_PHASE2_KR_GLOBAL_SELF_SERVICE_ME_V2_INTEGRATION` 을 코드로
옮긴 기록이다.

파는 쪽에서 보면 한 줄이다.

```
방문 → 가입 → 등급 고르기 → 결제 → 이용권 → ME_V2 응시
     → 서버 저장·이어보기 → 경험 → 결과 스냅샷 → PDF → 개인 첫 화면
```

이 줄 가운데 **사람이 끼어드는 자리가 없어야** 끝난 것이다. 전에는
결제 다음이 비어 있어서, 산 사람의 응시를 누군가 열어 줘야 했다.

---

## 0. 먼저 센 것: 절반이 이미 있었다

표를 더 만들기 전에 무엇이 도는지 셌다. 규격이 요구한 것의 절반 가까이가
이미 있었다: `users` · `orders` · `payments` · `products` ·
`entitlements` · `attempts` · `report_snapshots` · `evidence_profiles` ·
`evidence_snapshots` · `site_configs` · `country_packs`.

**새로 만든 표는 둘뿐이다.** `v2_responses` 와 `job_failures`.

| 하려던 것 | 한 것 |
|---|---|
| 상품이 시장·등급을 들고 다닌다 | `products` 에 칸 넷 추가 (`market` · `major_code` · `tier` · `assessment_version`) |
| 이용권이 등급을 들고 다닌다 | `entitlements` 에 칸 다섯 추가, `ends_at` 을 비울 수 있게, `kind` 에 `report` 추가 |
| 응시가 이용권을 가리킨다 | `attempts` 에 `entitlement_id` · `tier` · `education_stage` · `last_saved_at` |
| 응답을 서버가 들고 있는다 | **새 표** `v2_responses(attempt_id, item_id, value)` |
| 결과지를 불변으로 남긴다 | `report_snapshots` 에 `payload` · `pdf_path` · `trace_id` 추가 |
| 막힌 것이 아침에 보인다 | **새 표** `job_failures` |

**표를 하나 더 만들면 등급을 정하는 자리가 둘이 된다**(설계 원칙 10).
`entitlements` 가 이미 그 일을 하고 있었으므로 칸을 더했다.

---

## 1. 응답을 `responses` 에 넣지 않은 까닭

`responses.question_id` 는 `questions` 표를 가리키는 외래키다. 그런데
ME_V2 문항의 원본은 `sites/pca-platform/assessment/ME_V2/*.json` 이고 DB
에 없다. 넣으려면 92문항을 `questions` 에 심어야 하는데, 그러면 **ME_V1
채점이 그것을 집을 수 있다**(설계 원칙 8 에서 실제로 두 번 그랬다).

그래서 `v2_responses` 를 따로 두고 `item_id` 를 글자로 담는다. 외래키가
없는 대신 쓰는 쪽에서 거른다: `saveAnswers` 가 `itemsFor(tier)` 에 있는
문항만 받는다. **BASIC 을 산 사람이 PRO 문항 번호를 보내도 그 줄은 쓰이지
않는다.**

---

## 2. 등급은 이용권이 정한다

```
products.tier → entitlements.tier → attempts.tier → itemsFor(tier)
```

화면은 이 사슬에 끼어들지 못한다. `openV2Attempt()` 가 **등급을 인자로
받지 않는 것이 일부러다**: 받을 수 있으면 언젠가 화면이 넘기고, 그러면
주소로 등급을 올리는 길이 생긴다. 응시를 연 뒤에는 `/assessment/[id]` 가
그 응시의 등급을 읽기만 한다.

**한 이용권이 응시 하나다.** `attempts_entitlement_uniq` 가 DB 에서 못
박고, `openGrants()` 는 아직 응시로 바뀌지 않은 이용권만 돌려준다. 하나를
두 번 쓰면 같은 사람의 응답이 두 벌 쌓여 규준이 오염된다.

**중복 웹훅이 이용권을 두 개 만들지 않는다.** `entitlements_order_uniq`
가 주문 하나에 이용권 하나를 못 박는다. 코드의 if 로 막으면 고쳐 쓰다
빠뜨릴 수 있다.

## 3. 서버가 진실이고 브라우저 저장소는 사본이다

규격 §13·§56 이 막는 것은 **기기를 바꾸는 순간 사라지는 응답**이다.

- 답을 고치면 모아 두었다가 0.9초 멈출 때 한 번 보내고, 묶음을 넘어갈 때
  반드시 한 번 더 보낸다. **문항마다 왕복하지 않는다**: 92번 쓰게 되고 그
  가운데 하나가 늦으면 응시자가 멈춘 것으로 본다
- 저장이 안 됐으면 **넘어가지 않는다**
- `localStorage` 는 복구용 사본이고, 서버가 받아 준 답은 거기서 지운다.
  남겨 두면 다음에 들어왔을 때 어느 쪽이 최신인지를 또 판단해야 하고, 그
  판단이 틀리면 고친 답이 되돌아간다
- 이어서 들어오면 **안 찬 묶음으로** 간다(`progressOf().resumeSection`)

**어디까지 왔는지를 숫자만으로 적지 않는다**(규격 §43). `43/92` 옆에 뜻이
있는 묶음 이름이 선다: 해보고 싶은 일 · 해본 경험 · 직접 정한 것 ·
업무 방식 · 배울 뜻 · 진로 맥락.

## 4. 엔진을 한 벌만 돌린다

여기가 이번에 가장 크게 정한 것이다.

ME_V2 의 점수·판정·문장은 `sites/pca-platform/assets/*.js` 한 벌에 있다.
플랫폼에서 결과지를 내려면 길이 둘이었다.

| 길 | 왜 안 골랐나 / 골랐나 |
|---|---|
| 서버에 TypeScript 로 옮겨 적는다 | **결정하는 자리가 둘이 된다.** 웹과 PDF 가 다른 글을 내도 아무도 모른다 |
| 그 파일들을 플랫폼이 내주고 불러 쓴다 | **골랐다.** 고칠 곳이 한 곳이고, 웹과 PDF 가 다를 수 없다 |

```
/pca/[...path]          정적 엔진을 플랫폼이 내준다 (올려 둔 폴더 밖으로 못 나간다)
/me-v2/report-host.html 결과 스냅샷을 받아 PCAV2Report.render(J) 로 그린다
/me-v2/evidence-host.html 승인된 경험 입력 화면을 그대로 띄운다
src/lib/me-v2/render.ts 머리 없는 브라우저로 같은 엔진을 불러 그리고 찍는다
```

**채점은 한 줄도 고치지 않았다.** 전에 응시한 사람의 점수가 달라지지
않는다.

### 판본을 손으로 적지 않는다

`report_snapshots` 는 엔진 판본 다섯을 적는다. 그 값은 **실제로 돌아간
파일의 지문**이다(`src/lib/me-v2/versions.ts`). 파일 안에
`VERSION = '1.2'` 를 두면 고치면서 올리는 것을 잊고, 잊으면 스냅샷이
거짓을 적는다.

```
scoring:  v2-scoring.js + me-v2.js
evidence: evidence.js + readiness.js + evidence-rules.js
value:    value-engine.js + value-data.js
coverage: coverage-engine.js
renderer: v2-report.js + v2-value-report.js + v2-coverage-report.js
          + v2-result-json.js + report-print.css
```

## 5. 만들어 둔 결과지를 고치지 않는다

`report_snapshots` 는 줄이 쌓이기만 한다. 가장 최근 것이 지금 보는 것이고
옛것은 그대로 남는다(설계 원칙 4 와 같은 규칙이다).

각 줄이 **자기 안에** 그때의 것을 품는다.

```
payload = { result, summary, evidence, evidence_profile_version,
            input_warnings, sheets }
```

경험 사본 표(`evidence_snapshots`)는 응시마다 한 줄이라 다시 만들면
바뀐다. 그래서 결과지가 자기 안에도 들고 있다. **경험을 한 줄 더 적은
다음 날 어제 본 결과지가 달라지면 안 된다.**

**경험을 늘려도 다섯 값이 한 값도 바뀌지 않는다.** 관심 · 경험 ·
결정 소유 · 업무 방식 · 학습 의향은 문항에서만 나오고, 바뀌는 것은 증거
사다리와 역할별 범위와 문장이다. `npm run phase2:report` 가 경험을 늘려
다시 만들어 보고 그 다섯을 글자 그대로 견준다.

## 6. PDF 를 플랫폼이 찍는다

```
A4 · 여백 18mm 16mm · 머리말과 꼬리말을 우리가 그린다
```

**브라우저가 붙이는 주소와 날짜를 쓰지 않는다.** 인쇄 대화상자의 설정이라
CSS 로 끌 수 없고, 그대로 두면 파는 문서에 `localhost:3100` 이 찍힌다.
`displayHeaderFooter` 를 켜고 우리 틀로 덮는다. 검사가 그것을 센다: 찍힌
PDF 안에 `localhost` 나 `127.0.0.1` 이 있으면 실패다.

**한글 글꼴을 컨테이너에 깔아야 한다.** 리눅스에 `Pretendard` 도
`맑은 고딕` 도 없고, `WenQuanYi` 와 `Noto` 가 같이 깔려 있으면
fontconfig 가 `lang=ko` 에도 중국어 글꼴을 먼저 고른다. 한글 자형이
중국어 쪽으로 기울어 결과지가 번역물처럼 읽힌다.

- `apt-get install fonts-noto-cjk`
- `deploy/fonts-ko.conf` 를 `/etc/fonts/conf.d/` 에 넣는다
- `assets/app.css` 의 글꼴 사슬에 `"Noto Sans CJK KR"` 을 더했다

**PDF 를 웹에 그대로 올려 두지 않는다.** `var/reports/` 는 바깥에서
열리지 않는 자리이고, `/assessment/[id]/report/pdf` 를 지나면서 로그인한
본인인지 다시 본다. 주소만 알면 열리는 자리에 두면 번호를 하나씩 올려 남의
결과지를 받아 갈 수 있다.

## 7. 개인 첫 화면의 여섯 칸

```
none       아직 안 샀다             → 가격표
purchased  샀는데 시작하지 않았다    → 검사 시작
progress   풀고 있다                → 이어서 (안 찬 묶음 이름까지)
evidence   다 풀었고 경험이 비었다   → 경험 적기 (결과지 길도 함께)
generating 낼 수 있는데 아직 안 냈다 → 결과지 만들기 (막혔으면 그 때까지)
done       결과지가 있다            → 결과지 열기 · PDF
```

**순서가 곧 우선순위**이고 한 함수(`src/lib/me-v2/lifecycle.ts`)에만
있다. 화면마다 판단하면 화면이 늘 때마다 판단이 복사되고, 복사된 것 중
하나가 틀리면 산 사람이 자기 결과지를 못 찾는다.

**경험으로 막지 않는다.** `evidence` 는 권하는 칸이고, 그 상태에서도
결과지를 만드는 길이 함께 있다. 적지 않으셔도 결과지는 나가고, **무엇이
빠지는지를 결과지 맨 위에 적는다.** 숨기면 읽는 사람은 이 검사가 원래 그
정도인 줄 안다.

## 8. 막힌 것과 아직 안 한 것

`job_failures` 한 표이고, `/admin` **맨 위**에 선다. 운영자가 아침에 이
화면을 여는 이유가 그것이기 때문이다.

- **개인 서술을 담지 않는다.** 무엇이 몇 번 깨졌는지와 되짚을 번호까지다
- 비어 있으면 "지금 막힌 것이 없습니다" 로 적고, **비어 있는 것과
  검사하지 않는 것을 가른다**: 그 줄은 표를 실제로 센 결과다
- 결과지가 없는 사람의 첫 화면도 둘로 갈린다. 아직 안 만든 자리에는
  만드는 단추가 서고, 만들다 막힌 자리에는 막힌 때가 선다

## 9. 한국과 글로벌

| | 한국 | 글로벌 |
|---|---|---|
| 도메인 | `careermatri.co.kr` | `careermatri.com` |
| 통화 | KRW | USD |
| 결제 시장 | `KR` | `GLOBAL` |
| 목표 국가 | 묻지 않는다 | 묻는다 (안 고를 수 있다) |

**도메인을 코드에 적지 않는다.** `site_configs` 한 표에서만 읽고,
`resolveMarket()` 이 들어온 호스트로 시장을 고른다. `?market=` 을 받는
것은 한 배포본에서 둘을 눌러 보기 위해서다. **주소로 값이 바뀌지
않는다**: 주문 금액은 서버가 `products` 에서 다시 읽는다(규격 §8).

**화면 언어 · 사이트 지역 · 목표 국가는 다른 값이다.** 한국 사이트를
한국어로 쓰면서 미국 시장을 보는 사람이 가장 흔하고, 셋을 하나로 묶으면 그
사람에게 한국 공고가 나간다. `attempts` 에 세 칸이 따로 있다.

**확인된 나라 자료가 없으면 지어내지 않는다.** `country_packs` 가 비어
있어 결과지는 `GLOBAL_REFERENCE_MODE` 로 나가고 그 사실을 화면에 적는다.
임금·비자·면허를 한 줄도 적지 않는다.

## 10. 값을 지어내지 않았다

ME_V2 여섯 상품의 `amount` 가 **0** 이다. 승인된 가격이 없다.

- 가격표는 그 자리에 "값이 아직 정해지지 않았습니다" 로 적는다.
  **0 을 '무료' 로 적지 않는다**: 무료라고 적으면 파는 쪽이 공짜로 약속한
  셈이 된다
- `catalog.sellable()` 이 운영 결제 대행사가 켜져 있을 때 0원 상품을
  거절한다. 개발·시험에서는 0원 주문이 지나간다: 그래야 흐름 전체를 사람
  없이 한 바퀴 돌 수 있다

## 11. 아직 못 하는 것

**영어 결과지를 팔 수 없다.** 두 가지가 막는다.

1. **92문항이 한국어뿐이다.** `missingTranslations('en')` 이 92를 돌려준다.
   학위 단계마다 문장이 갈리는 12문항까지 치면 번역하고 검수할 것이 더
   많다. **문항을 지어내지 않는다**(설계 원칙 4 와 같은 이유다: 문체
   규칙으로 문항을 다듬으면 그 순간 문항이 바뀐다)
2. **결과지 엔진이 `report_language: 'ko'` 를 못 박고 있다.** 문장 조각이
   전부 한국어다

그래서 글로벌 흐름은 **결제·이용권·응시·저장·결과·PDF 까지 전부
돌지만**, 응시자가 읽는 글은 한국어다. 화면 껍데기만 영어로 바꿀 수 있고,
그것은 파는 상태가 아니다.

그 밖에:

- **운영 결제 대행사가 아직 안 붙었다.** `PAYMENTS_PROVIDER=mock` 이고,
  `portone` 으로 켜면 금액이 0 인 여섯 상품은 팔리지 않는다
- **결과 생성이 요청 안에서 돈다.** 사람이 단추를 누르고 기다린다(몇 초).
  대기열로 빼는 것이 다음이고, 지금은 `job_failures` 가 막힌 것을 받는다
- **인지 면접과 파일럿 200명을 안 돌렸다.** "과학적으로 검증된" 으로
  팔지 않는다. 규준이 없으므로 "상위 몇 %" 도 적지 않는다

## 12. 검사

```bash
npm run phase2:check    # 서버 쪽 한 바퀴 (K · P · S · G · F 33가지)
npm run phase2:report   # 제출 → 경험 → 결과 스냅샷 → PDF 25가지
node scripts/phase2-shots.mjs   # 브라우저로 끝까지 눌러 보고 쪽마다 찍는다
```

`phase2:report` 와 `phase2-shots` 는 **서버가 떠 있어야 한다**: 머리 없는
브라우저가 플랫폼 자신을 열어 엔진을 불러 쓴다.

검사가 세는 것 가운데 눈으로는 못 잡는 것들.

- 경험을 늘려 결과지를 다시 만들었을 때 **다섯 값이 글자 그대로 같은가**
- 찍힌 PDF 안에 **브라우저가 붙인 주소가 없는가**
- 남의 응시 번호로 결과지를 만들려 하면 **거절되는가**
- 중복 웹훅이 **이용권을 두 개 만들지 않는가**
- 좁은 화면에서 **가로 스크롤이 생기지 않는가**

### 돌리다 걸린 것

- **`test_sessions` 가 주문을 가리킨다.** 검사를 두 번 돌리려고 주문을
  지우는데, 개인 응시가 걸리는 회차가 그 주문을 가리켜서 외래키가 막았다.
  지우는 순서를 맞췄다
- **서버 액션은 쪽을 새로 받아 오지 않는다.** `networkidle` 로 갈음하면
  네트워크가 조용해진 순간에도 주소는 아직 앞 쪽이라, 멀쩡한 흐름이
  실패로 찍혔다. 주소가 바뀔 때까지 기다린다
- **`entitlements.ends_at` 이 `NOT NULL` 이었다.** 기간권은 날짜가 뜻을
  갖지만 결과지 이용권은 한 번 열리면 닫히지 않는다. 비울 수 있게 두지
  않으면 2099년 같은 가짜 날짜를 쓰게 되고, 그 날짜가 언젠가 온다

## 14. 완료 보고

규격 §60 이 끝났다고 보는 선: **새 이용자가 사람의 손을 거치지 않고**
`가입 → 결제 → 이용권 → ME_V2 → 서버 저장·이어보기 → 경험 → 결과 → PDF
→ 개인 첫 화면` 을 끝까지 간다.

검사 셋이 그것을 센다. `npm run phase2:check` 33가지 · `npm run
phase2:report` 25가지 · `node scripts/phase2-shots.mjs` 가 브라우저로 한
바퀴.

| # | 무엇 | 상태 | 어디 · 왜 |
|---|---|---|---|
| 1 | 셀프 가입 | 됨 | `/signup`. 가입하면 곧바로 로그인하고 가려던 곳으로 돌아간다 |
| 2 | 로그인 요구로 막지 않는다 | 됨 | 값을 먼저 보여 주고 고른 뒤에 가입으로 보낸다 |

### 못 넘긴 선

| 무엇 | 왜 | 풀리는 조건 |
|---|---|---|
| **영어 결과지** | 92문항이 한국어뿐이고 엔진이 `report_language: 'ko'` 를 못 박고 있다 | 문항 92 + 단계별 12 번역·검수, 결과지 문장 조각 영어판 |

**글로벌 흐름은 돈다.** 결제 · 이용권 · 응시 · 저장 · 이어보기 · 제출 ·
경험 · 결과 스냅샷 · PDF 가 전부 간다. 다만 **응시자가 읽는 글이
한국어다.** 화면 껍데기만 영어로 바꿀 수 있고, 그것은 파는 상태가 아니다.
