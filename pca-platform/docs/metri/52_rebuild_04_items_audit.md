# F. 92문항 전수 감사

92행 전부 적는다. 문면은 저장소의 원문이고(`items-*.json`), 학위별로
갈리는 Q77~88 은 학부판을 적었다.

결함 코드

| 코드 | 뜻 |
|---|---|
| `1ITEM` | 직무 하나를 문항 하나가 대표한다 |
| `DB` | 한 문항이 둘 이상을 묻는다(double-barreled). `심함`은 셋 이상 |
| `WEAK-DB` | 같은 영역 안이라 영향이 작은 겹묶음 |
| `DUP` | 다른 문항과 같은 것을 묻는다. 괄호에 상대 문항 |
| `OVERLAP` | 일부 겹친다 |
| `SD` | 사회적 바람직성. 거절하기 어려운 문면 |
| `AXIS` | 기술영역이 아닌 것을 기술영역 자리에 두었다 |
| `PERSON-LEVEL` | 사람 단위 한 값으로 묶여 영역별로 쓸 수 없다 |
| `NO-JUDGE` | 측정하지만 판정에 쓰이지 않는다 |
| `UNUSED` | 결과지에 한 글자도 나오지 않는다 |
| `PM-BIAS` | 기술 판단보다 과제 관리 쪽으로 기운다 |
| `LOW-VALUE` | 기계공학 직무 판단에 주는 정보가 적다 |

판정은 `유지 · 재작성 · 분리 · 병합 · 삭제 · 이동 · 승격` 일곱이다.
`이동`은 다른 축으로, `승격`은 결과에 실제로 쓰이게 올린다는 뜻이다.

학위 편향은 따로 적지 않고 아래 규칙으로 일괄 처리한다. **경험·판단·
산출물 축의 모든 문항은 수업과 캡스톤에서도 답할 수 있는 장면을 함께
제시한다**(지금 Q77~88 이 하는 방식). 그래서 학부생이 구조적으로 낮게
나오는 자리를 없애고, 대학원생에게는 같은 축을 연구 장면으로 묻는다.
