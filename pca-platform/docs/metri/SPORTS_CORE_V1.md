# SPORTS_CORE_V1 — 체육·운동재활 (2026-10-13)

PHASE 2 의 열 번째 Core 다. `src/` 아래에서 바뀐 파일이 **한 벌**이고 그것도
더하기만 했다(`result/chains.ts` · 영역 열둘의 작성 차례 · 판정 로직 0줄).
채점과 결과 판정과 Workspace UI 와 DB 스키마가 한 줄도 바뀌지 않았고 앞 열세
Core 의 지문이 그대로다.

```
영역 12 · 문항 369 (Core 233 · 팩 136) · 산업팩 8 · 역할팩 8 · 갈래 3
배재대 자리 71 → 77
```

## 자기 운동 실력을 재지 않는다

이 Core 가 가장 쉽게 적성검사로 미끄러지는 자리다. 묻는 것은 `운동하는 것이
좋다` 나 `달리기가 빠르다` 가 아니라 **남을 재고 짜고 돌리면서 무엇을 직접
정했는가**다. 그래서 `운동을 잘한다` 는 영역으로도 두지 않았다: 그것은
**응시자 자신의 수행**이고 이 Core 가 재는 것은 남의 몸을 재어 부하를 걸고
돌려보내는 판단이다. 문서에 적는 것으로는 지켜지지 않으므로 둘이 막는다: 짝
표(`src/lib/me-v3/measurement/registry.ts`)가 `PREFERENCE × OWNERSHIP_4` 를
거절하고, 문항마다 primary construct 를 적어 두어(`sports-v1-constructs.json`)
추론으로 지나갈 수 없다.

**측정과 처방을 나눈 까닭**은 앞엣것이 지금 어느 수준인지를 재는 일이고
뒤엣것이 **그 수준에 맞는 강도와 종목을 정하는** 일이어서다. 같은 까닭으로
손상 평가와 재활 단계를 나눴다: 앞엣것은 **지금 멈출지 보낼지**를 가리고
뒤엣것은 **다음 단계로 올릴지**를 판정한다. 동작 분석과 측정도 나눴다 — 어느
자리가 어긋났는지 보는 일과 **얼마나 할 수 있는지 재는 일**이 다른 판단이다.

**필수 축을 영역의 성질에서 골랐다.** 지도 쪽은 실패·수정이 걸린다 — 계획대로
안 되는 날이 많고 그 자리에서 바꾸는 것이 그 일이다. 시설 안전과 규정·윤리
쪽은 산출물과 실패·수정이 함께 걸린다: **점검표가 남아야 하고 같은 사고가
다시 나지 않아야 한다.** 측정과 손상 평가와 재활 단계와 선수 관리 쪽은
비교·검증이 걸린다 — 값과 판정은 기준이나 안 다친 쪽에 대어 보기 전까지
근거가 아니다.

## 스포츠 마케팅은 이 Core 에 두지 않았다

고객과 채널과 가격과 성과를 묻는 판단은 `BIZ_CORE_V1` 이 들고 있고, 배재대
`스포츠마케팅전공` 이 그 Core 의 `SPEC_BIZ_SPORTS` 로 이미 가 있다. **한
자리를 두 Core 가 묻게 되면 그 학생이 어느 자로 재어졌는지 아무도 모른다.**
같은 까닭으로 `물리치료학과` 와 `작업치료학과` 도 별칭에 넣지 않았다:
의료기관에서 처방에 따라 치료하는 자리는 이 Core 의 열두 영역과 겹치지 않고,
그 전공을 아는 분이 따로 세워야 한다.

## 축과 역할기능과 조직환경은 같은 코드다

J1~J8 과 RF1~RF8 과 OC1~OC7 이 기계공학 Core 와 **같은 코드**다. 이름은
체육·운동재활계열의 말로 바꿨다: 도면 자리에 **운동 처방표와 측정 기록과
복귀 판정서와 점검표**가 선다. 공통 판단 여섯과 학위 묶음 스물넷의 문항 번호도
같게 둔다 — 결과지가 그 번호로 사람이 읽는 이름을 찾고 그 표는 Core 를 모른다.

## 산업팩 여덟

프로팀·선수단 · 중환자가 아닌 **병원·재활센터** · 체육관·피트니스 ·
학교·유소년 · 노인·건강증진 · 대회·경기 운영 · 스포츠 과학·측정 ·
시설 운영·행정.

**`스포츠` 를 산업으로 두지 않는다.** 그것은 다루는 것의 이름이지 서는 자리가
아니고, 같은 운동을 놓고 프로팀과 재활센터와 피트니스와 학교가 서로 다른
판단을 묻는다. 프로팀과 재활센터를 따로 둔 까닭은 앞엣것은 **이번 주 경기에
내보낼 수 있는가**가, 뒤엣것은 **다시 다치지 않고 돌아가는가**가 기준을
정하기 때문이다.

## 역할팩 여덟

프로그램 설계 · 측정·평가 · 복귀·적합 판정 · 기록·표준 관리 · 현장 지도 ·
운영·조정 · 조사·연구 · 안전·규정 관리. 여덟이 역할기능 여덟과 하나씩
맞물리고, 묻는 것은 기술영역이 아니라 **그 자리에서 가진 권한과 범위**다.

## 자동 검사가 잡은 자리 열셋

눈으로는 열셋 다 멀쩡해 보인다.

- **산업팩과 역할팩의 문항이 글자까지 같았다**(1.00): 대회 운영과 운영·조정이
  둘 다 `일정이 밀린 날 무엇을 줄이거나 미룰지 내 이름으로 정한` 이었다
- **영역 둘의 둘째 J5 가 같은 꼴이었다**(0.74): 재활 단계와 시설 안전이 둘 다
  `되돌린·닫은 기록과 그 까닭을 적어 남겨 본` 이었다
- **산업팩 다섯이 Core 문항을 어미만 바꿔 베꼈다**(0.43~0.70). 다섯 다 그
  산업의 조건을 들게 다시 썼다
- **역할팩 셋이 Core 문항과 같은 꼴이었다**(0.46~0.57). 그러면 응시자는 같은
  질문을 두 번 받고, 역할팩이 파는 것(**권한과 범위**)이 사라진다
- **산업팩과 역할팩이 같은 말로 묻는 자리가 둘 더 있었다**(0.47 · 0.58)

## 사람 열두 벌에서 고른 자리

영역을 고를 때 **필수 축이 무엇인지를 보고 골랐다.** 산출물이 빈 자리를 그리려면
산출물이 필수인 영역(TD06 · `J4`·`J5`)이 필요하고, 산출물만 비는 자리를 그리려면
산출물이 필수가 아닌 영역(TD11 · `J1`·`J6`)이 필요하다. 검증만 비는 자리는
**비교·검증이 필수가 아닌 영역**(TD10 · `J3`·`J5`)이어야 한다 — 필수면 까닭이
둘이 되어 근거가 서지 않는다.
