# PCU 대표 학과 Human Review Pack

계열마다 대표 학과 하나를 골라 **그 학과 학생이 실제로 받는 글**을 모았다.
문항은 그 Core 의 은행에서 읽고, 결과 쪽의 일곱 절은 제품과 같은 길로
응시를 열고 끝까지 답하고 제출해 받은 글자를 그대로 옮겼다.

**읽어 주실 것 하나다.** 이 학과 학생이 읽었을 때 자기 전공의 이야기로
읽히는가. 기계가 셀 수 있는 것은 여기까지이고, 문면이 현장 말인지는
사람이 읽어야 한다.

생성 명령 `npm run pcu:pack` · 자동검사 `npm run pcu:dept`
