# 20. 도메인 — 지금 무엇이 막혀 있나

2026-09-14 작성, 2026-09-15 갱신. `npm run domains:check` 로 다시 확인할 수 있다.

---

## 0. 한 줄

**도메인보다 이름이 먼저 막힌다.** 한국에는 이미 **메트리(Metri)** 라는
온라인 검사 서비스가 있다. 그리고 코드가 가리키는 `metri.io` 도 우리
것이 아니다.

## 0-1. 2026-09-15 — `metri.co.kr` 을 사려다 찾은 것

`metri.kr` 에 CloudFront 가 응답하던 것이 우리 것일 수도 있다고 4절에
적어 뒀는데, **아니었다.**

| | |
|---|---|
| 누구 | 테라블루테크놀로지 (정신건강의학과 소프트웨어) |
| 무엇 | **메트리(Metri)** — 온라인 척도검사 전자화. 검사 처방·판독·보관 |
| 어디 | `metri.kr` · `clinic.metri.kr` · `client.metri.kr` |
| 또 | 구글플레이 앱 이름이 **'메트리'** (`com.metri.metri_client_flutter`) |
| 문구 | 사이트 대문이 "설문지 처방의 새로운 시작, Metri" |

**같은 낱말을 쓰고 있다** — 검사, 처방, 온라인. 파는 곳이 병원이고
우리는 학교라 시장은 갈리지만, 한국에서 "메트리 검사" 를 찾는 사람에게는
갈려 보이지 않는다.

그래서 `metri.co.kr` 은 **살 수 있느냐보다 사도 되느냐가 먼저**다.
`.kr` 을 쓰는 곳이 `.co.kr` 을 방어 등록해 두는 것은 흔한 일이라, 애초에
비어 있지 않을 가능성도 있다.

### 무엇을 확인해야 하는가 (코드로는 못 한다)

이 컨테이너는 whois·rdap·KIPRIS·DoH 가 전부 **송신 차단**이라 등록 여부도
상표도 여기서 볼 수 없다. 밖에서 볼 것 둘.

1. **KIPRIS 에서 '메트리' 상표** — 등록돼 있는지, 몇 류인지.
   우리가 걸리는 것은 41류(교육·검사)와 42류(SaaS)다. 저쪽이 44류(의료)에만
   있으면 숨통이 트이고, 41·42 에 걸쳐 있으면 이름을 바꾸는 편이 싸다.
   **이건 변리사 확인 사항이다. 이 문단은 법률 자문이 아니다**
2. **등록대행자(가비아·후이즈·호스팅케이알)에서 `metri.co.kr` 조회** —
   실제로 비어 있는지. 30초면 된다

### 갈림길 셋

| 고르면 | 값 | 치르는 것 |
|---|---|---|
| 그대로 간다 | 원고·로고를 한 글자도 안 고친다 | 상표 위험을 떠안는다. 검색에서 저쪽과 섞인다 |
| 이름은 두고 도메인만 멀리 | `metricareer.co.kr` 처럼 | 섞이는 것은 그대로다 |
| 이름을 바꾼다 | 위험이 없어진다 | 로고·원고·문서 전부. **지금이 가장 싸다** |

**지금이 가장 싼 때다.** 아직 배포도 안 했고 고객도 없다. 학교 한 곳에
납품한 뒤에 바꾸면 그 학교 문서까지 따라 바뀐다.

## 1. 확인한 것

DNS 로 조회했다. 이 컨테이너에서는 whois·rdap 이 막혀 있어서 **등록
여부가 아니라 "지금 누가 서버를 띄워 두었는가" 만** 봤다.

| 주소 | 결과 | 코드에서 쓰는 곳 |
|---|---|---|
| `metri.io` | **남의 서버가 응답** (34.234.15.46) | 인터내셔널 사이트 도메인 |
| `app.metri.io` | 응답 없음 | **네 사이트의 "시작하기" 가 전부 여기로 간다** |
| `metri.co.kr` | 응답 없음 | 한국 사이트 도메인 |
| `metri.kr` | 쓰이는 중 (CloudFront) | 안 씀 |
| `metri.com` · `metri.app` · `metri.co` | 쓰이는 중 | 안 씀 |
| `metriplus.co.kr` · `metriplus.kr` | 조용함 | 안 씀 |

**"조용함" 은 "비어 있음" 이 아니다.** 등록만 해 두고 레코드를 안 건
도메인은 응답하지 않는다. 사기 전에 등록대행자에서 WHOIS 를 봐야 한다.

~~`metri.kr` 이 우리 것일 수 있다~~ — **아니다.** 0-1절을 볼 것.
CloudFront 대역이 같았던 것은 그 뒤에 수많은 사이트가 있기 때문이다.

## 2. 왜 지금 문제인가

`marketing/src/content/global.ts` 의 `platformUrl: "https://app.metri.io"`
가 네 사이트의 "시작하기" 버튼이 가리키는 곳이다. `metri.io` 가 남의
것이면 그 아래 `app.` 도 우리가 만들 수 없다. **그 상태로 배포하면
버튼을 누른 학생이 남의 집 문 앞에 선다.**

지금은 아무 사이트도 배포돼 있지 않아서 실제 피해는 없다. 배포하는
날에 터진다.

## 3. 사야 하는 것

파는 범위가 **한국뿐**이므로(설계 원칙 9), 지금 필요한 것은 셋이다.

| 쓰임 | 후보 | 비고 |
|---|---|---|
| 한국 소개 사이트 | `metri.co.kr` | 코드가 이미 이 이름을 쓴다 |
| 플랫폼 (전 세계 하나, 설계 원칙 5) | `app.metri.co.kr` 또는 별도 도메인 | `metri.io` 를 못 쓰면 여기서 갈린다 |
| 메트리 플러스 | 한국 사이트 안의 경로로 둬도 된다 | 브랜드는 갈리되 도메인까지 나눌 필요는 없다 |

인터내셔널 사이트는 **파는 나라가 생긴 다음에** 정한다. 지금 `metri.io`
를 비싸게 사 오는 것보다, 한국 매출이 나고 나서 정하는 편이 싸다.

**`.co.kr` 은 국내 주소가 있어야 등록된다.** ACADEMIX 가 국내 법인이므로
요건은 맞고, KISA 가 인정한 등록대행자(가비아·후이즈 등)를 통해 등록한다.
등록비는 대행자마다 다르니 확인이 필요하다 — 지어내지 않았다.

## 4. 사고 나서 고칠 곳

도메인이 정해지면 바꾸는 곳은 **두 줄**이다. 나머지는 이 두 값에서 나온다
(`sitemap.ts` · `robots.ts` · og:image 의 `metadataBase` 가 전부
`site.domain` 을 읽는다).

```
marketing/src/content/kr.ts       domain: "metri.co.kr"
                                  platformUrl: "https://app.…"
marketing/src/content/global.ts   같은 두 줄
```

플랫폼 주소는 `NEXT_PUBLIC_PLATFORM_URL` 로도 덮을 수 있어서, 배포 환경에서
먼저 시험해 보고 원고를 고쳐도 된다.

그리고 `regions` 목록의 `live: false` 를 살아 있는 나라만 `true` 로 바꾼다.
**아직 안 열린 나라를 열린 것처럼 두지 않는다.**

## 5. 아직 아닌 것

- **등록 자체.** 결제와 명의가 필요해서 코드에서 할 수 있는 일이 아니다
- **`metri.io` 소유자 확인.** whois 가 막혀 있어 이 컨테이너에서는 못 본다
- **`metri.co.kr` 등록 여부.** 같은 이유로 못 본다. DNS 가 조용한 것은
  비어 있다는 뜻이 아니다
- **'메트리' 상표.** KIPRIS 도 막혀 있다. 이름을 확정하기 전에 볼 것
- **호스팅.** 도메인이 정해져야 인증서와 DNS 레코드를 정한다
