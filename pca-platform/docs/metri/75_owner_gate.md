# 75 · Owner Test 전 최종 Gate

이 문서는 **사람이 눌러야 답이 나오는 것만** 모았다. 기계가 셀 수 있는
것은 전부 `npm run v3:gate` 와 `npm run v3:all` 이 이미 센다.

판정을 세 가지로 적는다.

- **AUTOMATED PASS** 이 기계의 배포본에서 기계가 세어 통과했다
- **OWNER ACTION REQUIRED** 조건희가 직접 해야 답이 나온다
- **UNKNOWN** 이 세션에서 볼 수단이 없다 (BLOCKED 와 섞지 않는다)

**`EXTERNAL BROWSER PASS` 는 한 줄도 없다.** 이 컨테이너의 네트워크
정책이 `app.careermatri.com:443` 을 막는다(`connect_rejected`). 403 은
정책이고 사이트가 죽었다는 뜻이 아니다.

## STEP 1 · DB 가 지금 코드까지 올라와 있는가 (가장 먼저)

**이것부터 한다.** 이번 commit 이 스키마를 바꾸지 않은 것과, 운영 DB 가
지금 코드까지 올라와 있는 것은 **다른 질문**이다. 앞 회차에서 운영에
`career_profiles` 가 선 적이 없어 `/me` 가 500 이었고, 그 고침은
**이미지 안에 들어가는 스크립트**였다. 재배포는 끝났으므로 이제 그
컨테이너에서 한 줄을 쳐야 표가 선다.

Railway → 서비스 → `⋯` → **Shell** 에서 차례로:

```bash
npm run db:verify
```

- `핵심 표 7 / 7` · `ME_V3 표 5 / 5` · `내 CareerMatri 5 / 5` 와
  마지막 줄 `팔 수 있는 상태입니다` 가 나오면 **STEP 2 로 간다**
- 셋 가운데 하나라도 모자라면 **pending migration 이 있는 것**이고,
  아래를 이어서 친다

```bash
npm run db:upgrade
npm run db:verify
npm run ops:check
```

`db:upgrade` 는 **기존 자료를 건드리지 않는다**: 올리는 파일이 전부
`IF NOT EXISTS`·`ON CONFLICT` 이고 모든 psql 이 `--single-transaction`
이며, `DROP TABLE` 과 `TRUNCATE` 와 `db:init` 이 0건이다. 두 번 쳐도
같다(이 기계에서 운영 배치를 재현해 두 번 돌려 줄 수와 md5 가 같은 것을
확인했다).

> 컨테이너의 `npm run` 이 아는 것은 여덟뿐이다: `db:init` · `db:upgrade`
> · `db:verify` · `make:admin` · `ops:check` · `pg:smoke` ·
> `pg:confirm` · `pilot:check`. **다른 이름을 치면 `Missing script` 다.**

**판정: OWNER ACTION REQUIRED.** 이 세션에는 Railway Shell 권한이 없어
돌리지 못했고, 돌렸다고 적지 않는다.

## STEP 7 · PDF (P0)

`결과 PDF 저장` 을 누른다. **세 등급 전부** 한 번씩 본다.

| 보는 것 | 합격 |
|---|---|
| 상태 | 200 (파일이 받아진다) |
| 쪽 | 빈 쪽이 없다 |
| 글자 | 내부 코드가 없다 |
| 실패 쪽 | 503 사람 쪽이 **안 떠야** 한다 |

**못 뽑히면** 날글자 대신 사람이 읽는 쪽이 뜨고, 그때
`/admin/incidents` 에 줄이 하나 앉는다. 그 줄과 Railway 로그의
`[v3-pdf]` 한 줄을 그대로 주시면 된다. 모양은 이렇다.

```
[v3-pdf] attempt=1234 tier=BASIC step=open base=https://... chromium=/usr/bin/chromium tried=5 :: ...
```

- `step` 이 `browser` 면 브라우저를 못 띄운 것이고 `chromium=` 뒤가
  **운영 알파인에서 실제로 잡힌 경로**다
- `step` 이 `open` 이면 결과지 쪽을 못 연 것이고 `base=` 가 그 주소다
- `step` 이 `render` 면 쪽은 열렸는데 본문이 안 선 것이다

**chromium 후보를 다섯으로 넓힌 것이 운영에서 맞는지는 이 한 줄로만
확정된다.** 이 컨테이너에서 운영과 같은 알파인 이미지를 빌드하지 못해
(저장소가 403 으로 막힌다) 미리 답할 수 없다.
