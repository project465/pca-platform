# PHASE 1 — 이미 있는 Core 에 갈래만 더해 자리를 열었다 (2026-10-13)

새 Core 를 하나도 만들지 않았다. 더한 것은 **갈래 일곱**이고, 그 갈래로
배재대의 자리 **열여덟**이 `자료가 다 선 상태`(ASSESSMENT_READY)로 올라섰다.
문항 은행 · 채점 · 소유 판정 · 묶음 규칙 · 결과 모델 · DB 스키마가 한 줄도
바뀌지 않았다.

## 1. Coverage

```
배재대 선택 자리            117  (재학생 Catalog 57 · 2027 Catalog 60)
  자료가 다 선 자리           42   ← 24 에서 42 로
  아직 Core 가 없는 자리      73
  전공 탐색(자율전공)          2
```

| Core | 자리 | 갈래 |
|---|---|---|
| `BIZ_CORE_V1` 경영 | 24 | 경영 일반 · IT경영정보 · 글로벌비즈니스 · 관광경영 · 호텔항공경영 · 항공서비스 **+ 스포츠마케팅 · 지역소상공비즈니스 · 부동산재테크 · 농산업비즈니스 · 문화·콘텐츠 비즈니스** |
| `CS_CORE_V1` 컴퓨터·소프트웨어 | 11 | 컴퓨터공학 · 소프트웨어학 · 정보보안 · 게임공학 · 인공지능·데이터 **+ 글로벌IT** |
| `EE_CORE_V1` 전기전자공학 | 7 | 전기·전력 · 전자·회로 **+ 스마트배터리 · 드론·로봇** |

**`ME_CORE_V3` 기계공학은 배재대에 자리가 없다.** 그 학교의 두 Catalog
어디에도 기계공학 계열 모집단위가 없어서다. 열려 있는 Core 가 넷이고
그 가운데 셋만 이 학교의 자리를 연다.

## 2. 더한 갈래 일곱

| Core | 갈래 | 그 갈래가 조정하는 것 |
|---|---|---|
| EE | `SPEC_EE_BATTERY` 스마트배터리 | 전력전자 · 에너지·신재생 · 계측·시험을 먼저 읽는다 |
| EE | `SPEC_EE_ROBOT` 드론·로봇 | 제어·자동화 · 임베디드·펌웨어 · 신호처리를 먼저 읽는다 |
| CS | `SPEC_CS_GLOBAL_IT` 글로벌IT | 서버·API · 설계·구조 · 테스트·품질·배포를 먼저 읽는다 |
| BIZ | `SPEC_BIZ_SPORTS_MKT` 스포츠마케팅 | 마케팅·시장 · 고객·서비스 운영 · 영업·사업개발 |
| BIZ | `SPEC_BIZ_LOCAL_SME` 지역소상공비즈니스 | 영업·사업개발 · 회계·원가 · 운영·프로세스 |
| BIZ | `SPEC_BIZ_REALESTATE` 부동산재테크 | 재무·투자 판단 · 회계·원가 · 경영전략·기획 |
| BIZ | `SPEC_BIZ_AGRI_BIZ` 농산업비즈니스 | 영업·사업개발 · 운영·프로세스 · 회계·원가 |
| BIZ | `SPEC_BIZ_CULTURE_BIZ` 문화·콘텐츠 비즈니스 | 마케팅·시장 · 경영전략·기획 · 글로벌 비즈니스 |

**갈래는 Core 판정을 바꾸지 않는다**(`specialization_contract`). 조정하는
다섯 층은 영역을 설명하는 차례 · 산업 mapping · 역할 mapping · 예시 ·
Evidence 와 할 일의 문면이고, 건드리지 않는 다섯은 채점 · 축 수준 · 묶음
규칙 · 문항 은행 · 결과 모델이다. 같은 응답에 갈래만 바꿔 돌리면 Core
판정의 지문이 글자까지 같다는 것은 `v3:provenance` 가 센다.

## 3. 묶은 자리와 그 까닭

- **스마트배터리 → 전기전자.** 셀·모듈·충방전·보호회로가 전력전자와
  에너지 영역 안이다.
- **드론로봇 → 전기전자.** 구동과 센서와 제어와 전원이 이미 그 Core 의
  영역이다. **판단 Domain 자체가 다르다는 것이 전공자 검토에서 확인되면**
  그때 따로 만든다.
- **글로벌IT·AI → 컴퓨터·소프트웨어.** 인공지능 쪽은 그 Core 의
  기계학습·데이터 분석 영역이 든다.
- **스포츠마케팅 → 경영.** 묻는 것이 고객·채널·가격·성과다. **건강재활
  쪽은 이 Core 가 들지 않는다**: 같은 학부 안에 있어도 판단 단위가 다르다.
- **지역소상공·부동산재테크·농산업비즈니스·아트컬처/K컬처 → 경영.** 판단
  단위가 사업 기획과 원가와 고객이다. 농산업은 **기르는 일이 아니라 상품으로
  만들어 내보내는 일**을 묻는 자리이고, 기르는 쪽은 원예·산림 Core 가 든다.
- **글로벌경영 → 글로벌비즈니스 갈래 · 국제의료관광 → 관광경영 갈래.**
  둘 다 이미 있는 갈래이고 새로 만들지 않았다.

## 4. 자리마다 끝까지 밟았다

```bash
UI_BASE=http://127.0.0.1:3100 npm run pcu:coverage
```

자료가 다 선 자리 **42개 전부**를 제품과 같은 길로 지난다: 학과 맥락으로
응시를 열고 · 끝까지 답하고 · 제출하고 · 로그인한 본인으로 결과 쪽을 열어
학교와 학과와 갈래 이름이 적히는지와 안쪽 코드가 새지 않는지를 본다.
**종이는 갈래마다 한 자리씩** 뽑는다: 갈래가 Core 판정을 바꾸지 않으므로
종이의 모양을 정하는 것은 Core 와 등급이고, 자리마다 뽑으면 같은 것을
마흔두 번 센다. 결과는 **확인 44가지 · 통과 44 · 걸림 0** 이고 뽑은 종이
열두 벌이 전부 6쪽(BASIC)이다.

**학과 상세에서 눌러 들어가는 길은 따로 밟는다.** `core:walk` 가
`LEAF` 로 자리를 고를 수 있게 되어, 새로 연 자리 셋(드론로봇 · 글로벌IT ·
스포츠마케팅)을 실제 브라우저로 끝까지 눌렀다(각 26가지 통과).

```bash
UI_BASE=http://127.0.0.1:3100 CORE=EE_CORE_V1 LEAF=PCU26_DRONE TIER=STANDARD \
  npx tsx scripts/core-walk.ts
```

**닫아 둔 Core 는 세는 동안만 열고 반드시 되돌린다.** 두 검사 모두 등록부
두 복사본의 지문을 전후로 견주어 되돌아온 것을 확인한다.

## 5. 아직 아닌 것

**학생에게 열지 않았다.** 세 Core 모두 `open_to_students: false` ·
`READY_FOR_DOMAIN_REVIEW` 다. 전공자 검토와 인지 면접과 실제 응답 기반
신뢰도·타당도 검증을 하지 않았으므로 `검증된 검사` 로 팔지 않고 규준도
백분위도 적합도 비율도 내지 않는다.

**새로 쓴 갈래 일곱은 전공자 검토를 기다린다.** 기계가 셀 수 있는 것은
가리키는 영역과 산업과 역할이 그 Core 안에 있는 코드인가까지이고, 그
차례가 그 전공의 현장과 맞는지는 사람이 읽어야 한다.

**남은 자리 일흔셋**은 새 Core 가 있어야 열린다. 차례는
`docs/metri/PCU_FULL_COVERAGE_PLAN.md` 의 Core 열여섯이다.
