# ME_V1 실사용 감사

2026-10-07 결정: ME_V1(253문항)을 바로 지우지 않는다. 신규 판매와 신규
진입만 막고 **기존 결과의 열람과 재현을 남긴다.** archive 로 넘길 수
있는지는 실사용이 있는지 보고 정한다.

## 1. 보는 다섯 자리

`npm run v1:audit` 이 센다. **한 줄도 쓰지 않는다**: `UPDATE` 와 `INSERT`
가 그 파일에 없고 판정도 적지 않는다. 숫자를 보고 사람이 정한다.

| 보는 것 | 어디서 | 왜 |
|---|---|---|
| ME_V1 응시 전체와 최근 90일 | `attempts` × `responses` | 사람이 지금 쓰고 있는가 |
| 열려 있는 회차 | `test_sessions.closes_at` | 지금 응시할 수 있는 자리가 있는가 |
| ME_V1 을 쓴 계약과 기관 수 | `contracts` × `test_sessions` | 연락할 곳이 있는가 |
| 안 쓴 좌석 | `seats.status` | 산 사람이 쓸 자리가 남았는가 |
| ME_V1 결과 스냅샷 | `report_snapshots.assessment_version` | 열람을 남겨야 하는 결과의 수 |

판본을 가리는 방법은 표로 가른다. `responses` 에 줄이 있는 응시가 ME_V1
이고 `v2_responses` 에 줄이 있는 응시가 ME_V2 다. 두 표를 나눠 둔 것이
그 자체로 판본 표시다(설계 원칙 8).

## 2. 홈페이지도 같이 센다

홈페이지의 학과 계약 결과지 예시가 ME_V1 출력이다. 직무 적합도 100점과
1군 묶음과 업무 성향 여섯은 ME_V1 이 **실제로 계산하는** 값이라 지금
남겨 두었는데, ME_V1 을 접으면 그 절이 **아무 제품도 가리키지 않는다.**
그래서 DB 없이도 그 네 자리를 함께 적는다.

## 3. 판정 둘

| 결과 | 그때 하는 일 |
|---|---|
| 실사용 계약이 있다 | 그 계약 범위에서만 살려 두고 신규 진입만 막는다 |
| 실사용 계약이 없다 | `archived` 로 넘기고 홈페이지의 ME_V1 결과 예시를 내린다. `claims:check` 금지 목록에 그 모양을 더한다 |

## 4. 지금 돌려 본 결과

**개발 DB 에서 돌린 값이고 운영이 아니다.** 운영 값은 컨테이너 안에서
사람이 한 번 돌려야 나온다.

| 자리 | 개발 DB 값 |
|---|---|
| ME_V1 응시 전체 | 0 |
| ME_V2 응시 전체 | 29 |
| 최근 90일 ME_V1 응시 | 0 |
| 열려 있는 회차 | 0 |
| ME_V1 을 쓴 계약 | 0 |
| 안 쓴 UNIV 좌석 | 0 |
| 안 쓴 계약 좌석 | 40 (시연 자료) |
| ME_V1 결과 스냅샷 | 0 |
| 상품 `REPORT_UNIV` · `UNIV_FREE` · `UNIV_UPGRADE` | 셋 다 켜짐 |

개발 DB 에는 ME_V1 응시가 없다. 그러나 **이 값으로 archive 를 결정하지
않는다**: 운영 DB 를 안 봤고, 학과 계약이 그쪽에 있을 수 있다. 상품 셋이
켜져 있는 것은 지금 상태이고, 신규 판매를 멈추려면 그 셋을 꺼야 한다.

## 5. 다음에 할 일

```bash
# 운영 컨테이너 안에서 (Railway → 서비스 → ⋯ → Shell)
npm run v1:audit
```

읽기만 하므로 운영에서 돌려도 아무것도 바뀌지 않는다. 결과를 보고 셋을
정한다. 상품 셋을 끌지 · 회차를 닫을지 · 홈페이지 예시를 내릴지.

## 6. 보존은 말이 아니라 지문으로

ME_V1 의 문항 은행과 전공 Skill Tree 셋을 `v2:frozen` 이 함께 잠근다.
잠근 파일은 열둘이고, 한 글자만 바뀌어도 걸린다.

```
ME_V2_DECISION_2026  assessment/ME_V2/*.json 여덟
PCA_ME_V1            items_pca_me_v1.json · major_{ME,EE,CE}.json 넷
```

**ME_V2 와 ME_V3 자료와 합치지 않는다.** 직무군 열여섯과 기술영역 열둘
사이에 1 대 1 사상이 없어서, 합치면 어느 쪽도 아닌 값이 나온다.
