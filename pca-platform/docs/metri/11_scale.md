# 월 5억까지 가는 길 — 정직한 산수

> 결론부터. **진단만 팔아서는 월 5억이 안 된다.**
> 진단은 입구이고, 돈은 **진단이 특정해 준 교육 수요**에서 나온다.
> 이건 희망이 아니라 나눗셈이다.

---

## 1. 먼저 가격을 근거로 정한다

| 비교 대상 | 가격 | 출처 |
|---|---|---|
| **정식 MBTI 온라인 검사** | **약 30,000원** (검사+결과만, 상담 별도) | 이투데이 체험 기사 |
| 코멘토 직무부트캠프 5주 | **정상가 약 300,000원** | 코멘토 |
| K-디지털 기초역량훈련 크레딧 | **50만 원** (내일배움카드) | 고용노동부 |
| 고용24 직업심리검사 | **무료** | 고용노동부 |
| 홀랜드 자가채점 세트 | 11~12만 원 (교사용 세트, 1인 단가 아님) | 유통가 |

**읽는 법 세 가지.**

1. **3만 원이 개인 검사의 천장이다.** MBTI 라는 이름값이 그 값을 받는데,
   METRI 가 첫해에 그걸 넘으면 "왜 더 비싼가" 를 매번 증명해야 한다.
2. **무료 대체재가 있다** (고용24). 그래서 개인에게 파는 싸움은 이기기 어렵다.
   개인 매출은 부가로 잡고, 본진은 기관이다.
3. **교육 단가가 진단의 10배다.** 30만 원 대 3만 원. 여기가 진짜 시장이다.

### 정하는 값

| 상품 | 값 | 이유 |
|---|---|---|
| 개인 전체 리포트 | **정가 39,000 / 재학생 29,000** | MBTI 3만 원 아래로 붙인다. 정가를 걸어두는 건 학과 계약의 가치를 보이기 위해서다 |
| 학과 단체 (500명) | **1인 28,000 · 연 1,400만** | 개인가와 같은 수준에 학과 리포트가 덤으로 붙는 구조 |
| 고교 (300명) | 1인 15,000 | 학교 예산 단가가 낮다 |
| 무료 간이 진단 | 0 | 12문항. 1순위 직무까지 공짜 |

---

## 2. 진단만으로 월 5억이 되는지 나눠 본다

```
월 5억 = 연 60억
학과 하나 = 500명 × 28,000원 = 1,400만 원

60억 ÷ 1,400만 = 429개 학과
```

한국 4년제 대학은 190여 개이고 공학계열 학과는 대략 2,000개 남짓이다.
**429개면 전체의 20%를 1년 안에 먹어야 한다.** 안 된다.

가격을 올려도 마찬가지다. 공대 전체 3,000명 패키지(6,600만)로 팔아도
**91개 대학** — 4년제 대학의 절반이다. 역시 1년은 아니다.

**그래서 진단만 파는 회사로는 이 숫자에 못 간다.** 여기서 멈추면 안 된다.

---

## 3. 돈이 어디 있는지 다시 본다

코멘토는 교육을 판다. 5주 부트캠프 30만 원이고, 경북대·전남대 반도체특성화
대학사업단이 **사업비로 그걸 샀다.** 대학은 진단보다 교육에 훨씬 큰 돈을 쓴다.

그런데 코멘토에는 없는 것이 있다.

> **누구에게 무슨 교육을 팔아야 하는지 모른다.**
> 300종 과정을 차려놓고 학생이 고르게 한다. 학과 담당자도 감으로 고른다.

METRI 는 그걸 숫자로 안다.

```
기계공학과 487명 집계
  GD&T 충족률 31%
  지역 공고 1,240건 중 67% 가 GD&T 를 요구
  → 겹치는 칸. 대상 학생 372명
```

**이 한 줄이 곧 견적서다.** 학과가 이미 문제를 인정한 상태에서 해결책을 파는 것이라
전환이 다르다. 이게 경쟁사 분석에서 찾은 빈 자리와 정확히 같은 자리다.

| 경쟁자 | 가진 것 | 없는 것 |
|---|---|---|
| Lightcast Skillabi | 프로그램–노동시장 정렬 | **학생 개인이 없다** |
| Cognavi | 개인 Skill Tree 매칭 | **학과 집계가 없다** |
| SkillsFuture | 국가 표준 프레임워크 | **학생 진단이 없다** |
| 고용24 잡케어 | 무료·전 국민 | **공학 특화도 학과 집계도 없다** |
| 코멘토 | 교육 300종·대학 채널 | **진단이 없다. 누구에게 팔지 모른다** |
| **METRI** | **개인 진단 → 학과 집계 → 교육 수요 특정** | 아직 교육 공급 |

## 4. 교육을 붙이면 숫자가 달라진다

학과 하나에서 나오는 매출을 다시 센다.

| | 금액 | 근거 |
|---|---|---|
| 진단 500명 | 1,400만 | 1인 28,000 |
| 교육 전환 20% × 30만 | **3,000만** | 100명. 코멘토 정상가 기준 |
| 학과 맞춤 캠프 1건 | 1,200만 | 3일·30명 |
| **학과 하나 합계** | **약 5,600만** | |

```
60억 ÷ 5,600만 = 107개 학과
```

**429개에서 107개로 줄었다.** 여전히 크지만 이건 3년이면 닿는 숫자다.

**전환율 20%가 이 계산의 급소다.** 근거는 두 가지다 —
진단이 부족 역량을 이미 지목했고(무작위 권유가 아니다), 학과가 그 명단을 갖고 있다.
검증 전까지는 추정이므로 1차 100명 검증에서 이 값을 반드시 잰다.

### 국비지원이 전환율을 바꾼다

코멘토는 K-디지털 기초역량훈련으로 간다. **내일배움카드 크레딧 50만 원**이면
학생 자부담이 거의 없다. 전환율 20%가 아니라 그 이상이 나온다.

METRI 자체는 훈련과정이 아니라 진단이라 KDT 에 직접 편입되지 않는다.
대신 **KDT 훈련기관의 사전진단 모듈**로 들어갈 수 있다.
훈련기관의 최대 골칫거리가 중도탈락률인데, 미스매치를 줄여주는 도구는 그들에게 값이 있다.
이건 별도 채널이고, 4차에 검토한다.

## 5. 월 5억의 구성 (3년차 목표)

| 구성 | 월 매출 | 연 매출 | 어떻게 |
|---|---|---|---|
| 학과 진단 B2B | 1.0억 | 12억 | 86개 학과 × 1,400만 |
| **교육 (진단이 만든 수요)** | **2.0억** | **24억** | 진단 학생의 20%가 30만 원 과정 |
| 지자체·RISE 사업 수주 | 1.0억 | 12억 | 대형 4~6건. 앵커 예산 |
| B2C 개인 | 0.5억 | 6억 | 월 1,700건 × 29,000 |
| 고교·교육청 | 0.5억 | 6억 | |
| **합계** | **5.0억** | **60억** | |

**교육이 40%다.** 진단은 20%뿐이다.
그런데 진단이 없으면 나머지 80%가 안 팔린다 — 그게 METRI 의 자리다.

### 연차별

| | 1년차 | 2년차 | 3년차 |
|---|---|---|---|
| 계약 학과 | 8 | 30 | 86 |
| 진단 매출 | 1.1억 | 4.2억 | 12억 |
| 교육 매출 | 0.3억 | 6억 | 24억 |
| 사업 수주 | 0 | 3억 | 12억 |
| 개인·고교 | 0.1억 | 1.5억 | 12억 |
| **연 합계** | **1.5억** | **약 15억** | **약 60억** |
| **월 환산** | 0.13억 | 1.25억 | **5.0억** |

**1년차가 관문이다.** 8개 학과에서 교육 전환율을 실측해야
2년차 계획이 희망이 아니라 계산이 된다.

## 6. 그래서 무엇을 바꾸는가

1. **홈페이지가 "진단 파는 사이트" 로 보이면 안 된다.** ✅ 2026-09-11 반영
   학과 담당자가 사는 것은 진단이 아니라 **커리큘럼을 손볼 근거**다.
   네 사이트 홈에 `gap` 절을 넣었다 — 487명 → 충족률 31% → 공고 요구 67% →
   **대상 372명** 이 왼쪽에서 오른쪽으로 좁혀지고, 마지막 칸이 곧 견적서다.
   그 아래 도구 갈래 표가 다섯 갈래의 빈칸을 보여준다.
   원고는 `marketing/src/content/{kr,global,kz,tr}.ts` 의 `gap`,
   화면은 `GapSection` 이다.

   **경쟁사 이름을 적지 않았다.** 공개 사이트에서 특정 회사를 지목해
   "이것이 없다" 고 쓰는 것은 영업에 쓰기 전에 법무 확인이 필요하다.
   그래서 회사명 대신 갈래(노동시장 정렬 분석 · 개인 매칭 · 국가 프레임워크 ·
   무료 공공검사 · 직무교육 플랫폼)로 적었다. 논지는 그대로 살아 있고,
   영업 자료에서는 실명 표를 써도 된다 — 그건 공개 게시물이 아니다.
2. **학과 리포트의 마지막 칸이 제품이다.** "그래서 학과가 할 일" —
   개설 과목, 비교과 캠프, 개인 처방 발송. 세 줄 다 우리 매출이다
3. **교육 공급을 붙여야 한다.** 자체 개설이든 제휴든.
   진단만 팔면 우리가 만든 수요를 남이 가져간다
4. **1차 검증에 전환율 측정을 넣는다.** Top-3 수용률 70% 옆에
   **교육 전환율 20%** 를 같은 무게로 둔다
