# 레퍼런스 화면을 구현 기준으로: 화소 분석과 토큰 (R26)

목표 화면은 `docs/metri/shots/reference/reference-home-desktop.png`
(1448×1086 · 2026-10-11 수령)이다. 같은 설계의 저해상도 판
(`reference-home-2026-10-18.png` · 807×610)이 함께 있고, **이 회차는
고해상도 판으로 다시 잰다.** 저해상도 판은 데스크톱 그림의 폭이 573px
이라 1440 으로 올리는 배율이 2.51 이고, 한 화소의 오차가 2.5 화소가 된다.
고해상도 판은 1012px 이라 배율이 1.42 다.

재는 자는 둘이다.

```
scripts/lab/r26_ref.py      # 그림의 화소를 읽는다
python3 - <<'PY' ... PY     # 자리마다 불러 쓴다
```

**잉크 높이로 재지 않는다.** 올려 그린 그림은 가장자리가 번져 잉크
높이로 재면 글자가 한 단 커 보인다. 재는 것은 **가로 잉크 ÷ 그 글의
진폭(em)** 이고, 섞인 글(숫자·가운뎃점·라틴)은 진폭이 글꼴마다 달라
**한글만 이어진 토막**으로 잰다.

그 자리에서 가운뎃점의 진폭이 1em 이 아니라 **0.34em** 이라는 것이
드러났다. `구조·내구` 로 재면 13.7em 이 나오고 `해석` 으로 재면 15.8em
이 나온다. 섞인 토막으로 재면 20% 가 틀어진다.

## E. 여백 (§7)

잰 값을 4 의 배수로 모으면 이렇다.

```
8   절 머리 → 거드는 줄(7)
16  칸 사이(16) · 거드는 줄 → 타일(19)
24  (쓰는 자리 없음)
32  본문 좌우 여백(34 · 31) · Hero → 절 머리(30)
48  절 → 절(48 · 51)
64  Hero 안쪽 좌우 여백(67) · CTA 높이(64)
```

**이 여섯은 `surface.css` 의 `--ui-2 · --ui-4 · --ui-5 · --ui-6 ·
--ui-7 · --ui-8` 과 같다.** 여백은 고칠 것이 없고, 고쳐야 하는 것은
**어느 자리에 어느 단을 쓰는가**다.

레퍼런스가 쓰는 세로 리듬은 **세 단**뿐이다.

| 사이 | 값 |
|---|---|
| 한 묶음 안(머리 ↔ 거드는 줄) | 8 |
| 묶음 ↔ 담긴 것 | 16~20 |
| 절 ↔ 절 | 48 |

## F. 레퍼런스의 구조 문법 (§2)

```
SIDEBAR + MAIN WORKSPACE
MAIN:  PAGE TITLE → PRIMARY ACTION HERO → CURRENT STATE
       → RECENT CHANGES → RECENT RECORDS
```

**다섯 절이 다섯 가지 생김새를 쓴다.** 이것이 이 그림에서 가져올 첫째
규칙이다.

| 절 | 생김새 | 담는 것 |
|---|---|---|
| PAGE TITLE | 면도 테도 없다 | 이름 한 줄 + 메타 한 줄 |
| PRIMARY ACTION HERO | **이 쪽에서 면을 가진 유일한 자리** | 눈썹+표시 · 두 줄 큰 글 · 본문 한 줄 · 채운 단추 · 글줄 링크 · 오른쪽 그림 |
| CURRENT STATE | 절 머리(표시+이름+오른쪽 링크) + 거드는 줄 + **흰 카드 셋** | 배지 · 이름 · 거드는 줄 · 꺾쇠 |
| RECENT CHANGES | 같은 절 머리 + **카드 없는 줄** | 작은 표시 · 한 문장 · 날짜 |
| RECENT RECORDS | 같은 절 머리 + **줄 + 단추 둘** | 표시 · 이름/번호 · 날짜 · 단추 둘 |

**되풀이되는 것은 절 머리 하나뿐이다.** 표시(22~44px) + 절 이름(0.86) +
오른쪽 링크(0.59), 그 아래 거드는 줄(0.56). 넷이 늘 같은 자리에 선다.

**카드는 한 절에만 있다.** 나머지 둘은 줄이고, 줄끼리는 가는 금으로만
갈린다.

## G. Result 를 같은 문법으로 (§3)

| 규격의 자리 | 레퍼런스에서 빌려오는 생김새 | Result 가 담는 것 |
|---|---|---|
| HERO | PAGE TITLE | 신분 한 줄 · 그 사람이 고른 문장 한 줄 · 손에 남은 것 |
| CURRENT STATE | CURRENT STATE 의 카드 셋 | 지금 설명할 수 있는 영역 셋(배지 · 이름 · 상태 · 꺾쇠) |
| PRIMARY ACTION | PRIMARY ACTION HERO | 눈썹 · 두 줄 큰 글 · 까닭 한 줄 · 채운 단추 · `그 밖에 할 일 N개` |
| EVIDENCE | RECENT RECORDS 의 줄 | 경험마다 한 줄(표시 · 한 일/남긴 것 · 쓰는 자리 · 단추) |
| NEXT ACTION | RECENT CHANGES 의 줄 | 나머지 할 일 줄 |
| DETAIL | — | 펼침 안 |
| WORKSPACE CONTINUATION | — | 닫는 자리 한 줄 |

**§13 이 이 회차의 범위를 셋으로 못 박았다**: HERO · CURRENT STATE +
PRIMARY ACTION · EVIDENCE 의 들머리. 그 아래는 승인 뒤다.

| 근거 들머리 | 줄 셋이 바탕 위에 떠 있다 | 흰 면 하나 안에. 줄 사이 금은 면보다 한 단 옅게 |
| 가운뎃점 | 좁은 화면에서 **다음 줄의 첫 글자**로 섰다 | `li + li::before` → `li:not(:last-child)::after` |
