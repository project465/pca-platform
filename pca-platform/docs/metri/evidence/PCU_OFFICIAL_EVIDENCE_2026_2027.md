# CareerMatri × 배재대학교 — 2026/2027 학과 편제 근거 및 Claude 수정 지시

조사 기준: 2026-10-12. **이 문서는 공식 사이트에 공개된 연도별 대학·학과 안내를 사람이 대조해 정리한 연구용 전달 자료**다. Claude 실행환경에서 직접 접속·검증한 것은 아니다. 본 문서만으로 원본 웹사이트 직접 접근이 성공했다고 주장하거나 `verified_at`에 허위 시간을 입력하지 말 것.

## 3. 다른 단과대학의 연도별 학부·학과 근거 요약

아래는 대학 공식 연도별 페이지의 학과 이름을 정리한 것이다. 학과/학부/전공/트랙을 구분해야 하며 **모든 기재 항목이 반드시 CareerMatri 응시 선택지가 되는 것은 아니다.** '교직과·교직부'는 행정 교육조직일 수 있으니 학생 응시 대상에서 자동 포함하지 말 것. 외국인 전공 및 평생학습 전공의 포함 여부 역시 계약 범위와 학생 계정 대상에 맞게 결정할 것.

### 2027년 공식 대학·학과 안내 (최상단 '2027년' 탭)

- **인문사회대학**: 국어국문한국어교육학과; 일본학과; 경찰법학부(경찰학/법학 전공, 2학년 선택); 행정학과(일반행정/소방행정 트랙); 심리상담학과; 유아교육과. 별도로 '교직과' 표시.

## 4. 2026→2027 추가 차이 목록

- 전기전자공학과 → 전기공학과 (정확한 개편 계보는 명칭 유사성만으로 결정 불가).
- 소프트웨어공학부 4전공 → AI소프트웨어공학부 5전공; 인공지능전공 추가.
- 드론로봇공학과 → 피지컬AI공학부(드론로봇공학/AI융합전자). 동일 Core 가능 여부를 신규로 판단해야 함.
- 공연예술학과 음악·영화영상 트랙 → 공연예술학부 실용음악·영화영상학 전공: 학과와 전공이 동일한 레벨인지 주의.
- 평생교육융합학부 전공 목록: 라이프케어→사회복지상담, 지역소상공비즈니스→농산업비즈니스, 시니어운동처방→시니어운동처방·파크골프 등. 개편 관계를 확정하지 못하면 `replaces`를 임의 설정하지 말 것.
- 글로벌융합학부: 2026년 6전공 → 2027년 7전공. 2027년에는 K컬처비즈니스, 글로벌IT·AI, K푸드테크 명칭이 나옴. 학교 안내와 입시 모집단위의 범위 차이 확인 필요.
- 2027 입학안내 랜딩 화면은 '철도건설학과'라고도 표기하나, 공식 2027 대학·학과 연도 탭 및 정시 모집요강의 '철도건설공학과'를 우선 대조할 것.

## 6. 정확성 및 한계

- 대학 공식 **연도별 페이지를 참조해 2026과 2027을 명확히 분리**한 자료이다.
- 과거 공지에 포함된 2027 **시행계획은 이후 정시/수시 모집요강과 충돌**한다. 연도별 최신 자료를 우선 검토한다.
- 본 문서는 학사 편제에 대한 **근거 제공용**으로, 학교가 실제 2026년 기존 재학생 중 복학·편입·학과개편자를 어떻게 소속 처리하는지 확인해 주지는 않는다. 학생 개인의 학적을 기계적으로 학년도에 대입하지 말 것.
- 본 파일의 이름·목록은 공식 학과 안내를 기준으로 정리했으나, 최종 운영 반영은 적합성 정책과 학교 계약 요건을 확인한 후 진행할 것.
