# 판정 규칙

## 1. 보기 넷의 뜻

문면은 축의 `l2` 행동을 묻고 **보기가 누가 그 행동을 소유했는가**를 받는다.
뜻은 `ownership.ts` 한 곳에 있고 화면과 문서와 채점이 같은 표를 읽는다.

| 코드 | 보기 | 뜻 |
|---|---|---|
| `NONE` | 없다 | 그 일을 해 본 적이 없다 |
| `RECEIVED` | 남이 한 것을 받아 썼다 | 남이 정한 조건이나 결과를 받아 썼다. **도구를 돌리기만 한 것이 여기다** |
| `DID` | 내가 했다 | 그 일을 내가 했다. 판단에 참여한 범위까지가 여기다 |
| `DECIDED_USED` | 내가 정했고 그 결과가 쓰였다 | 조건이나 기준을 내가 정했고 그 결과가 다음 작업에 쓰였다 |

**`해석 프로그램을 돌렸다` 와 `해석 조건을 정했다` 가 같은 칸에 들어가지
않는다.** 조건을 받아 쓴 쪽은 `RECEIVED` 이고 확인으로 세지 않는다.

## 2. 축 하나의 상태

| 상태 | 언제 |
|---|---|
| `NOT_OBSERVED` | 답이 없거나 `없다` 를 골랐다 |
| `PARTICIPATED` | `RECEIVED`. **확인이 아니다** |
| `CONFIRMED` | `DID` 거나, `DECIDED_USED` 인데 근거가 둘에 못 미친다 |
| `OWNED` | `DECIDED_USED` 이고 **근거가 둘 이상**이다 |

**소유는 응답만으로 서지 않는다.** 근거는 그 축에서 고른 판단 체크리스트
항목과, 산출물 축이면 고른 산출물, 비교·검증 축이면 고른 검증 대상,
그리고 한 칸에 문항이 둘인 자리에서 둘 다 확인인 경우다. 근거가 하나면
칸 하나를 채운 사람과 끌고 간 사람이 같아진다.

**한 칸에 문항이 둘이면 높은 응답을 쓴다.** 더해서 올리지 않는다.

## 3. 영역 하나의 상태

다섯 신호가 **따로** 나간다. 합쳐서 하나의 숫자를 만드는 자리가 없고,
그것을 검사가 센다.

| 신호 | 어디서 | 모양 |
|---|---|---|
| 관심 | 격자 | 1에서 5 · 낮음·중간·높음 |
| 경험 | 격자 | 없음 · 한두 번 · 여러 번 |
| 학습 의향 | 격자 | 1에서 5 · 낮음·중간·높음 |
| 확인된 판단 | 선별·심화 | 축 이름의 목록 |
| 소유한 판단 | 선별·심화 + 근거 | 축 이름의 목록 |
| 산출물 | J5 + 고른 산출물 | 상태 둘 |
| 검증 | J6 + 고른 검증 대상 | 상태 둘 |

## 4. 묶음

| 묶음 | 조건 |
|---|---|
| `Z1_EVIDENCE_ESTABLISHED` 근거가 선 영역 | 확인된 축 **넷 이상** + 그 영역의 **필수 축 둘 다 확인** + **J5 산출물 확인** + **고른 산출물 하나 이상** + 관심이 낮지 않음 |
| `Z2_EVIDENCE_INCOMPLETE` 근거가 아직 덜 선 영역 | 확인된 축이 하나 이상인데 위 조건을 못 채웠다. **까닭을 코드로 적는다** |
| `Z3_EVIDENCE_LOW_INTEREST` 근거는 있고 관심이 낮은 영역 | 위 조건을 채웠거나 확인된 축이 셋 이상인데 관심이 낮다 |
| `Z4_INSUFFICIENT_EVIDENCE` 판단할 근거가 부족한 영역 | **확인된 축이 하나도 없다** |
| `NOT_EXPLORED` 열지 않은 영역 | 그 영역의 심화가 열리지 않았다 |

**개수만으로 판정하지 않는다.** 확인된 축이 여섯인 사람이 떨어지고 넷인
사람이 서는 자리가 있다. 조건이 개수가 아닌 필수 축과 산출물이기 때문이다.

**Z2 와 Z4 를 섞지 않는다.** 많이 해 봤는데 남은 것이 없는 사람과 아직
아무 경험이 없는 사람은 완전히 다른 결과다. 앞엣것은 `남길 산출물 하나`
가 다음 걸음이고 뒤엣것은 `짧게 한 번 겪어 보기` 다.

**비교·검증이 비어도 근거는 설 수 있다.** 그 영역의 필수 축에 J6 이 있으면
막히고, 없으면 `MISSING_VERIFICATION` 을 다음 걸음으로만 남긴다.

### 4-1. 첫 쪽에 올리는 영역

근거가 선 영역이 먼저다. 없으면 덜 선 영역, 그것도 없으면 **관심이 높은
영역**이다. 아무 경험이 없는 사람도 방향은 받아야 한다. **묶음 안에서
차례를 만들지 않는다.**

### 4-2. 동점은 오류가 아니다

묶음과 확인 수와 소유 수와 관심이 같은 영역을 `tied` 에 그대로 적는다.
억지로 차례를 만들지 않고, BASIC 에서는 이것이 흔하다.

## 5. 관심과 근거를 네 칸으로

| 칸 | 뜻 | 다음 걸음 |
|---|---|---|
| `A_HIGH_HIGH` | 관심 높고 근거 있음 | 먼저 볼 후보 |
| `B_HIGH_LOW` | 관심 높고 근거 얕음 | `TRY_SHORT_EXPERIENCE` · 학습 의향이 높으면 `STUDY_NEXT` |
| `C_LOW_HIGH` | 관심 낮고 근거 있음 | `RECHECK_DIRECTION` |
| `D_LOW_LOW` | 둘 다 낮음 | `NOT_A_PRIORITY` |

관심이 중간이면 칸을 비운다(`null`). 더해서 한 점수로 만들지 않는다.

**학습 의향을 관심에 더하지 않는다.** 관심이 높고 경험이 없고 학습 의향이
낮으면 `더 공부하세요` 가 아니고 **짧게 한 번 겪어 보기**가 먼저다.

## 6. 등급

| 등급 | 쓰는 것 | 금지 |
|---|---|---|
| BASIC | 관심 · 경험 · 학습 의향 · 선별 네 축 | **근거가 섰다는 판정** · 축 이름 · 여덟 축을 센 값 |
| STANDARD | 여덟 축 · 체크리스트 · 산출물 · 검증 · 선호 · 일관성 | 번역 · 지원 문장 |
| PRO | 위에 경험 번역 · 목표 · 산업·역할 맥락 | 등급이 올랐다고 묶음이 올라가는 것 |

BASIC 의 영역 확인 수는 **0 으로 적는다**: 묻지 않은 축을 센 것으로 적지
않는다. 그리고 `tier_limits` 네 칸을 스냅샷에 적어, 결과지가 BASIC 에서
강한 말을 쓸 수 없게 한다.

**PRO 는 점수를 올리지 않는다.** 같은 응답을 STANDARD 와 PRO 로 돌리면
영역 묶음이 글자까지 같다(`v3:persona` 가 센다).

## 7. 응답 품질

| flag | 언제 |
|---|---|
| `INCONSISTENT` | 같은 축을 학교 장면과 실무 장면에서 물었는데 두 칸 이상 갈렸다 |
| `LOW_VARIANCE` | 격자 스물넷이 거의 한 값이다 |
| `REVIEW` | 반대 방향 두 문항을 함께 높게 답했거나, 체크리스트와 어긋났다 |
| `OK` | 걸린 것이 없다 |

**Core 를 깎지 않는다.** 따로 적어 두고, 결과지가 `이 결과는 좁게
읽으십시오` 를 붙인다. 어긋남은 **과대 보고 쪽만 센다**: `내가 정했고 그
결과가 쓰였다` 를 골랐는데 그 축에서 고른 항목이 하나도 없는 자리다.
`내가 했다` 에 항목이 비는 것은 흔한 일이라 세지 않는다. 세면 성실하게
답한 사람이 전부 `다시 볼 것` 으로 적힌다.

## 8. 빈 것의 네 가지

| 코드 | 뜻 |
|---|---|
| `NOT_ROUTED` | 그 문항이 이 응시에서 열리지 않았다 |
| `SKIPPED` | 봤는데 답하지 않았다 |
| `ANSWERED_NONE` | 겪은 적이 없다고 답했다 |
| `NONE_MISSING` | 답이 있다 |

**하나로 뭉개면 결과지가 안 물어본 것을 `없다` 로 적는다.**
