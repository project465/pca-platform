# 26. 홈페이지 — 코드로 만든 판과 아임웹으로 옮기는 순서

2026-09-18. 원고는 `sites/imweb/copy.md`, 이미지는 `sites/imweb/media/`.

**코드로 만든 판이 `sites/careermetri/index.html` 이다.** 아임웹 에디터로
옮기지 않고 그대로 배포할 수 있는 한 장이고, 원고는 위 파일과 같은 것이다.
정체성은 CLAUDE.md 를 따랐다 — 딥네이비 바탕에 금색 강조, 결과지만 흰
문서로 띄운다. 화면 캡처 셋(`sites/careermetri/img/`)은 우리 플랫폼에서
실제로 뽑은 기계공학 결과지·학과 리포트·응시 화면이다.

아임웹으로 옮길지, 이 판을 그대로 올릴지는 고르는 문제다. 이 판은 도메인만
붙이면 되고 요금제가 없다. 아임웹은 문의 폼과 결제가 붙어 있다.

아임웹 요금제는 Starter · Pro · Global 셋이고, 개인 도메인은 Starter
이상, 전자결제(PG) 설정도 유료 플랜이다. 상품 수 제한 없이 파는 것은
Pro 다. **수수료율은 확인하지 못했다. 지어내지 않는다.**

---

## 0. 한 줄

**원고와 이미지는 다 만들어 뒀다.** 아임웹에서 할 일은 붙여 넣기고,
그 앞에 도메인과 신고가 있다.

## 1. 순서

아임웹은 **기본 도메인(`○○.imweb.me`)으로 먼저 사이트를 만들 수 있다.**
그래서 도메인 구매를 기다리지 않고 페이지부터 짠다. 개인 도메인 연결은
Starter 이상이고, 사이트 개설 시 유료 요금제를 14일 체험할 수 있다.

### 0. 먼저 정할 것 셋 (원고를 붙이기 전에)

원고를 두 번 고치지 않으려면 이 셋이 먼저다.

| 무엇 | 지금 상태 |
|---|---|
| 이름 | 코드는 커리어메트리, 제안서는 METRICAREER |
| 가격 | 제안서 19,800원, 코드 `products` 29,000원 |
| 결과지 절 | 제안서 8섹션, 플랫폼 7절 |

### 1. 아임웹 가입, 기본 도메인으로 사이트 개설

14일 체험 시계가 여기서 돌기 시작한다. **원고가 준비된 다음에 가입한다.**
원고는 `sites/imweb/copy.md` 에 다 있다.

### 2. 페이지 다섯을 만들고 원고를 붙인다

`copy.md` 가 페이지·섹션 순서대로 적혀 있다. 회색 설명은 빼고 코드
블록만 붙인다.

### 3. 이미지를 올린다

`sites/imweb/media/` 의 `plat-*.png` 다섯 장이 본문용이다. 제안서 그림은
부록 표에 쓸 수 있는 것만 적어 뒀다(결과 예시 그림은 경영학과라 쓰지 않는다).

### 4. 도메인을 산다 (1·2·3과 같이 해도 된다)

`careermetri.co.kr` 과 `careermetri.com` 을 등록대행자에서 조회하고 산다.
아임웹 안에서 사도 되고 타사에서 산 것을 연동해도 된다. **DNS 가 조용한
것은 비어 있다는 뜻이 아니다.**

### 5. Starter 이상으로 올리고 도메인을 연결한다

`환경설정 > 도메인`. 무료 플랜에서는 개인 도메인이 붙지 않는다.

### 6. 푸터와 문의 폼을 채운다

전자상거래법 제10조의 일곱 칸. **비어 있으면 "확인 필요" 라고 찍어 둔다.**
값을 지어내지 않고, 빈칸으로도 두지 않는다. 문의 폼 알림 수신 주소도
같은 값이 필요하다(`LAUNCH.md` 2-2 · 아직 없다).

### 7. 공개

**여기까지가 문의를 받는 홈페이지고, 결제 없이 된다.** 1순위 매출인
학과 계약은 계약으로 좌석이 생기므로 PG 도 통신판매업 신고도 필요 없다.

---

개인 결제를 열 때만 아래가 붙는다.

### 8. PG 를 신청한다

유료 플랜에서 전자결제(PG)를 설정한다. 계약이 되면 **구매안전서비스
(에스크로) 이용확인증**이 나온다. 이것이 아임웹을 쓰는 실익이다.

### 9. 통신판매업 신고 (관할 구청 / 정부24, 3~5일)

사업자등록증 + 에스크로 확인증 + **웹사이트 주소**. 도메인이 여기서
필요하다.

### 10. 응시권 상품을 올리고 코드를 넣는다

```
npm run metri:codes -- --product REPORT_UNIV --count 50 --batch imweb-2026-10 --days 365
```

CSV 가 나오면 주문 완료 자동발송에 붙인다. 평문은 이때 한 번만 보인다.
**올릴 수 있는 것은 응시권뿐이다** — 업그레이드는 어느 응시를 여는지가
코드에 담기지 않아 발행이 거절된다(`21_imweb.md` 7절).

상품 설명에 교환 주소를 적는다. 코드만 주고 어디에 넣는지 안 적으면
문의가 전부 거기서 온다.

## 2. 아임웹에 맡기지 않는 것

| | 어디서 | 왜 |
|---|---|---|
| 소개·설득 | 아임웹 | 에디터로 충분하다 |

빌더로 못 만드는 것의 목록은 `21_imweb.md` 1절에 있다.

## 3. 원고를 만들면서 걸린 것 셋

**제안서의 예시 화면이 전부 경영학과다.** 개인 리포트 22장과 기관 리포트
3장이 "한국대학교 경영학과" 로 만들어져 있다. 이공계부터 연다고 정한
상태에서 그걸 홈페이지에 올리면, 담당자가 경영학과 검사를 요청할 때
내줄 문항이 없다. 그래서 **우리 플랫폼에서 기계공학 결과지와 기관
리포트를 실제로 뽑아** `plat-*.png` 로 넣었다.

처음 뽑은 것은 못 썼다. 시연 응답을 기계적으로 만들었더니 열 계열이
전부 동점이 되어 결과지가 "10개 계열이 1군" 이라고 찍혔다. 엔진이
정직하게 답한 것이지만 예시로는 쓸 수 없어서, 응시자마다 끌리는 영역을
둘씩 달리 주고 다시 채점했다.

**제안서 결과지는 8섹션, 지금 결과지는 7절이다.** 홈페이지에 8섹션을
적고 학생이 7절을 받으면 그 차이를 담당자가 먼저 발견한다. `copy.md`
3-1 에 고르는 길 셋을 적어 뒀다.

**가격이 두 벌이다.** 제안서는 인당 19,800원이고 코드의 `products` 는
29,000원(`REPORT_UNIV`)이다. 원고는 제안서를 따랐다. **홈페이지를 올리기
전에 한쪽으로 맞춰야 한다** — 산 사람이 결제 화면에서 다른 값을 본다.
