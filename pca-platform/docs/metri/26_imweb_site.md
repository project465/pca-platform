# 26. 아임웹으로 홈페이지 만들기 — 작업 순서

2026-09-18. 원고는 `sites/imweb/copy.md`, 이미지는 `sites/imweb/media/`.

---

## 0. 한 줄

**원고와 이미지는 다 만들어 뒀다.** 아임웹에서 할 일은 붙여 넣기고,
그 앞에 도메인과 신고가 있다.

---

## 1. 순서 (앞을 건너뛰면 뒤를 다시 한다)

### ① 도메인을 산다

통신판매업 신고서에 **웹사이트 주소 칸**이 있다. 그래서 도메인이 먼저다.
`careermetri.co.kr` 과 `careermetri.com` 을 등록대행자(가비아·후이즈·
호스팅케이알)에서 조회하고 산다. **DNS 가 조용한 것은 비어 있다는 뜻이
아니다.** 이름 자체는 2026-09-16 에 정했다(`24_naming.md`).

### ② 아임웹에 가입하고 도메인을 연결한다

무료 플랜으로 페이지를 먼저 짜 보고, 도메인 연결과 결제가 필요해지는
시점에 유료로 올린다. **요금제와 수수료는 확인하지 못했다. 지어내지
않는다** — 가입 화면에서 보고 이 줄을 채운다.

### ③ 페이지 다섯을 만들고 원고를 붙인다

`sites/imweb/copy.md` 가 페이지·섹션 순서대로 적혀 있다. 회색 설명은
빼고 코드 블록만 붙인다. 이미지는 부록의 표를 따른다.

### ④ 푸터를 채운다

전자상거래법 제10조가 요구하는 일곱 칸이다. **비어 있으면 "확인 필요"
라고 찍어 둔다.** 값을 지어내지 않고, 빈칸으로도 두지 않는다.

### ⑤ 문의 폼을 켜고 수신 주소를 넣는다

지금 코드에는 담당자·전화·이메일이 없다(`LAUNCH.md` 2-2). 아임웹 폼의
알림 수신 주소도 같은 값이 필요하다.

### ⑥ 여기까지는 결제 없이 된다

**1순위 매출인 학과 계약은 결제가 필요 없다.** 계약으로 좌석이 생기고
학생은 그냥 들어온다. 홈페이지는 문의를 받는 곳이면 충분하다.

### ⑦ 개인 결제를 열 때 (나중)

PG 계약을 하면 구매안전서비스(에스크로) 이용확인증이 나오고, 그것으로
관할 구청에 통신판매업 신고를 한다(3~5일). 그다음 응시권 상품을 올리고
`npm run metri:codes` 로 코드를 찍어 자동발송에 넣는다. 자세한 것은
`21_imweb.md` 6·7절. **올릴 수 있는 것은 응시권뿐이다** — 업그레이드는
어느 응시를 여는지가 코드에 담기지 않아 발행이 거절된다.

## 2. 아임웹에 맡기지 않는 것

| | 어디서 | 왜 |

빌더로 못 만드는 것의 목록은 `21_imweb.md` 1절에 있다.

## 3. 원고를 만들면서 걸린 것 셋

**제안서의 예시 화면이 전부 경영학과다.** 개인 리포트 22장과 기관 리포트
3장이 "한국대학교 경영학과" 로 만들어져 있다. 이공계부터 연다고 정한
상태에서 그걸 홈페이지에 올리면, 담당자가 경영학과 검사를 요청할 때
내줄 문항이 없다. 그래서 **우리 플랫폼에서 기계공학 결과지와 기관
리포트를 실제로 뽑아** `plat-*.png` 로 넣었다.

처음 뽑은 것은 못 썼다. 시연 응답을 기계적으로 만들었더니 열 계열이
전부 동점이 되어 결과지가 "10개 계열이 1군" 이라고 찍혔다. 엔진이
정직하게 답한 것이지만 예시로는 쓸 수 없어서, 응시자마다 끌리는 영역을
둘씩 달리 주고 다시 채점했다.

**제안서 결과지는 8섹션, 지금 결과지는 7절이다.** 홈페이지에 8섹션을
적고 학생이 7절을 받으면 그 차이를 담당자가 먼저 발견한다. `copy.md`
3-1 에 고르는 길 셋을 적어 뒀다.

**가격이 두 벌이다.** 제안서는 인당 19,800원이고 코드의 `products` 는
29,000원(`REPORT_UNIV`)이다. 원고는 제안서를 따랐다. **홈페이지를 올리기
전에 한쪽으로 맞춰야 한다** — 산 사람이 결제 화면에서 다른 값을 본다.
