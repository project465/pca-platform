## 한 문장

**ME_V3 는 전공과 학위와 전공계열에 따라 묻는 장면을 갈아 끼우되, 직무
판단은 응답자가 실제로 내린 기술 판단과 남긴 산출물 하나로만 만든다.**

## 이번 회차에서 새로 정한 것 여섯

앞 회차가 열어 두었거나 이번 지시로 더해진 자리다.

1. **전공계열이 들어가는 자리를 넷으로 못 박았다.** 문항 routing · 문면
   장면 · 번역 module 선택 · 결과지의 읽는 법 한 절이다. 가중치 · 판단 축
   개수 · 묶음 조건 · 등급 경계 · 지역 layer 에는 들어가지 않는다.
2. **BASIC 을 고정 문항 수에서 `공통 핵심 + 분기` 구조로 바꿨다.** 학사와
   이공계 대학원과 인문·사회·경상 대학원이 서로 다른 블록을 받고, 공통
   핵심은 같다.
3. **판단 축 척도를 둘로 나눴다.** 선별 척도 J4 와 전체 척도 J8 이다.
   `4축 중 2개` 를 `8축 중 4개` 로 적지 않는다.
4. **역채점과 일관성 장치를 함정 문항 없이 세웠다.** 역방향 문면 · 강제
   선택 · 같은 축 두 장면 · 응답과 체크리스트의 어긋남 넷이다.
5. **번역 layer 를 공통층과 계열 module 로 갈랐다.** 열 단계는 계열과
   무관하고, 보기 목록과 영역 사상만 계열이 정한다.
6. **ME_V2 를 읽기 전용으로 잠그는 방법을 정했다.** 문서에 적는 것으로
   끝내지 않고 지문 대조 검사를 둔다(`53_v3_09_revisions.md` 2절).

## 가장 중요한 한 가지

전공계열 분기는 **값을 더하는 분기가 아니고 묻는 말을 고르는 분기다.**

인문·사회·경상 석사가 기계공학 모듈로 들어와도 구조해석 근거가 생기지
않는다. 생기는 것은 그분이 실제로 한 일(조사 설계 · 자료 분석 · 요구
정리 · 이해관계자 조정)이 기술 조직의 어느 자리로 읽히는가다. 반대로
그분이 유한요소 해석을 실제로 했다면 그 보기를 고를 길이 열려 있어야
하므로, 계열이 천장이 되지 않게 **다른 모듈의 보기를 여는 길**을 함께
둔다(`53_v3_04_translation.md` 5절).

이것이 지켜지는지는 검사 한 줄로 확인한다. **같은 응답에 계열 값만 바꿔
돌렸을 때 영역 묶음과 확인된 축이 한 칸도 바뀌지 않아야 한다.**
