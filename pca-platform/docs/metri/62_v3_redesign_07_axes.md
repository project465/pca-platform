# 공통 판단축 재검토

날짜 2026-10-08 · **구현 전 설계**

축 이름을 지키는 것이 목적이 아니다. **실제 판단 구조가 목적이다.**

---

## 1 · 잡아야 하는 흐름과 지금 축

| 잡아야 하는 흐름 | 지금 축 | 맞는가 |
| --- | --- | --- |
| 문제 | J1 문제 정의 | 맞다 |
| 요구 | J2 요구사항 해석 | 맞다 |
| 직접 판단 | J3 직접 기술 판단 | 맞다 |
| 방법·도구 | J4 방법·도구 | **이름은 맞고 문면이 틀렸다** |
| 산출물 | J5 산출물 | 맞다 |
| 비교·검증 | J6 비교·검증 | 맞다 |
| 실패·수정 | J7 실패·수정 | 맞다 |
| 실제 활용 | J8 조직 활용 | **이름은 맞고 문면이 틀렸다** |

**여덟을 유지한다.** 흐름과 축이 하나씩 맞고, 빠진 자리도 남는 자리도
없다. 축을 늘리거나 줄이지 않는다.

---

## 2 · 그래도 고쳐야 하는 둘

### 2-1 · J4 · 도구 사용이 판단을 밀어냈다

지금 J4 문항 열넷 가운데 넷이 **도구를 썼는가만 묻는다.**

| 지금 | 무엇이 빠졌는가 |
| --- | --- |
| `상용 해석 도구로 모델을 만들어 직접 돌려 본 경험` | 이상화 수준과 요소와 접촉 조건을 **누가 정했는가** |
| `전산유체 해석이나 열회로 계산으로 값을 직접 내 본 경험` | 격자와 난류 모델과 경계조건 가운데 **무엇을 정했는가** |
| `3차원 모델로 형상과 조립 상태를 직접 만들어 본 경험` | 그 모델에서 **무엇을 단순화하고 무엇을 남겼는가** |
| `요구 추적표를 써서 항목을 관리해 본 경험` | 추적이 **끊긴 자리를 어떻게 메웠는가** |

**축의 정의를 좁힌다.** J4 가 묻는 것은 `무엇으로 어떻게 했는가` 에서
**`그 방법을 쓰면서 무엇을 정했는가`** 로 옮긴다. 영역 사전의 `l2` 를 보면 이미
그렇게 적혀 있다(`TD02 J4 l2` 가 도구 사용이 아니고
`체결력·베어링 수명·강성을 손계산으로 남겼다` 같은 줄이다). **사전이 맞고
문항이 사전을 따라가지 않았다.**

### 2-2 · J8 · 전달과 활용을 가르지 못한다

지금 J8 문항 열둘 가운데 열이 **전달에서 멈춘다.**

| 지금 | 무엇이 빠졌는가 |
| --- | --- |
| `설계 검토 회의에 올려 설명해 본 경험` | 올린 뒤에 **채택됐는가** |
| `담당자에게 넘겨 본 경험` | 넘긴 뒤에 **무엇이 바뀌었는가** |
| `팀에 배포해 본 경험` | 배포한 뒤에 **남이 그것으로 일했는가** |
| `팀에 공유해 본 경험` | 공유한 뒤에 **계속 쓰이는가** |

**축의 정의를 좁힌다.** J8 은 `누구에게 줬는가` 가 아니라
**`그 결과로 남의 일이 달라졌는가`** 다. 이것이 중요한 까닭은 J8 이
`소유(L3)` 를 가르는 축이기 때문이다. 전달에서 멈춘 문면으로는
**보고서를 메일로 보낸 사람과 그 보고서로 설계를 바꾼 사람이 같은 값**을
받는다.

## 3 · 선별 척도 S4 를 다시 고른다

지금 BASIC 이 묻는 넷은 J3 · J5 · J6 · J8 이다.

**J8 을 빼고 J7 을 넣는다.**

| 까닭 | |
| --- | --- |
| J8 은 학부생이 구조적으로 불리하다 | 캡스톤 결과가 남의 일을 바꾸는 일은 드물다. 선별에서 J8 을 물으면 학부생 열에 아홉이 L0 이 되고, 그 칸은 아무것도 가르지 못한다 |
| J7 은 학부생도 거의 다 겪는다 | `결과가 예상과 달라 조건을 바꿔 다시 해 본` 은 실험 과목에서 반드시 일어난다 |
| J7 이 더 잘 가른다 | 겪고 **원인을 좁힌 사람**과 겪고 **다시 돌린 사람**이 갈린다 |

그래서 선별 넷은 **J3 · J5 · J6 · J7** 이고, J8 은 심화(S8)에서만 묻는다.
`4축 중 2개` 를 `8축 중 4개` 로 적지 않는 규칙은 그대로다.

## 4 · 필수 축을 다시 본다

영역마다 `빠지면 안 되는 축 둘` 이 적혀 있다. 선별이 J8 에서 J7 로 바뀌면
필수 축이 J8 을 가리키는 영역이 생긴다. 확인한 결과 **지금 열두 영역의
필수 축에 J8 이 들어간 곳은 없다**(TD12 가 `J5 · J8`). TD12 하나만
`J5 · J1` 로 바꾼다. TD12 에서 소유를 가르는 것은 남이 쓰는가인데, 그것은
심화에서 묻고 선별에서는 **무엇을 자동화할지 정했는가**가 더 잘 가른다.

| 영역 | 지금 | 바꾸는가 |
| --- | --- | --- |
| TD01 | J3 · J5 | 그대로 |
| TD02 | J3 · J6 | 그대로 |
| TD03 | J3 · J6 | 그대로 |
| TD04 | J4 · J6 | 그대로 |
| TD05 | J3 · J5 | 그대로 |
| TD06 | J4 · J6 | 그대로 |
| TD07 | J3 · J5 | 그대로 |
| TD08 | J3 · J6 | 그대로 |
| TD09 | J3 · J7 | 그대로 |

## 5 · 보기 넷은 그대로

`없다 · 남이 한 것을 받아 썼다 · 내가 했다 · 내가 정하고 그 결과가 쓰였다`
를 바꾸지 않는다. 네 단계의 뜻이 판정 규칙과 묶여 있고, 파일럿이 아직
`내가 했다` 와 `내가 정했다` 의 경계가 통하는지 말해 주지 않았다.

**다만 넷째 보기의 문면이 J8 과 겹친다.** `그 결과가 쓰였다` 는 조직 활용과
같은 말이라, J8 문항에서 넷째 보기를 고르면 같은 것을 두 번 세는 꼴이다.
J8 문항에서만 넷째 보기를 `내가 정했고 그것이 기준이 됐다` 로 달리 적는
것을 검토한다. **이것은 파일럿 뒤에 정한다.** 지금 바꾸면 판정 규칙을
건드린다.
