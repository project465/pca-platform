# G. BASIC · STANDARD · PRO 최종 역할

가격은 그대로다. BASIC 무료 · STANDARD 14,900원 · PRO 21,900원. 가르는
것은 문항 수가 아니고 **판단의 깊이**다.

| 등급 | 판단의 종류 | 한 줄 |
|---|---|---|
| BASIC | 묶음과 개수 | 어디부터 볼지 정한다 |
| STANDARD | 이름과 조건, 영역과 직무 사이의 차이 | 견주어 고르고 무엇이 비었는지 안다 |
| PRO | 번역과 문장, 목표와의 대조 | 가진 것을 지원 재료로 꺼낸다 |

## 1. BASIC (무료)

| | |
|---|---|
| **해결하는 질문** | 내 수업과 프로젝트와 연구 경험이 **어느 기술영역으로 읽히는가**, 그리고 어디부터 더 볼 것인가 |
| **받는 데이터** | `CORE-GRID` 36 · `CORE-JUDGE` 4 · `CORE-FORCE` 2 · `PROBE-J4` 8 · 학위·계열 분기 블록 4~8. 응답 54~58, 10분에서 14분 |
| **보여 주는 결과** | 영역 묶음 셋(Z2 · Z3 · Z4)과 그 안의 영역 이름 · 고른 영역 둘의 **선별 네 축 가운데 확인된 개수** · 비어 있는 선별 축의 개수 · 관심과 학습 의향이 갈리는 영역과 그 뜻 · 30일 안에 만들 것 하나 · 학위와 계열에 맞는 경험 한 줄 |
| **보여 주면 안 되는 결과** | Z1(근거가 섰다는 판정) · 축의 **이름** · 채우는 조건 · S8 여덟 축 · 직무 비교 · 조직환경별 차이 · 번역 · 90일과 365일 · 지역 교차 결과 |
| **아래보다** | 아래가 없다 |

### 1-1. 무료에서 하지 않는 것 둘

**경험 입력 화면을 요구하지 않는다.** 선별과 분기 블록만으로 결과가
나오게 설계한다. 지금은 경험 입력을 건너뛰면 결과의 절반이 비는데 무료
응시자는 대부분 건너뛴다.

**Z1 을 만들지 않는다.** 선별 네 축으로 `근거가 섰다` 고 말하지 않는다.
무료가 말하는 것은 `먼저 확인해 보실 영역` 과 `선별 네 축 가운데 둘` 까지다.

## 2. STANDARD (14,900원)

| | |
|---|---|
| **해결하는 질문** | 후보 영역 둘셋 가운데 **어디로 갈 것인가**, 그리고 **무엇이 비어 있는가** |
| **받는 데이터** | BASIC 전부 + 심화 영역 셋의 남은 축 16(셋째 영역은 선별 네 축까지 함께 열린다) + `DEEP-CHECK`(판단 체크리스트 · 산출물 체크 · 검증 대상 · 한 줄 근거) + `PREF-RF-OC` 14 + `CONSIST` 4. 심화 영역은 기본 셋이고 **구분되지 않으면 넷째가 추가 결제 없이 열린다**. 새로 묻는 응답 34개, 추가로 10분에서 15분 |
| **보여 주는 결과** | Z1~Z4 네 묶음 · 영역별 여덟 축의 **이름과 수준** · 비어 있는 축을 채우는 조건 · 공고 직무명 둘셋의 차이와 가르는 질문 · 조직환경 일곱에 따라 달라지는 성과 이름 · 이미 있는 근거 묶음 · 30일과 90일 · 지역 교차 결과 |
| **보여 주면 안 되는 결과** | 번역 열 단계 · 지원서 문장 초안 · 목표 직무 요구 대조 · 365일 · `근거 한 쪽` PDF |
| **아래보다** | 개수에서 **이름**으로 바뀐다. `선별 네 축 가운데 둘` 이 `여덟 축 가운데 다섯이고, 비어 있는 것은 비교·검증과 실패·수정이며 채우는 조건은 이것` 으로 바뀐다 |

## 3. PRO (21,900원)

| | |
|---|---|
| **해결하는 질문** | 내 연구와 프로젝트 경험을 **직무 언어로 옮겨 지원 재료로 만들려면** 무엇을 어떻게 적어야 하는가 |
| **받는 데이터** | STANDARD 전부 + `TRANS-10` 12(계열 module 의 보기 메뉴) + `TARGET` 3. 새로 묻는 응답 15개, 추가로 9분에서 13분 |
| **보여 주는 결과** | 번역 열 단계를 영역 둘셋의 판단 축으로 옮긴 표 · 그 번역에서 나온 **지원서 문장 초안** · 목표 직무의 요구와 내 근거의 대조표 · 비어 있는 번역 단계와 되묻는 말 · 365일 · `근거 한 쪽` PDF |
| **보여 주면 안 되는 결과** | 합격 가능성 · 기업 추천 · 상위 몇 퍼센트 · 나라별 임금과 비자 · 적성 등급 |
| **아래보다** | **번역이 붙는다.** STANDARD 는 비어 있는 것을 알려 주고, PRO 는 이미 가진 것을 꺼내 쓸 문장으로 만든다 |

## 3-1. 등급을 올리면 앞 응답을 다시 묻지 않는다

**등급은 겹쳐 쌓인다**(BASIC ⊂ STANDARD ⊂ PRO). 그래서 올라갈 때 새 응시를
만들지 않고 같은 응시의 `tier` 를 올리고 **추가 블록만 연다.** 처음부터 그
등급으로 시작한 사람과 올라온 사람의 최종 응답 묶음이 같다.

| | 처음부터 시작 | 올라올 때 새로 묻는 응답 |
|---|---|---|
| BASIC | 54에서 58 | |
| STANDARD | 88에서 92 | 34 |
| PRO | 103에서 107 | 15 |
| 넷째 영역이 열리면 | +8 | +8 |
| 산업팩 하나 · 역할팩 하나 | +12 | +12 |

추정 시간이다. 블록마다 한 응답에 드는 시간을 적어 두고 곱한 값이며
**실측이 없다.** 파일럿에서 재서 고친다.

| 경우 | 추정 |
|---|---|
| BASIC | 약 10분 |
| 처음부터 STANDARD | 약 21분 |
| 처음부터 PRO | 약 30분 (팩까지 33분) |
| BASIC 끝낸 뒤 STANDARD | 약 11분 |
| STANDARD 끝낸 뒤 PRO | 약 9분 (팩까지 13분) |

**ME_V2 에서는 이것이 안 됐다.** 등급이 문항 수를 정해서(48 · 68 · 92)
48문항을 푼 응시에 유료 절을 얹을 수 없었다. V3 는 등급이 **묻는 블록**을
정하므로 같은 응시에 더할 수 있다.

**좌석은 늘지 않는다.** 응시가 하나이므로 같은 사람의 응답이 두 벌 쌓이지
않고 규준도 오염되지 않는다. 어느 응시를 올리는 결제인지는
`orders.upgrades_attempt_id` 가 들고 다닌다.

**세는 산식은 한 곳이다**(`src/lib/me-v3/response-count.ts`). `v3:items` 와
`v3:wording` 이 같은 수를 따로 세다 84 와 88 로 갈린 적이 있고, 갈린 까닭이
실수가 아니라 설계 구멍이었다: 심화 영역을 하나 더 열면 그 영역의 선별 네
축도 같이 열려야 하는데 한쪽이 빼먹었다. 그대로 두면 셋째 영역이 여덟 축
가운데 넷만 답한 상태로 묶음 판정에 들어간다.

## 4. 전공계열과 등급의 관계

**계열로 등급 값을 가르지 않는다.** 같은 등급을 산 사람은 계열이 달라도
같은 종류의 판단을 받는다.

| 질문 | 답 |
|---|---|
| 인문·사회나 경상 석사가 PRO 를 사면 번역을 받는가 | 받는다. 보기 메뉴가 그 계열 쪽이다 |
| 그 번역이 영역 열둘 전부에 근거를 주는가 | 아니다. 고른 방법이 닿는 영역에만 준다 |
| 그것을 사기 전에 알 수 있는가 | 상품 쪽에 적는다. 5절을 볼 것 |
| 학사도 PRO 의 번역을 받는가 | 받는다. 수업과 캡스톤 메뉴다 |
| 계열에 따라 가격이 다른가 | 다르지 않다 |

## 5. 사기 전에 알려야 하는 것

PRO 의 값이 번역이므로, **번역할 경험이 적은 사람에게는 PRO 의 값이
작다.** 그 사실을 상품 쪽에 적는다. 적지 않으면 환불 요청으로 돌아온다.

> 깊이 등급은 적어 주신 연구와 프로젝트 경험을 직무 언어로 옮기는
> 자리입니다. 아직 캡스톤이나 연구 경험이 없으시면 받으시는 양이
> 적습니다. 견주기 등급부터 보시는 편이 낫습니다.

비이공계 계열에게는 한 줄을 더 적는다.

> 인문·사회계열 대학원 경험은 요구 분해와 자료 판단과 기준 적합 쪽으로
> 번역됩니다. 경상계열은 요구 분해와 비용·수요 추정과 운영 판단 쪽입니다.
> 설계와 해석 영역의 근거는 이 응답으로 생기지 않습니다.

## 6. 이 분할이 맞는지 보는 반증 조건

그대로 답으로 쓰지 않고 틀렸을 때 무엇을 바꿀지 적는다.

| 가정 | 무엇으로 보는가 | 틀리면 |
|---|---|---|
| 무료 10분에서 14분이면 끝까지 답한다 | 파일럿의 선별 완료율 | 격자의 학습 의향 칸을 빼고 영역 여섯으로 줄인다 |
| 개수에서 이름으로 바뀌는 것이 14,900원의 값이다 | 파일럿의 지불 의향과 실제 전환 | 목표 직무 대조를 STANDARD 로 내린다 |
| 번역이 21,900원의 값이다 | 대학원 참가자의 가치 차이 문항 | 모의 면접 질문 생성을 PRO 에 더한다 |
| 심화 세 영역이면 충분하다 | 넷째가 자동으로 열린 비율 | 기본을 네 영역으로 올린다 |
| 비이공계 계열도 값을 본다 | 그 계열 참가자의 가치 문항 | 그 계열을 번역 전용 상품으로 따로 가른다 |
| 학부생도 번역에서 값을 본다 | 학부 참가자의 PRO 가치 문항 | 학부는 캡스톤 번역으로 문면을 갈라 쓴다 |

## 7. 등급이 서로 구별되는지 세는 검사

지금 `tiersDistinct()` 가 받는 것의 겹침을 센다. 새 기준에서는 **판단의
종류**를 센다. 아래 등급과 같은 종류만 더해지면 실패다.

| 세는 것 | 실패 조건 |
|---|---|
| 등급마다 결과 항목의 **상세 수준**(개수 · 이름 · 번역) | 상위 등급이 하위와 같은 수준이면 실패 |
| 보여 주면 안 되는 목록이 실제로 비어 있는가 | 하위 등급 결과에 상위 항목이 한 줄이라도 있으면 실패 |
| 등급 문구가 문항 수나 쪽수를 말하는가 | 말하면 실패 |
| 계열별로 등급 값이 갈리는가 | 갈리면 실패 |

마지막 줄이 이번에 더해진 검사다.
