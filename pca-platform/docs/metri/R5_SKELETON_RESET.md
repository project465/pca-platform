# BIZ Result Skeleton Reset

이 회차는 기존 Result 를 다시 칠하지 않았다. **첫 화면의 뼈대 자체를
다시 세웠다.** measurement · scoring · frozen response · result/evidence/gap
decision · Core · Domain · DB · registry · `student_open` · Gate 1·2 는 한 줄도
건드리지 않았고, 세 동결(`v3:freeze` · `v3:freeze:measure` ·
`v3:workspace`)이 **기록을 다시 적지 않은 채로** 통과한다.

BEFORE / AFTER 는 `docs/metri/shots/review-loop/r5/before` 와 `.../after` 에
같은 이름으로 있다. **같은 데이터**(BIZ · 배재대 경영학과 · PERSON=C)다.

## 1. 버린 것

| 버린 것 | 까닭 |
|---|---|
| Hero = 메타 3줄 → 눈썹 → 판정 문장 → 거드는 줄 | 시스템이 판정을 발표하는 자리로 읽힌다 |
| Summary 4블록과 `order`/`grid-area` 재배치 | 제목+본문+둥근 카드가 넷 되풀이되면 그것이 template |
| 2×2 격자 · card stack | 넷을 다 읽고 나서 무엇이 중요한지 스스로 정해야 한다 |
| Summary 아래 따로 서던 CTA 줄 | 다 읽은 사람이 `그래서 뭘 누르지` 를 한 번 더 찾는다 |
| 첫 화면의 산업·직무 띠 | 첫 화면이 답할 것은 셋이고 이것은 넷째다 |

## 2. 새 First Viewport

```
한 줄 식별      배재대학교 · 경영학과 · 경영 일반 · CareerMatri PRO · 응답일
OPENING         [✓ 지원서에 바로 쓸 수 있어요]        ← 판정은 작은 알약
(흰 면 · 가운데) “여러 안 가운데 하나를 근거를 들어     ← **학생이 고른 문장이 h1**
                 골랐고, 예산이나 인원을 … 나눴어요.”
                 경영전략·기획  마케팅·시장  영업…     ← 분류는 칩
NOW             지금 이야기할 수 있는 것 │ 다음에 채울 부분
(테 없음 · 왼쪽)  목표와 지표 표 …        │ 직접 정한 기준을 아직 …
NEXT            지금 하면 좋은 일
(mint 면 ·      그때 직접 정한 것을 적어 두기
 가운데)         … 세 줄로 적어 보세요.
                 [ 지금 할 일로 담기 → ]              ← CTA 가 이 안에
                 경험 추가 · 결과 PDF 저장 · 내 CareerMatri
```

가장 큰 전환은 **h1 이 판정문에서 학생의 문장으로 바뀐 것**이다. 판정은
`headlineBadgeKo()` 가 내놓는 열넉 자 안짝의 알약 하나로 내려갔다.
**판정은 바뀌지 않았다**: 알약도 문장도 결과 모델이 이미 들고 있는 값이다.

## 3. Scroll Narrative

OPENING → NOW → NEXT(CTA) → 내가 이미 가진 근거 → 산업·직무 → 앞으로 채울
것 → 다음에 할 일 → 부록.

**하위 상세 절의 차례는 그대로 두었다.** Evidence 전면 수정 금지가 아직
걸려 있어서, 이번에 다시 세운 것은 첫 화면이다.

## 4. Desktop / Mobile

| | Desktop 1440 | Mobile 390 |
|---|---|---|
| OPENING | 글 폭 680px 로 가운데 | 같은 가운데 · 여백 한 단 좁게 |
| NOW | 두 칸 · **세로 금** 하나 | 위아래 · **가로 금** 하나 |
| NEXT | 전폭 · 가운데 | 같음 |

축소판이 아니다: NOW 를 가르는 금의 **방향이 바뀐다**.

## 5. 섞인 component 와 색의 역할

| 자리 | 모양 | 둥글기 | 면 | accent |
|---|---|---|---|---|
| OPENING | 둥근 면 | 24px | white | navy ink · blue 알약 |
| NOW | 테 없는 두 칸 | 0 | 없음 | blue 이름표 / lilac 이름표 |
| NEXT | 둥근 면 | 20px | soft mint | mint 이름표 · navy CTA |
| 칩 | 알약 | 999px | cool gray | — |

**한 화면의 색면은 mint 하나다.** 카드마다 색을 깔면 그 색이 아무것도
가리키지 않는다.

## 6. 설명량

- Hero 보조 문장: 두 문장 → **한 문장**
- `남아 있는 기록` 의 둘째 설명 줄: 화면에서 **걷었다**(종이에는 남는다)
- 할 일의 까닭 한 줄: 화면에서 **걷었다**(종이와 아래 할 일 절이 든다)
- 산업·직무 설명 한 줄: 화면에서 **걷었다**
- 이름: `남긴 근거` → `남아 있는 기록` · `더 채울 부분` → `다음에 채울 부분`

## 8. 겪은 것

- **이름이 겹치는 것이 또 버그였다(열세 번째).** NOW 의 거드는 줄에
  `rs-sub` 를 지었는데 그 이름은 분포 절이 이미 쓰고 있었다. 특 정도가
  높아 덮이기는 하지만 그 의존이 곧 다음 사고다. `rs-now-sub` 로 바꿨다.
- **띄운 서버를 틀리면 검사가 거짓말을 한다(여섯 번째).** `pkill` 이 옛
  서버를 못 잡았고 `assertFreshServer()` 가 그 자리에서 멈췄다.
- **이름을 바꾸면 그 이름을 든 검사도 같이 고친다.** `.rs-do` 를 걷자
  `v3:product-loop` 의 CTA 줄이 셀 자리를 잃었다. 쪽은 멀쩡히 뜨는데
  검사만 빨갛게 서는 자리다.
- 눌러 보는 검사가 잡은 **진짜 하나**: `/me/state` 에 `적는 자리가 아직
  비어 있습니다` 가 남아 있었다. 자료에 따라서만 서는 줄이라 앞 회차가
  지나갔다. 무엇을 적으면 되는지로 바꿨다.

## 9. 아직 아닌 것

운영 배포본을 밖에서 열지 못했다(네트워크 정책). 학생 공개 상태를 바꾸지
않았다. Evidence 상세와 그 아래 절은 이번 범위가 아니다. 다른 Core 로
넓히지 않았다.
