# 사업주가 정해야 하는 것

규격 §37 이 요구한 한 장. **지어내지 않았다.** 비어 있는 칸은 비어 있고,
칸마다 그 값이 어디로 들어가는지와 정하지 않으면 무엇이 안 되는지를
같이 적었다.

이 문서가 채워지면 `npm run launch:check` 의 막힌 것 열아홉 가지 가운데
열넷이 사라진다. 나머지 다섯은 도메인 구매와 사업자 등록처럼 서류가
걸린 것들이다.

## [PRICING]

```
KR BASIC:
KR STANDARD:
KR PRO:
GLOBAL BASIC:
GLOBAL STANDARD:
GLOBAL PRO:
GLOBAL currency:
```

| 어디로 | `products.amount` · `products.price_status = 'approved'` |
|---|---|
| 정하지 않으면 | 가격표가 `PRICE_NOT_APPROVED` 를 적고 결제 단추가 서지 않습니다 |
| 참고 | `docs/metri/08_revenue.md` 가 경쟁사 공개가와 학과 예산에서 역산한 범위를 적어 두었습니다. **그 숫자는 제안이지 확정이 아닙니다** |

**0원으로 두지 않습니다.** 0원은 이미 다른 뜻으로 쓰고 있습니다(법이
요구하는 무료 시용 구간). 값을 정하기 전까지는 `not_approved` 로 두는
쪽이 맞습니다.

**등급 차이를 문항 수로 잡지 않았습니다**(규격 §4). BASIC 은 방향,
STANDARD 는 견주는 깊이, PRO 는 증거 구조와 실행입니다. 값의 간격도 그
순서를 따라야 합니다. 받는 것은 `src/lib/tiers.ts` 에 한 곳으로 적혀
있고 상품 쪽과 가격표가 그것을 읽습니다.

## [PAYMENT]

```
KR provider:
Global provider:
```

| 어디로 | `.env` 의 `PAYMENTS_PROVIDER` 와 채널 열쇠 |
|---|---|
| 정하지 않으면 | 운영에서 서버가 아예 뜨지 않습니다(가짜 결제를 코드가 거절합니다) |
| 걸리는 시간 | 가맹점 심사 영업일 3~10일. 통신판매업 신고 3~5일 |

국내 쪽은 PortOne 어댑터가 서 있습니다(`src/lib/payments/portone.ts`).
**해외 쪽은 대행사가 정해지지 않았습니다.** 국내 PG 의 일반 카드결제로는
해외 발급 Visa·Mastercard 가 승인되지 않아서, 글로벌은 해외결제 채널이나
다른 대행사를 거쳐야 합니다. 어댑터 계약은 같으므로 고르고 나면 파일 한
장이 늘어납니다.

**통신판매업 신고서에 웹사이트 주소 칸이 있습니다.** 도메인이 그 앞
단계입니다.

## [POLICY]

```
Refund policy:
Retake policy:
Result update policy:
```

| 어디로 | `src/lib/refund.ts` 의 구간과 `/legal/refund` 본문 |
|---|---|
| 지금 서 있는 것 | 응시 전 전액 · 응시 후 거절 · 결과지를 연 뒤 거절. 기간권은 일할 |
| 정하지 않으면 | 지금 코드의 선이 그대로 나갑니다. **그 선이 사업 결정이 아니라 개발 기본값입니다** |

**응시 전은 법보다 넓게 주고 있습니다**: 7일로 끊지 않고 기간 제한을
두지 않습니다. 좁히는 쪽으로 바꾸시려면 전자상거래법 제17조와 시용 장치
요건을 함께 봐야 합니다.

재응시와 결과지 갱신은 **아직 아무 규칙도 없습니다.** 상품 쪽 FAQ 에
"정해지지 않았습니다" 로 적어 두었습니다. 정해지면 그 줄을 고칩니다.
같은 사람이 문항을 또 풀면 응답이 두 벌 쌓여 **규준이 오염됩니다**.

## [BUSINESS]

```
Legal business name:
Business registration details:
Support email:
Support process:
```

| 어디로 | `BUSINESS_*` · `SUPPORT_EMAIL` · `SUPPORT_HOURS` 환경변수 |
|---|---|
| 정하지 않으면 | 전자상거래법 제10조 표시가 비어 결제를 받을 수 없습니다 |

일곱 칸입니다: 상호 · 대표자 · 주소 · 전화 · 이메일 · 사업자등록번호 ·
통신판매업 신고번호. **비어 있으면 상품 쪽 푸터에 '확인 필요' 로
찍힙니다.** 빈칸은 눈에 안 띄고, 눈에 안 띄면 그대로 런칭됩니다.

지원 주소는 **지어내지 않았습니다.** 없는 주소로 보낸 메일은 아무 데도
닿지 않고, 보낸 사람은 답을 기다립니다.

보유한 신고는 **직업정보제공사업 J1700020220007호 하나**입니다. 알선과
취업추천서와 이력서 발송 대행은 하지 않고, 원고도 그 범위로 적혀
있습니다(`src/lib/product-copy.ts` 의 말하지 않는 것).

## [DOMAIN]

```
careermatri.co.kr:
careermatri.com:
```

| 어디로 | `db/schema_platform.sql` 의 `site_configs` 두 줄 |
|---|---|
| 정하지 않으면 | 소개 사이트의 '시작하기' 가 우리 것이 아닌 주소를 가리킵니다 |

**규격 철자의 `.com` 에 남이 있습니다.** `npm run domains:check` 가
그것을 확인했습니다(216.198.79.1). `careermetri.com` 은 조용합니다.
어느 철자로 사실지는 사시는 분이 정하고, 정하고 나면 고칠 곳은 저 두
줄과 `marketing/src/lib/domains.ts` 입니다.

**저장소는 지금 한 철자로 모여 있습니다**(`careermatri`).
`npm run domains:audit` 이 두 철자가 같이 사는 것을 막습니다. 한 글자
차이라 섞이면 눈으로는 찾지 못합니다.

## 정하지 않아도 할 수 있는 것

아래는 사업주 결정과 무관하게 이미 돌고 있습니다. 결정이 늦어도 멈출
필요가 없습니다.

- 두 언어로 검사 → 경험 → 결과지 → PDF
- 환불 요청과 결정, 그 기록
- 지원 화면(주문 번호 · 참조 번호 · 비밀번호 복구)
- 퍼널 계측과 사고 화면
- 파일럿 열 문항
- 백업 스크립트와 복구 절차

## 한 장으로

| 정할 것 | 누가 | 없으면 막히는 것 |
|---|---|---|
| 여섯 등급의 값 | 사업 결정 | 결제 단추가 서지 않는다 |
| 글로벌 통화 | 사업 결정 | 글로벌 가격표 |
| 국내 PG | 심사 | 운영에서 서버가 뜨지 않는다 |
| 해외 PG | 사업 결정 + 심사 | 글로벌 결제 |
| 환불·재응시·갱신 규칙 | 사업 결정 | 지금은 개발 기본값이 나간다 |
| 사업자 일곱 칸 | 사업자 등록 | 결제를 받을 수 없다 |
| 지원 메일 주소 | 사업 결정 | 문의받을 자리가 없다 |
| 메일 대행사 | 운영 담당 | 거래 메일 여섯 통이 안 나간다 |
| 도메인 둘 | 도메인 구매 | 주소가 우리 것이 아니다 |
| 복구 시험 날짜 | 운영 담당 | 백업이 완료가 아니다 |
