# Z1 명세 한 쪽 · BASIC 에 넣을지 판단하는 자료

BASIC 에서 Z1 을 빼기로 했고, 넣을지를 뒤에 판단하기 위한 자료다.
**임의로 BASIC 에 넣지 않는다.**

## 1. Z1 의 정확한 정의

> **Z1 은 그 기술영역에서 지원서와 면접에 쓸 근거가 섰다고 말할 수 있는
> 상태다.**

세 조건을 모두 만족할 때만 켜진다.

| 조건 | 값 |
|---|---|
| 확인된 판단 축의 개수 | `G8 ≥ 4` (여덟 축 가운데 넷 이상이 L2 이상) |
| 그 영역의 필수 축 | 둘 모두 L2 이상 |
| 관심 | `I` 가 낮음이 아님 |

## 2. 쓰는 입력

| 입력 | 블록 | 등급 |
|---|---|---|
| `probe[TD].J{3,5,6,8}` | `PROBE-J4` | BASIC 이상 |
| `deep[TD].J{1,2,4,7}` | `DEEP-J8` | **STANDARD 이상** |
| `check[TD].judgements` · `artifacts` · `verified_against` | `DEEP-CHECK` | **STANDARD 이상** |
| `trans.T3` · `T4` · `T6` · `T8` · `T9` · `T10` | `TRANS-10` | PRO |
| `grid.interest[TD]` | `CORE-GRID` | BASIC 이상 |

## 3. 만드는 결과

| 결과 항목 | Z1 이 거기서 하는 일 |
|---|---|
| A 강하게 드러난 기술영역 | Z1 영역 목록 자체가 이 절이다 |
| B 비교가 필요한 영역 | Z1 안에서 `G8` 이 같거나 하나 차이인 둘셋 |
| F 이미 있는 근거 | Z1 영역의 산출물과 검증과 활용 묶음 |
| J 비교할 직무 | Z1 영역에서 별칭표로 공고 직무명을 뽑는다 |
| I 다음 행동 | Z1 이 비면 Z2 를 먼저 보여 준다 |

## 4. BASIC 에 넣으면 사용자가 더 얻는 판단

선별 네 축(S4)만으로 Z1 을 만들면 조건이 이렇게 바뀐다.

> `G4 ≥ 3` 이고 필수 축 둘이 S4 안에 있고 둘 다 L2 이상

이때 사용자가 더 얻는 것은 **`먼저 확인해 보실 영역` 이 `근거가 선 영역`
으로 바뀌는 것 하나뿐이다.** 축의 이름과 채우는 조건은 그대로 유료에
있으므로, 받는 사람은 판정은 받고 근거는 못 받는다.

## 5. 넣지 못하는 구조적 이유 (가장 무거운 발견)

**필수 축이 S4 밖에 있는 영역이 넷이다.** S4 는 J3 · J5 · J6 · J8 이다.

| 영역 | 필수 축 | S4 안에 있는가 |
|---|---|---|
| TD01 · TD02 · TD03 · TD05 · TD07 · TD08 · TD10 · TD12 | 여덟 영역 전부 | **있다** |
| TD04 동역학·진동·NVH | J4 · J6 | J4 가 **없다** |
| TD06 재료·내구·파손 | J4 · J6 | J4 가 **없다** |
| TD09 설비·보전 | J3 · J7 | J7 이 **없다** |
| TD11 시스템·요구사항 | J2 · J5 | J2 가 **없다** |

BASIC 에서 Z1 을 켜면 **열두 영역 가운데 여덟에서만 켜지고 넷에서는
구조적으로 켜지지 않는다.** 그것은 `evidence-rules.json` 이 열여섯 직무
가운데 여덟에만 있어서 `BUILD_EVIDENCE` 가 절반에서 발화하지 못하던 것과
같은 결함이고, 이번 재설계가 없애려던 자리다.

영역에 따라 판정 경로가 갈리면, 진동을 깊게 한 사람이 진동 영역에서
Z1 을 못 받고 설계 영역에서만 받는다. 그 사람은 제품이 자기 전공을
모른다고 읽는다.

## 6. 범위도 좁다

BASIC 은 선별 심화를 **최대 두 영역**에만 연다. 그래서 Z1 이 켜질 수 있는
자리가 열둘 가운데 둘이고, 경험이 없다고 답한 사람은 영 개다. 넣어도
대부분의 무료 응시자에게는 보이지 않는 절이 된다.

## 7. STANDARD 전환 가치를 훼손하는가

**훼손한다.** 두 가지 방향이다.

| 방향 | 무엇이 일어나는가 |
|---|---|
| 판정을 먼저 준다 | STANDARD 의 첫 문장이 `근거가 선 영역` 인데 그것을 무료가 먼저 말한다 |
| 근거 없는 판정을 준다 | 축 이름이 없으니 `왜 그렇게 읽었는가` 를 답할 수 없다 |

지금 분할의 논리는 **개수에서 이름으로**다. 무료가 개수를 주고 유료가
이름과 조건을 준다. Z1 은 개수가 아니고 **판정**이라 그 선을 넘는다.

## 8. 넣기로 한다면 정직한 길

판정을 주려면 그 판정을 받칠 입력을 함께 받아야 한다.

| 길 | 비용 |
|---|---|
| S4 에 J2 · J4 · J7 을 더해 S7 로 넓힌다 | 영역당 응답 +3. 두 영역이면 +6. 무료가 14분에서 18분 |
| 영역별 필수 축만 추가로 묻는다 | 영역당 +1에서 +2. 영역에 따라 묻는 수가 달라져 화면이 들쭉날쭉 |
| 심화를 한 영역으로 줄이고 여덟 축 전부 | 무료가 영역 하나만 보게 되어 선별의 뜻이 사라진다 |

첫째가 가장 깨끗하고, 그 대가가 무료 소요 시간이다. **무료 완료율이 파일럿
에서 높게 나오면 그때 다시 볼 자리다.**

## 9. 제 판단

**BASIC 에서 빼 둔다.** 필수 축 넷이 S4 밖이라 영역에 따라 판정 경로가
갈리는 것이 가장 무거운 이유이고, 전환 가치 훼손은 그다음이다.

다시 볼 조건은 둘이다. V3 파일럿에서 **무료 완료율이 높고** 소요 시간에
여유가 있으면 S7 로 넓혀 재검토한다. 그때도 **영역 열둘 전부에서 켜지는
상태**가 아니면 넣지 않는다.
