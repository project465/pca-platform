받은 규격 `CAREERMATRI_PHASE2_1_KR_GLOBAL_COMMERCIAL_READINESS` 의 열여덟
항목. **무엇이 되고 무엇이 막혀 있는지**를 한 장에 적는다.

## 0. 한 줄

한국어와 영어 **양쪽에서** 검사 → 경험 → 결과지 → PDF 가 실제로 돈다.
막혀 있는 것은 넷이고 전부 **우리 밖에서 정해져야 하는 것**이다.

```bash
npm run commercial:check   # 끝낸 것 69가지 · 막힌 것 4가지
```

## 2. 작업 중 드러난 **진짜 탈** 다섯

규격이 시킨 것을 하다 보니 나온 것들이다. 전부 고쳤다.

### ① 사전을 엔진보다 뒤에 올리고 있었다

엔진 파일은 올라오는 순간 `PCAI18N.T` 를 붙들어 둔다. 사전이 뒤에 오면
**그 파일이 그리는 자리만** 한국어로 나간다. 화면으로는 "거기만 한국어"
라서 눈에 잘 띄지 않았다. 학위 단계가 영어판에서 `학부 ·` 로 나왔다.

이제 싣는 순서를 `global:check` 가 세 틀에서 센다.

### ② 영어로 적은 경험이 걸리지 않았다

증거 지도의 검색어 786가지와 준비도 신호 매처 115가지가 전부 한국어였다.
같은 내용을 영어로 적은 응시자는 **적어 주신 언어 때문에 공백을 더
받았다.** 그 공백이 되묻는 말을 더 띄워 영어 결과지가 등급마다 한 장씩
길어졌고, 처음에는 그것이 조판 탈로 보였다.

맞추기 어휘 835가지(영어 낱말 1,030개)를 넣고, 패리티 검사에 **어휘가
한국어로 적어 주신 분의 결과지를 건드리지 않는지**를 넣었다.

### ③ 0원이 두 가지를 말하고 있었다

무료 구간과 '값을 아직 못 정했다' 가 표에서 똑같이 생겼고, '0원이면 팔지
않는다' 로 막으면 **법이 요구하는 시용 장치까지 닫혔다.**

### ④ 금액만 보고 통화를 안 보고 있었다

`USD 29` 가 `KRW 29` 주문을 확정시킨다. 한 시장만 열어 두었을 때는
드러나지 않고 글로벌을 여는 순간 열린다.

### ⑤ 경험 입력 칸이 빈 상자로 서 있었다

창과 부모의 악수가 어긋나서, 창이 빨리 뜨는 날 씨앗이 영영 오지 않았다.
**간헐적이라 더 나쁘다.** 브라우저로 한 바퀴 돌아 찍은 화면에서 드러났다.

## 3. 한국어는 한 글자도 바뀌지 않았다

지역화 공사가 한국어를 건드리지 않았다는 것을 **해시로** 지킨다.

```
i18n:parity    결과지 세 등급의 한국어 해시
intake:i18n    응시·경험 화면의 한국어 해시
```

사전의 열쇠가 한국어 원문 자체라, 한국어는 사전을 거쳐도 그대로 나온다.
구조적으로 회귀가 불가능한 쪽을 골랐고, 그 위에 해시를 한 겹 더 뒀다.
그 해시가 실제로 회귀를 두 번 잡았다.

## 4. 쪽수

두 언어 × 두 입력 열두 벌이 전부 같다.

```
BASIC     12장    STANDARD  14장    PRO  17장
```

영어가 더 긴 것은 **조판으로** 맞췄다(`html[lang="en"]`). 글을 깎아서
맞추지 않았다: 영어판에서 문장을 덜어내면 두 언어가 다른 제품이 되고,
어느 쪽이 덜 받았는지는 받은 사람만 안다.

## 5. 막힌 것 넷

| 무엇 | 누가 정하는가 |
|---|---|
| ME_V2 여섯 상품의 가격 | 사업 결정 |
| 영문 약관·개인정보 처리방침 본문 | 법률 검토·번역 |
| 도메인 소유 (규격 철자의 `.com` 에 남이 있다) | 도메인 구매 |
| 사업자 정보 (전자상거래법 제10조) | 사업자 등록 |

운영 결제를 켜면 다섯째가 붙는다: 해외 결제 대행사가 정해지지 않았다는 것.

**'TODO' 로 적지 않았다.** TODO 는 개발이 할 일로 읽히고, 그러면 아무도
결정하지 않는다.

## 6. 아직 아닌 것 — 팔 때 말하지 않을 것

- **인지 면접과 파일럿 200명을 돌리지 않았다.** 영어 문항이 한국어 문항과
  같은 것을 재는지는 확인되지 않았다. "검증된 영어판" 이라고 팔지 않는다
- **규준이 없다.** "상위 몇 %" 를 쓰지 않는다
- **나라별 자료가 없다.** 임금·비자·면허 자료를 지어내지 않는다.
  결과지는 `GLOBAL_REFERENCE_MODE` 로 나가며 그 사실을 적는다
- 튀르키예어·카자흐어는 켜지 않았다

## 7. 검사 한 벌

```bash
npm run intake:i18n      # 응시·경험 화면 두 언어 (+ 한국어 회귀)
npm run i18n:parity      # 결과지 두 언어 판정 대조 (+ 한국어 회귀)
npm run i18n:coverage    # 데이터 파일 덮임 (화면을 그리지 않는다)
npm run v2:pdf           # 쪽수 — 두 언어 × 두 입력
npm run commercial:check # 끝낸 것과 막힌 것
npm run domains:audit    # 도메인 철자
npm run global:check     # 결제 → PDF 영어 한 바퀴 (실제 DB · 실제 브라우저)
node scripts/phase2-shots.mjs   # 두 언어로 끝까지 눌러 보고 쪽마다 찍는다
```
