## 1 · 사업주가 제안한 구조를 검토한다

```
시작 → 학위/전공/현재 상태 → 진로 관심 → 관심 산업 1~2개
→ Core Screening → Core Deep Dive → Industry Deep Dive → Role Deep Dive → Result
```

**이 구조가 지금보다 낫다.** 까닭 셋이다.

1. 산업이 **검사 앞쪽**에 들어와 이후 장면을 바꾼다. 지금은 맨 뒤다.
2. Screening 과 Deep Dive 가 **이름으로 갈려** 응시자가 지금 무엇을 하는
   중인지 안다. 지금은 격자 열두 화면이 진단처럼 보인다.
3. 산업과 직무가 **같은 층**에 선다. 지금은 둘 다 PRO 꼬리다.

**두 자리를 고친다.**

**첫째, Industry 를 한 덩어리로 두지 않고 셋으로 나눈다.**
산업 전문 질문만 뒤에 두면 응시자는 여전히 `검사를 다 풀고 나서 산업을
만난다`. 그래서 **① 맨 앞에서 고르고 ② Screening 과 Deep Dive 사이에서
그 산업이 요구하는 것을 읽고 ③ Deep Dive 안에서 산업 문항을 섞는다.**

**둘째, Role 을 Industry 뒤가 아니라 Deep Dive 와 묶는다.**
직무는 `어느 영역을 깊게 봤는가` 가 정해져야 고를 수 있고, 고르고 나면
그 직무의 판단을 그 영역 안에서 묻는 것이 자연스럽다. 직무를 맨 뒤로
빼면 응시자가 `또 다른 설문` 으로 읽는다.

### 고친 구조

```
0  시작과 동의
```

## 3 · 자동 진행을 어디에 두는가

**둘 때**: 한 화면에 고르기가 하나뿐이고, 고른 뒤에 더 할 일이 없을 때.
보기 넷 화면(선별 심화 · 경험 심화 · 직무 심화 · 산업 심화)이 여기 든다.
이 화면이 전체의 절반이 넘으므로 자동 진행이 주는 이득이 크다.

**두지 않을 때**:
- 격자처럼 한 화면에 여러 줄을 받는 자리. 마지막 줄을 고치러 돌아갈 수
  없게 된다.
- 번역처럼 **한 줄을 적는 칸이 같이 있는 자리.** 고르자마자 넘어가면
  적을 자리가 사라진다.
- 산업·직무 고르기. 고른 뒤에 설명을 한 번 더 읽는 자리다.

**자동으로 넘길 때 지킬 것 셋**
1. 넘어가기 전에 **250ms 쯤 멈춘다.** 고른 것이 눈에 들어와야 한다.
2. **되돌아가기를 막지 않는다.** `이전` 이 늘 서 있고, 돌아가면 고친 값이
   그대로 보인다.
3. **마지막 화면에서는 자동으로 넘기지 않는다.** 끝났다는 것을 사람이
   눌러서 확인한다.

### BASIC · `어디를 더 알아볼 것인가`

| 받는 것 | 검사에서 어떻게 느껴지는가 |
| --- | --- |
| 열두 영역 탐색(관심 · 해 본 정도) | 격자 두 화면 |
| **관심 산업 고르기와 그 산업이 요구하는 것** | 산업 카드와 장면 화면 |
| 해 본 영역 2~4개의 **선별 넷**(J3 · J5 · J6 · J7) | 보기 넷 화면 8~16 |
| 배울 뜻(깊게 볼 영역만) | 2~3 |
| 방향 제시 | 결과지 |

**BASIC 이 말할 수 없는 것**: 근거가 섰다는 판정 · 여덟 축 · 산업 전문
판단 · 직무 연결. 그 사실을 결과지가 적는다.

### STANDARD · `내가 실제로 무엇을 판단해봤는가`

| 더 받는 것 | 검사에서 어떻게 느껴지는가 |
| --- | --- |
| 여덟 축 심화 | 영역마다 축 이름이 달린 화면이 는다 |
| **근거 고르기** | 자기가 한 일을 목록에서 집는다 |

| **직무 고르기와 직무 심화** | 영역에서 직무로 넘어가는 것을 본다 |
| Gap 과 구체 Action | 결과지 |

| 더 받는 것 | 검사에서 어떻게 느껴지는가 |

STANDARD 는 그 산업이 보는 축으로 Gap 이 설명된다 · PRO 는 그 산업의
판단을 직접 묻는다.
