# 수동 검토표 · 기술영역 열둘

`npm run v3:qa` 가 만든다. **직접 고치지 말고 문항 은행을 고친다**
(`sites/pca-platform/content/me-v3-items.json`).

읽는 법은 한 줄에 다섯 칸이다. 문면이 묻는 **행동**, 그 축에서
확인으로 치는 **판단**, 소유로 올라가는 판단, 같은 축에 붙은 **증거**
항목 수, 그 응답이 쓰이는 **결과 절**이다. 마지막 칸이 비면 받고 쓰지
않는 문항이라는 뜻이고, 그런 자리는 묻지 않는 것이 맞다.

| 결과 절 | 이름 |

| E | 직접 해본 기술 판단 |
| F | 이미 있는 근거 |

| I | 다음 행동 |
