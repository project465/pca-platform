# 갈래 예순셋 — 사람이 읽고 짚은 자리를 고친 회차

`PCU HUMAN REVIEW FINAL CORRECTION + 63 SET REVERSE AUDIT` 의 결과다.
이 회차가 한 일은 둘이다. **사람이 읽고 짚은 자리만 고친 것**과, 그 자리와
**같은 종류의 문제를 예순세 세트에서 다시 센 것**이다.

새 기능을 만들지 않았다. scoring · threshold · item · item count · Core
architecture · Domain · Result/Evidence/Gap decision · registry · routing ·
DB schema · `student_open` · `open_to_students` 를 한 줄도 건드리지 않았고,
**측정 동결이 기록을 다시 적지 않은 채로 통과한다.**

```
npm run pcu:spec        확인 567가지 · PASS 567 · 걸림 0
                        §6 Reverse Audit A~E   전부 0 / 63
                        §7 Reality Audit 여덟 줄 전부 63 / 63
npm run pcu:dept        확인 920가지 · PASS 920
npm run pcu:content     자리 117 · COMPLETE 115 · THIN 0 · GENERIC 0
npm run pcu:generic     14짝 · 통과 14 · 걸림 0
npm run pcu:coverage    자리 115 · 종이의 글자까지
```

## A. 동결 세 전공은 한 글자도 바뀌지 않았다

생명공학(`BT_CORE_V1`) · 유아교육(`SPEC_EDU_EARLYCHILD`) ·
법학(`SPEC_LAW_LAW`) 셋은 이번 회차에서 손대지 않았다. 대표 20 재출력에서
그 셋이 `UNCHANGED` 로 서는 것이 그 증거다. **공통 문구 쪽에도 영향이
없다**: 이 회차에 바뀐 공통 자리는 `result/chains.ts` 의 세 줄(드론·로봇 ·
원예·산림 · 커뮤니케이션디자인)뿐이고 그 셋의 Core 를 가리키지 않는다.

## B. §2 재작성급 둘

**문화·콘텐츠 비즈니스**(아트컬처비즈니스 · K컬처비즈니스 두 자리가 쓴다).
Gap 이 전사 목표와 사업계획과 목표·지표 표를 견주게 하고 있었다. 그것은
경영 일반의 자리다. 강조 영역을 `마케팅·시장 → 수요·예약·가격 관리 →
재무·투자 판단` 으로 다시 세워, 견주는 자리가 **이전 회차 관객 반응 ·
채널별 참여 · 비슷한 콘텐츠의 값과 구성 · 콘텐츠별 수익 구조 · 저작권·유통
조건** 으로 바뀐다. 남길 것 다섯도 그 말로 적었다.

**`현지화` 를 공통으로 쓰지 않는다.** K컬처에는 맞고 아트컬처에는 억지인
말이라, 두 자리가 함께 쓰는 문면을 `관객·시장·유통 채널에 맞게 조정` 으로
바꿨다.

**시니어운동처방**(시니어운동처방 · 시니어운동처방·파크골프). 학부생의
글이 의료 권한처럼 읽히던 자리를 넷 고쳤다: `운동 처방표` → `운동 계획표`,
`그만둘 조건` → `중단·휴식 기준`, `질환이나 약을 확인` → `지도 시 고려할
건강정보 확인`, `처방의 무엇을 바꿈` → `운동 계획의 무엇을 조정함`. 학생의
자리는 관찰 · 운동 지도 · 안전 확인 · 프로그램 운영 · 기록 안이다.

**고치지 못한 자리를 적어 둔다.** `운동 처방표` 와 `복귀 판정서` 는 SPORTS
Core 의 `sports-v1-domains.json` 에도 있고, 그 파일은 그 Core 의
`bank-lock.json` 이 지문을 들고 있다. 고치면 **문항 은행 판본을 올려야**
하고 그것은 §11 이 막은 자리다. 그래서 갈래 층만 고치고 Core 사전의 그 두
낱말은 그대로 남는다. 운동재활과 스포츠지도의 Gap 재료에 그 말이 설 수
있다.

## E. §5 반복 표현을 3~5종으로 분산

판정 의미를 바꾸지 않고 토막 108자리를 고쳤다. **억지로 모든 문장을 다르게
만들지 않았다**: 패션의 `한 벌`(옷 한 벌)과 광고사진의 `한 장`(사진 한
장)처럼 그 전공의 말인 자리는 그대로 두었고, 동결 세 전공은 손대지 않았다.

| 표현 | 전 | 후 |
|---|---|---|
| 한 벌 | 53회 / 34세트 | 25회 / 15세트 |
| 한 장 | 45회 / 30세트 | 9회 / 8세트 |
| 그 자리 | 20회 / 12세트 | 11회 / 7세트 |
| 견주 | 30회 / 24세트 | 13회 / 12세트 |
| 무엇을 먼저 | 21회 / 15세트 | 14회 / 9세트 |
| 어떤 기준으로 정했고 | 10회 / 10세트 | 3회 / 3세트 |
| 가르셨습니까 | 8회 / 8세트 | 4회 / 4세트 |

들어간 자리: `한 묶음` · `한 쪽` · 떼기 · `대어 보고` · `맞춰 보고` ·
`올려 보고` · `어느 것부터` · `어느 쪽을 먼저` · `무엇을 근거로` ·
`어떤 근거로` · `무엇을 보고` · `나누셨습니까` · `구분하셨습니까` ·
`현장에서` · `진행 중에` · `수업 중에`.

## F. §6 Reverse Audit — 다섯 갈래를 예순세 세트에서

`npm run pcu:spec` 이 아홉 항목과 함께 센다. **판정을 새로 만들지
않았다**: 이미 보고 있던 자리를 갈래로 묶어 줄로 내놓았을 뿐이다.

```
A Core 문장 잔존         0 / 63
B 다른 전공 문맥 유입      0 / 63
C 학부생 권한 초과        0 / 63
D 특정 세부직무로 좁힘     0 / 63
E Gap 과 Action 불일치    0 / 63
```

**0 이 아무것도 세지 않아서 나온 값이 아니다.** 다섯 자리에 일부러 흠을
넣어 돌려 다섯이 전부 걸리는 것을 보고 되돌렸다: 같은 Core 의 다른 갈래의
할 일을 그대로 베끼면 A 가 2를, 남의 Core 영역 이름(`구조·내구 해석`)을
넣으면 B 가 1을, `처방표` 를 넣으면 C 가 1을, 한 낱말(`믹싱`)이 근거 여섯
줄 가운데 다섯 줄에 들면 D 가 1을, 할 일이 강조 영역의 재료와 한 낱말도
겹치지 않으면 E 가 1을 적는다.

**D 를 영역 이름으로 세지 않는다.** 처음에는 그 Core 의 영역 이름이 글에
몇 가지 나오는지로 셌는데, 그러면 수출 절차처럼 **제 말을 쓰는 갈래**가
걸린다(글로벌비즈니스 · 항공서비스 · 부동산자산관리 셋이 그렇게 걸렸다).
세는 것을 **그 전공 낱말 하나가 근거 여섯 줄 가운데 다섯 줄 이상에
나오는가** 로 바꿨다. 사람이 짚은 두 자리(실용음악이 녹음·믹싱으로,
글로벌IT 가 배포로 좁았던 것)가 바로 그 모양이었다.

**C 가 세지 않는 말을 적어 둔다.** `간호 진단` 과 `투약` 은 간호학의
표준 용어고 `토양 분석과 처방 기록` 은 농학의 말이다. 세면 맞는 용어를
지우라고 요구하게 된다. 심리상담의 `사례 개념화` 는 지우지 않고 **지도받은
맥락**을 글에 적는 쪽으로 고쳤다.

## H. 고치다 드러난 자리 넷

**결과지 동결에 `result/chains.ts` 가 없었다.** 영역마다의 작성 차례를
드는 파일이고 학생이 읽는 글인데, 어느 동결 목록에도 없어서 고쳐도 아무
기록이 흔들리지 않았다. 사람이 짚은 세 줄을 고치면서 그 파일을 결과지 동결
목록에 넣고 `me-v3-result-copy.26` 으로 올렸다. 이 저장소가 같은 자리를
`CAREERMATRI_CORE_UI_FREEZE_1` 에서 적어 둔 그 구멍이다.

**띄운 서버를 틀리면 검사가 거짓말을 한다 — 세 번째.** 앞 회차의 서버가
3100 을 잡고 있는데 `stage-serve.sh` 가 **듣기에 실패하기 전에**
`var/.serving-build` 를 새 빌드로 적어서, `assertFreshServer()` 가
통과하고 **옛 빌드가 응답했다.** 그 상태의 `pcu:generic` 은 결과 쪽 대신
오류 쪽을 받아 열네 짝 전부를 `쪽 겹침 1.00` 으로 적었다. 옛 서버를 끄고
다시 띄우니 열네 짝이 0.80~0.83 으로 통과한다. **고장은 제품이 아니라 검사
환경이었다.**

**눌러 보는 검사에도 `V3_PREVIEW_OPEN` 이 필요하다.** 띄운 서버만 열어
두면 모자란다: 응시를 여는 것은 그 검사 과정이고, 그 과정이 그 값을 들고
있지 않으면 **학교 맥락이 통째로 버려지고 기계공학으로 열린다.** 그때
`없는 산업팩이다: INDUSTRY_KLANGEDU_V1` 로 그 자리에서 멈춘다.

**같은 Core 의 두 학과가 받는 쪽이 전보다 더 갈렸다.** `pcu:generic` 의
쪽 겹침이 0.91~0.93 에서 0.80~0.83 으로 내려갔다. 갈래마다 남길 것과 할
일과 면접 질문이 그 전공의 말로 바뀐 결과다.

## 아직 아닌 것

갈래 예순셋의 근거 예시와 할 일과 지원서·면접 재료가 그 전공에서 실제로
나오는 경험인지는 **그 전공을 아는 분이 읽어야** 한다. 기계가 셀 수 있는
것은 가리키는 영역과 산업과 역할이 그 Core 안에 있는 코드인가와, 위의
다섯 갈래와 여덟 줄까지다. 규준이 없으므로 `검증된 검사` 로 팔지 않는다.
학생 공개 상태를 바꾸지 않았고(열린 Core 0개) 운영 배포본을 밖에서 열지
못해 `PCU CANARY BLOCKED` 가 그대로다.
