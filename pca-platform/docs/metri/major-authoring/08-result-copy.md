# 08. Result Copy — 결과 문구의 재료

결과 문장은 자유문이 아니다. **정해진 칸에서 조립된다.** 전공을 쓰는
사람이 채우는 것은 문장이 아니라 그 재료다.

## 영역마다 세 묶음

### Evidence — 이미 있는 근거

| 무엇 | 어디서 온다 |
|---|---|
| 무엇을 직접 정했는가 | `axes[J].l3` 와 고른 체크리스트 |
| 무엇을 직접 해봤는가 | `axes[J].l2` 와 고른 체크리스트 |
| 무엇이 결과물로 남았는가 | `artifacts[]` 에서 고른 것 |
| 어디에 쓰였는가 | `org_outcomes{}` 와 J8 |

### Gap — 아직 없는 근거

| 무엇 | 어디서 온다 |
|---|---|
| 어떤 근거가 없는가 | 확인되지 않은 축과 `required_axes` |
| 무엇을 더 확인해야 하는가 | `verify_targets[]` |

### Action — 다음 한 걸음

학생이 수업·프로젝트·연구·인턴에서 **실제로 할 수 있는 한 단계**를 적는다.
재료는 `verify_targets` 와 `artifacts` 와 `workflow` 의 걸음이다.

- 한 걸음이다. 화살표로 이은 절차를 본문에 적지 않는다
- 적는 차례가 필요하면 펼침 안으로 내린다
- 이미 해 본 사람에게 더 해 보라고 적지 않는다

## 금지 표현

재지 않은 것을 단정하는 말을 쓰지 않는다.

`종합적으로 분석한 결과` · `적합한 직무` · `최적 산업` · `잠재력` ·
`강점을 바탕으로` · `다양한 가능성` · `AI 추천` · `맞춤형 진로` ·
`검증됐다` · `강점이다` · `가장 잘 맞` · `당신은 ~형 인재`

결과는 판정이 아니라 **근거와 부족과 행동**으로 적는다.

## 세는 명령

```bash
npm run v3:result:copy   # 재지 않은 것을 단정했는가
npm run v3:copy          # 화면 카피 규칙
npm run copy:audit       # 기계로 쓴 냄새
```
