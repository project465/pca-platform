**열둘을 그대로 둔다.** 다만 넷은 손본다. 바꾸지 않는 까닭과 손보는 까닭을
아래에 적는다.

**새 영역을 만들지 않는 까닭.** 후보로 본 것이 셋이다. `유압·공압` 과
`금형·사출`, `의료·바이오 기기`. 앞의 둘은 TD05 와 TD01·TD08 안의
subarea 로 이미 들어 있고, 독립 영역으로 세우면 그 영역을 묻는 문항이
채용 공고에 견주어 너무 좁아진다. 셋째는 **산업**이고 영역이 아니다.
산업을 영역 자리에 세우면 지금 ME_V2 가 축을 섞어 둔 것과 같은 실수가
된다.

학부에게는 **실습실·학과 장비 관리 경험**을 진입로로 적어 준다.

부품 간 치수 맞춤이 같은 판단**이라는 것을 문면과 보기에 적는다. 이것을
안 하면 TD11 은 구조적으로 대학원·경력자 전용 영역이 된다.

### TD12 · 엔지니어링 자동화·데이터 · **성격 재정의**

| 칸 | 내용 |
| --- | --- |
| 무엇을 다루는가 | 반복 계산과 판정을 어떻게 남겨 다시 쓰게 하는가 |
| 대표 업무 | 반복 작업 → 입출력 규격 → 자동화 범위 → 검증 규칙 → 손으로 한 결과 대조 |
| 핵심 판단 | 자동화할 범위 · 입출력 규격 · 틀린 값을 거르는 규칙 |
| 대표 산출물 | 돌아가는 코드 · 대시보드 · 절차서 |
| 대표 검증 | 손계산 대조 · 회귀 검사 |
| 연결 산업 | 스마트팩토리 · 반도체 · 이차전지 |
| 연결 직무 | 해석 자동화 · 설비 데이터 |
| 학부 | 과제 자동화 스크립트 · 측정 데이터 처리 |
| 석사 이상 | 해석 자동화 · 대리모델 · 데이터 파이프라인 |

**성격을 다시 적는다.** 지금 이름만 보면 `코딩 잘하는가` 로 읽히고, 실제로
문면도 그렇게 돼 있다(`스크립트로 만들어 돌려 본`). 이 영역이 기계공학에서
의미를 가지는 자리는 **남이 쓸 수 있게 판단 규칙을 남기는가**다. 문면을
거기에 맞춘다.

## 2 · 겹치는 자리를 어떻게 가르는가

지금 `boundaries` 열 쌍이 있고 쓸 만하다. 다만 응시자가 보는 자리에
없다. **격자에서 영역을 고를 때 겹치는 쌍이 나란히 서면 그 자리에 한 줄로
적어 준다.**

| 헷갈리는 쌍 | 가르는 한 줄 |
| --- | --- |
| TD01 ↔ TD02 | 치수를 바꿀 권한이 있는가, 예측의 타당성을 책임지는가 |
| TD02 ↔ TD04 | 정적·피로 하중인가, 주파수와 전달경로인가 |
| TD02 ↔ TD06 | 구조가 버티는가, 재료가 왜 깨졌는가 |
| TD07 ↔ TD10 | 한 건의 판정인가, 양산 내내 지켜지는가 |
| TD08 ↔ TD09 | 조건으로 품질과 택트를 잡는가, 멈추지 않게 하는가 |
| TD05 ↔ TD01 | 구동과 제어 파라미터인가, 형상과 강성과 공차인가 |
