# K. 실제 구현 순서

열세 단계다. 단계마다 **끝났다고 말할 조건**을 붙인다. 앞 단계가 끝나기
전에 다음으로 가지 않는다. 1단계에서 4단계까지가 데이터 작업이고 코드가
거의 없다.

| 순서 | 무엇 | 끝났다고 말할 조건 | 코드 |
|---|---|---|---|
| 0 | ME_V2 를 잠근다 | `v2:frozen` 이 여덟 벌의 지문을 대조하고, 한 글자 고쳐 보면 실패한다 | 적다 |
| 1 | 영역 사전을 만든다 (`me-v3-domains.json`) | 영역 열둘 × 축 여덟에 `l2` · `l3` · 체크리스트 · 산출물 · 검증 대상이 전부 있고, 필수 축 둘이 적혀 있다 | 없다 |
| 2 | 별칭표와 경계표를 데이터로 옮긴다 | 공고 이름 스물넷이 조합으로 풀리고, 경계 열 쌍의 구분 질문이 전부 문항 후보로 적혀 있다 | 없다 |
| 3 | 증거 지도 199영역을 재배치한다 | 영역마다 축 여덟에 하나 이상 걸리고 고아가 0 | 없다 |
| 4 | 조직별 성과 이름을 채운다 (`org_outcomes`) | 영역 열둘 × 조직 일곱에 성과 이름이 있고, 기관 이름이 0개 | 없다 |
| 5 | 입력 분기와 `attempts` 칸 일곱 | 석사 이상에 `grad_field` 가 없으면 응시가 시작되지 않고, 제약이 DB 에서 막는다 | 있다 |
| 6 | 문항을 쓴다 (블록 열넷) | `53_v3_03_items.md` 8절의 검사 여덟 가지 전부 통과 | 있다 |
| 7 | 채점과 판정을 짠다 | 영역별 `I` · `L` · `axis` · `G4` · `G8` · `Z` 가 나오고, 계열만 바꾸면 결과가 같다 | 있다 |
| 8 | 경험 입력을 체크리스트 중심으로 바꾼다 | 자유입력 없이 축이 확인되고, 서술은 추가 근거로만 쓰인다 | 있다 |
| 9 | 번역 layer 와 계열 모듈 | 연구 입력만으로 영역 둘 이상에 근거가 붙고, 빈 단계는 빈 채로 적힌다. 다른 모듈을 여는 탈출구가 돈다 | 있다 |
| 10 | 결과지 절 열 가지 | 본문에 내부 이름이 0개. 인쇄 규격 통과. 되짚기 부록에 문항 번호가 남는다 | 있다 |
| 11 | 등급 경계와 상품 원고 | 등급마다 판단의 종류가 다르고 검사가 그것을 센다. 상품 쪽에 계열 한계가 적혀 있다 | 있다 |
| 12 | 지역 layer 표 여섯 | 자료 없는 교차가 `자료 없음` 으로 적히고, 지역만 바꾸면 결과 아홉 항목이 같다 | 있다 |
| 13 | 홈페이지 | `claims:check` 가 새 규칙까지 0곳. ME_V3 가 내놓는 것만 적혀 있다 | 있다 |

## 1. 단계마다 늘어나는 검사

새로 만드는 검사와 고치는 검사를 가른다.

| 검사 | 새로 | 무엇을 센다 | 단계 |
|---|---|---|---|
| `v2:frozen` | 새로 | ME_V2 여덟 벌의 지문 | 0 |
| `v3:domains` | 새로 | 영역 사전의 빈 칸과 고아 영역 | 1~4 |
| `v3:items` | 새로 | 덮임 · 역채점 · 겹묶음 · 중복 · 결과 연결 · 학위 장면 · 계열 중립 · 시간 | 6 |
| `v3:neutral` | 새로 | 계열과 지역만 바꿨을 때 결과가 같은가 | 7 · 12 |
| `v3:check` | 새로 | 채점 골든. 같은 응답이면 같은 결과 | 7 |
| `v3:flow` | 새로 | 실제 브라우저로 등급 × 학위 × 계열 조합을 끝까지 | 10 |
| `evidence:check` | 고친다 | 경험을 넣어도 관심 묶음이 그대로인가 | 8 |
| `coverage:check` | 고친다 | 열둘 영역 기준으로 다시 | 3 |
| `i18n:parity` | 고친다 | 새 결과지의 한국어 해시를 다시 굳힌다 | 10 |
| `v2:pdf` → `v3:pdf` | 고친다 | 등급별 쪽수 범위(3·6·9 + 부록) | 10 |
| `tiersDistinct` | 고친다 | 판단의 종류로 센다 | 11 |
| `claims:check` | 고친다 | 새 금지 네 갈래를 더한다 | 13 |
| `pilot:check` | 고친다 | 새 문항 셋과 계열 저장을 센다 | 5 |

## 2. 병행해도 되는 것

| 병행 | 왜 |
|---|---|
| 파일럿 20~30명 (ME_V2 로) | 새 모형의 가정을 재는 자료가 된다. 5단계의 `attempts` 칸만 먼저 올린다 |
| PG 내부 확인과 메일 연결 | 검사 모형과 독립이다 |
| 운영 인프라 확인 | 같다 |
| 통신판매업 신고 | 같다 |

**5단계를 파일럿보다 먼저 올린다.** 칸이 없으면 파일럿 참가자의 학위와
계열이 저장되지 않고, 끝난 뒤에는 되물을 수 없다.

## 3. 멈추는 선

| 신호 | 멈추고 다시 보는 것 |
|---|---|
| 1~3 단계에서 영역 경계가 열 쌍 가운데 셋 이상 애매하다 | 영역 수를 열둘에서 아홉으로 줄인다 |
| 6 단계에서 선별이 15분을 넘는다 | 격자에서 학습 의향 칸을 빼거나 영역을 여섯으로 줄인다 |
| 7 단계에서 묶음이 응답에 거의 반응하지 않는다 | 확인 조건과 필수 축을 다시 본다 |
| 8 단계에서 체크리스트가 길어 응시자가 닫는다 | 영역마다 판단 항목을 다섯으로 줄인다 |
| 9 단계에서 인문·사회·경상 번역이 영역 둘에 못 닿는다 | 그 계열을 1차에서 뺀다 |
| 파일럿 결과 적합도가 3.0 미만 | 측정 모델을 다시 본다. 구현을 더 밀지 않는다 |

## 4. 하지 않는 것

| 하지 않는 것 | 왜 |
|---|---|
| ME_V2 문항을 고쳐 ME_V3 로 쓰기 | 응시한 사람의 결과가 바뀐다(설계 원칙 4) |
| 두 판본의 결과를 합치기 | 축 사이에 1 대 1 사상이 없다 |
| 전공계열로 가중치 주기 | 그 계열이라서 점수가 오른 줄이 생긴다 |
| 영역 수를 늘려 coverage 를 넓게 보이기 | 영역이 늘면 영역마다 문항이 줄어 지금 제품의 결함으로 돌아간다 |
| 공고 자료 없이 요구 강도 채우기 | 근거 없는 강도가 근거처럼 읽힌다 |
| 규준 없이 백분위 적기 | 규준 표본이 없다 |
| 구현 전에 홈페이지에 새 결과를 적기 | 돌지 않는 것을 파는 자리가 된다 |
