# E. 대학원·계열별 경험 번역 구조

## 1. 층을 둘로 가른다

```
공통 번역 layer      열 단계. 계열과 무관하다. 단계 이름도 순서도 같다
      │
      ├── module STEM-ME     이공계. 실험·해석·설계·과제
      ├── module HSS         인문·사회·경상. 조사·분석·기획·보고
      └── module INTERDISC   기타·융합. 두 모듈의 교집합 + 확인 질문
```

계열이 바꾸는 것은 **보기 메뉴와 영역 사상표** 둘뿐이다. 단계와 수준
정의와 금지 규칙은 전 계열이 같다. 층을 가르는 까닭은 계열을 늘릴 때
공통층을 다시 쓰지 않으려는 것이고, 지금 보이는 것보다 뒤에 더 큰
차이가 있다. **모듈마다 번역을 따로 적으면 한쪽만 고치는 날이 오고, 그날
두 제품이 된다**(결과지 사전을 한 벌로 둔 것과 같은 까닭이다).

## 2. 공통 layer 열 단계

| 단계 | 받는 것 | 입력 모양 | 공통 판단 축으로 |
|---|---|---|---|
| T1 연구·과제 문제 | 무엇을 다뤘는가 | 짧은 글 + 영역 태그 | J1 문제 정의 |
| T2 왜 그것이 문제인가 | 문제의 근거 | 보기 + 한 줄 | J2 요구 해석 |
| T3 방법 선택 | 왜 그 방법인가 | 보기(모듈) + 검토한 대안 | J3 직접 판단 |
| T4 변수·가정 | 무엇을 고정하고 무엇을 바꿨는가 | 체크 + 한 줄 | J3 직접 판단 |
| T5 수행 | 무엇을 몇 번 어떻게 | 보기(모듈) + 반복 수 | J4 방법·도구 |
| T6 비교·검증 | 무엇과 견주었는가 | 보기(모듈) | J6 비교·검증 |
| T7 오차·불확실성 | 산포와 한계를 어떻게 다뤘는가 | 보기(모듈) | J6 비교·검증 |
| T8 기술·실무 판단 | 결과를 보고 무엇을 정했는가 | 영역 체크리스트 | J3 직접 판단 |
| T9 산출물 | 무엇이 남았는가 | 보기(모듈) | J5 산출물 |
| T10 조직·산업 활용 | 누가 무엇에 쓸 수 있는가 | 보기 + 한 줄 | J8 조직 활용 |

**단계 하나가 축 하나로 가지 않는다.** T3 와 T4 와 T8 이 모두 J3 로
가고, T6 와 T7 이 모두 J6 로 간다. 그래서 번역을 끝낸 사람은 같은 축에
근거가 여럿 쌓이고, 그 사실이 수준을 L3 로 올리는 조건이 된다
(근거 둘 이상이어야 한 칸을 올리는 지금 규칙을 그대로 쓴다).

### 2-1. 빈 단계를 추정하지 않는다

| 비어 있는 단계 | 결과지에 적는 말 |
|---|---|
| T7 오차·불확실성 | 산포와 한계를 어떻게 다루셨는지 아직 적지 않으셨습니다 |
| T10 조직·산업 활용 | 이 결과를 누가 어디에 쓸 수 있는지 적으시면 지원 재료가 됩니다 |
| T6 비교·검증 | 무엇과 견주셨는지가 비어 있어 이 영역을 확인으로 올리지 않았습니다 |

마지막 줄이 중요하다. **T6 가 비면 산출물이 있어도 확인으로 올리지
않는다.** 영역 사전에서 J6 를 필수 축으로 둔 영역이 여섯이다.

## 5. module INTERDISC 와 천장을 없애는 길

`interdisc` 를 고른 사람에게는 두 모듈의 교집합을 보여 주고 확인 질문
둘을 더한다.

| 확인 질문 | 왜 |
|---|---|
| 연구에서 다룬 대상이 물리 시스템입니까, 사람과 조직입니까, 둘 다입니까 | 보기 메뉴를 어느 쪽으로 넓힐지 정한다 |
| 수치 모델이나 실험 장치를 직접 만드셨습니까 | STEM 메뉴를 열지 정한다 |

그리고 **모든 계열에 같은 탈출구를 둔다.**

> 이 목록에 없는 일을 하셨습니까
> ( ) 네, 다른 종류의 방법을 썼습니다 → 다른 모듈의 보기를 함께 엽니다

계열이 천장이 되면 안 되는 까닭은 실제 경로가 섞이기 때문이다. 경영학
석사가 생산 라인에서 실험 계획으로 조건을 찾은 일이 있고, 기계공학
석사가 사용자 조사로 요구를 정리한 일이 있다. **고른 계열이 할 수 있는
말의 한계가 되면 그 사람의 경험이 사라진다.**

## 6. 계열을 늘릴 때 무엇을 쓰는가

다음 계열(예를 들어 전기전자나 화공)을 더할 때 새로 쓰는 것과 그대로
쓰는 것을 적어 둔다.

| 그대로 쓴다 | 새로 쓴다 |
|---|---|
| 열 단계와 단계 이름 | T3 · T5 · T6 · T7 · T9 의 보기 메뉴 |
| L0~L3 수준 정의 | 방법에서 영역으로 가는 사상표 |
| 빈 단계 문면의 틀 | 그 계열의 영역 사전 |
| 금지 규칙 넷 | 없음 |
| 문장 틀과 조직별 성과 이름의 구조 | `org_outcomes` 의 값 |

**사상표가 계열마다 새로 필요한 까닭**은 같은 방법이 계열마다 다른
영역으로 가기 때문이다. 유한요소 해석은 기계에서 TD02 이고 전기전자에서는
전자기 해석이다. 사상표를 데이터로 두면 계열을 더하는 일이 파일 하나를
더하는 일이 된다.

## 7. 금지 규칙 넷

앞 회차에서 정한 것을 그대로 확정한다.

1. **학위로 단계를 올리지 않는다.** 단계는 응답한 근거 둘 이상으로만
   올린다.
2. **논문 수와 연구비를 역량으로 세지 않는다.** 산출물 종류는 세고 수량은
   세지 않는다.
3. **연구 주제의 새로움을 평가하지 않는다.** 제품이 잴 수 있는 값이 아니다.
4. **빈 단계를 추정으로 채우지 않는다.**

여기에 이번 회차의 다섯째를 더한다.

5. **전공계열로 근거를 더하거나 빼지 않는다.** 계열은 보기 메뉴를
   고르고, 근거는 고른 보기에서만 나온다. 같은 응답에 계열만 바꿔
   돌렸을 때 확인된 축이 바뀌면 실패다.
