# 과목 처방 — 고교학점제

메트리 플러스 결과지의 05 절. 2026-09-12 에 만들었다.

"기계공학이 앞에 있습니다" 로 끝나면 학생이 다음 주에 할 일이 없다.
**2학년 과목 신청서에 무엇을 적을지까지 내려가야** 결과지가 쓰인다.

---

## 1. 무엇을 보고 만들었나

먼저 이미 있는 것을 봤다. 이 시장은 비어 있지 않다.

| 무엇 | 주는 것 |
|---|---|
| **학점나비** (hakjum.school) | 선택과목 181개를 교과별로, 학점·석차등급·선수과목·관련 학과. 학과별 권장과목, 내신 등급 계산기, **학교 개설 여부를 반영한 이수 로드맵** |
| **대구교육청 전공 연계 선택과목 검색** | 대학 전공별 권장과목 검색 |
| **시도 고교학점제 지원센터** (서울·경기·울산·강원 등) | 계열별 권장 선택 과목 안내 |
| **서울대 전공 연계 과목 선택 안내** | 모집단위 유형별 권장 과목. 2028학년도부터 서류평가·교과역량평가에 반영 |

여기서 가져온 기준 — **학점, 석차등급 기재 여부, 선수과목(위계), 학년 배치,
대학 권장, 학교가 안 열었을 때의 길.** 이 여섯이 없으면 목록이지 처방이 아니다.

**우리가 다르게 하는 것 하나.** 위 서비스들은 전부 "이 학과에 가려면 이 과목"
이다. 학생이 학과를 이미 정했다고 전제한다. 메트리 플러스는 채점이
"1군에 기계공학과 신소재공학이 있고 이 검사로는 우열을 못 가린다" 고 말하는
제품이다. 그래 놓고 처방이 기계공학 과목만 내면 앞뒤가 안 맞는다.

그래서 처방을 **세 덩어리로 나눈다.**

```
먼저 듣습니다      1군 어느 쪽으로 가도 필요한 과목
여기서 갈립니다    어느 쪽으로 기우는지에 따라 갈리는 과목
여유가 되면        그쪽으로 정하면 도움이 되는 과목
```

고1이 지금 하나로 좁힐 이유가 없다. 좁히지 않고도 다음 학기에 할 일이 나온다.

## 2. 데이터

`data/metri/hs_subjects_kr.json` 한 파일이 원본이다. 고칠 곳은 여기다.

- **과목 73개** — 2022 개정 교육과정 보통교과 중 이공계 8계열에 실제로 걸리는 것
  (국어 6 · 수학 13 · 영어 10 · 사회 14 · 과학 19 · 기술·가정 7 · 정보 4)
- **계열 × 과목 필요도 123행** — 3 사실상 필수 / 2 권장 / 1 도움. 행마다 **왜**가 붙는다
- **대학 권장** — 서울대 2028 유형②(자연계): 기하 · 미적분Ⅱ,
  그리고 "과학 교과 진로 선택 3과목 이상" 이라는 묶음 규칙

체육·예술·제2외국어·한문·교양은 **담지 않았다.** 확인하지 못한 것을 채워 넣지
않기 위해서다. 이공계 진학 판단에 걸리지도 않는다.

### 확인한 것과 확인 못 한 것

교차 확인한 것 — 수학·과학·정보·기술가정·국어·영어의 구분(일반/진로/융합),
공통과목 기본학점 4(과학탐구실험 1), 2028 대입에서 **사회·과학 융합선택 9과목만
절대평가**(석차등급 미기재), 서울대 유형② 권장.

확인 못 한 것 — 교양 교과군의 구분, 전문교과 전체. 그래서 안 담았다.

**학교마다 여는 과목과 학점이 다르다.** 결과지가 그 말을 직접 한다 —
"최종 확인은 재학 중인 학교의 교육과정 편제표로 하십시오."

## 3. 산식

점수를 만들지 않는다. `scoring.ts` 가 정한 **1군**을 읽을 뿐이다.

```
1군 계열들이 요구하는 과목을 전부 모은다
  → 과목별로 1군 안 최고 필요도를 쓴다
  → 1군이 넓으면(4계열 이상) 소수 계열만 요구하는 과목을 뒤로 뺀다
  → 학년 정원(52학점) 안으로 줄인다. 필요도 3 은 그대로, 2 는 정원까지
  → 남은 과목의 선수과목을 따라 올라가며 빠진 것을 채운다
  → 학년별로 나누고 학점을 센다
  → 대학 권장 규칙을 대조한다
```

**학년 정원 52학점.** 2022 개정에서 3년 총 이수학점은 192(교과 174 + 창체 18)
이고 고1 공통이 60~70을 가져간다. 남는 것을 2·3학년이 나누므로 한 학년에
50학점 안팎, 과목으로는 열두어 개다.

이 상한이 없으면 어떻게 되는지 실제로 봤다. 1군에 8계열이 전부 들어온
학생에게 **3학년 17과목 68학점**짜리 목록이 나갔다. 신청할 수 없는 목록은
처방이 아니다.

**소수 계열만 요구하는 과목을 뒤로 빼는 이유.** 여덟 계열이 1군인 학생에게
여덟 갈래의 필수를 다 담으면 23과목짜리 장바구니가 된다. 절반 미만의 계열만
요구하는 과목은 "지금 들어야 할 것" 이 아니라 "그쪽으로 정하면 필요한 것" 이다.
대신 결과지가 **"계열을 먼저 좁혀야 한다"** 고 말한다.

**선수과목을 따라 올라가는 이유.** 미적분Ⅱ 를 적어 놓고 미적분Ⅰ 을 빠뜨리면
학생은 그 신청서를 낼 수 없다. `metri:prescribe` 가 그것을 검사한다 — 선수과목이
빠진 처방이 나오면 스크립트가 실패한다.

## 4. 실제로 나오는 것

`npm run metri:prescribe`

**1군이 좁은 학생** (기계공학 · 신소재공학)

```
먼저 듣습니다 10과목 — 대수 · 미적분Ⅰ · 미적분Ⅱ · 기하 · 화학 · 물리학 ·
                      영어Ⅰ · 영어 독해와 작문 · 주제 탐구 독서 · 전자기와 양자
여기서 갈립니다 6과목 — 물질과 에너지(신소재) · 역학과 에너지(기계) ·
                      화학 반응의 세계(신소재) · 창의 공학 설계(기계) …
2학년  7과목 28학점    3학년  9과목 36학점    합계 64학점
SNU — 과학 진로선택 3과목 이상: 지금 4과목 ✓ 충족
```

**1군이 넓은 학생** (8계열 전부)

```
먼저 듣습니다 7과목 · 여기서 갈립니다 5과목
2학년  7과목 28학점    3학년  5과목 20학점    합계 48학점
→ 계열을 먼저 좁혀야 한다
SNU — 과학 진로선택 3과목 이상: 지금 2과목 (1과목 더 필요)
```

계열이 다른 학생에게 다른 과목이 나가는지를 스크립트가 판정한다.
