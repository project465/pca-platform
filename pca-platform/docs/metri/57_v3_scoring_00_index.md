# ME_V3 판단 엔진 · 읽는 순서

2026-10-08 에 만들었다. **문항 은행은 1차 동결했고**(`ME_V3_ITEM_BANK_V1`)
이 회차는 그 응답을 판단으로 바꾸는 코드다. 결과지와 홈페이지와 공고
수집과 구독과 월간 리포트와 반복결제는 건드리지 않았다.

## 한 문장

**같은 응답을 넣으면 늘 같은 판단이 나오고, 왜 그 판단인지 문항 번호까지
되짚을 수 있다.**

| 문서 | 무엇 |
|---|---|
| `57_v3_scoring_01_architecture.md` | 층과 파일, 들어가지 않는 것 넷 |
| `57_v3_scoring_02_rules.md` | 축 판정 · 묶음 판정 · 등급 차이 · 응답 품질 |
| `57_v3_scoring_03_reason_codes.md` | 코드 스물한 가지와 번역이 갈리는 자리 |
| `57_v3_scoring_04_tests.md` | 사람 열두 벌 · 변형 검사 · 되짚기 예시 |

```bash
npm run v3:scoring                  # 서른 가지
npm run v3:persona                  # 결과를 읽는 규칙 열다섯 가지
npm run v3:all                      # 판본 잠금부터 채점까지 한 번에
TRACE=P12:TD02 npm run v3:scoring   # 한 영역을 문항까지 되짚는다
GOLDEN=update npm run v3:scoring    # 규칙을 일부러 바꿨을 때만
```

## 바뀌지 않은 것

**ME_V2 는 읽기 전용이다.** 직무군 열여섯과 관심 점수 정렬과 역할 점수를
가져오지 않았고, 엔진 파일에 그 이름이 없는지 검사가 센다. 두 판본의
결과를 합치지 않는다.

**점수를 만들지 않는다.** 관심과 경험과 학습 의향과 확인된 판단과 소유와
근거와 산출물과 검증을 **따로** 내놓는다. 종합 적합도 숫자를 만드는 자리가
없는지도 검사가 센다.
