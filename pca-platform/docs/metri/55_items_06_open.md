# 전공자 검토가 필요한 자리와 다음 구현 단계

## 1. 전공자가 봐 주셔야 하는 자리

문면을 쓴 사람이 기계공학 현업자가 아니다. 자동 검사는 **문면이 규칙을
지키는지**만 세고, 그 문장이 현장에서 실제로 쓰이는 말인지는 세지 못한다.
아래 다섯 묶음이 그 자리다.

### 1-1. 영역 둘이 체크리스트가 얇다

| 영역 | 증거 항목 | 가장 얇은 축 |
|---|---|---|
| TD05 제어·메카트로닉스 | 15 | J2 요구사항 해석 1개 |
| TD09 설비·보전 | 16 | J6 비교·검증 1개 |

나머지 열 영역이 19에서 25개다. 문항은 여덟 축에 다 서 있지만, 응답과
대조할 증거 항목이 적으면 **그 영역의 L2 판정이 응답 한 줄에 기댄다.**
현업자가 두 영역에서 각각 다섯 줄쯤 더 적어 주시면 메워진다.

### 1-2. 용어가 현장 말과 어긋났을 수 있는 문항

| 문항 | 문면 | 확인할 것 |
|---|---|---|
| `TD05_J3` | 부하 계산을 근거로 모터와 감속비를 직접 정해 본 경험이 있다 | 선정 과정을 이렇게 부르는가 |
| `TD09_J3` | 부품 교체 기준이나 예비품 보유 수준을 직접 정해 본 경험이 있다 | 보전 쪽에서 쓰는 말인가 |
| `TD12_J3` | 결과가 맞는지 판정하는 규칙을 직접 정해 넣어 본 경험이 있다 | 자동화 쪽에서 더 흔한 말이 있는가 |
| `TD04_J4` | 모달 해석이나 가속도 측정으로 고유진동수를 구해 본 경험이 있다 | 둘을 한 문항에 두어도 되는가 |

### 1-3. 산업팩의 산업 용어

조선의 선급 규칙, 원전의 안전등급, 반도체의 파티클과 평균 고장 간격,
이차전지의 롤투롤 장력처럼 **그 산업 사람만 아는 말**을 썼다. 산업팩
여덟 벌을 각각 그 산업 경력자 한 명이 읽어 주시는 것이 가장 값싼 검증이다.

### 1-4. 보기 목록이 긴 문항 여섯

`v3:wording` 이 보고로 남긴 자리다. 묻는 행동은 하나이고 뒤의 목록이 답의
후보인데, 응시자가 목록을 조건으로 읽어 "셋 다 해야 하나" 로 받아들일
위험이 있다. 화면에서 목록을 보기로 내릴지 문면에 둘지는 **응시 화면을
만들 때** 정한다.

### 1-5. 아직 쓰지 않은 것

| 자리 | 상태 |
|---|---|
| 산업별 별칭 변형 | 비어 있다. 직무명이 산업마다 다르게 불리는 표가 없다 |
| 지역 요구 강도 | 공고 자료가 없어 비어 있다 |
| 번역 모듈의 보기 메뉴 | 열 단계의 문항은 썼고 계열별 보기 목록은 모듈 파일에 있다 |
| 영어판 | 한 줄도 쓰지 않았다. 한국어가 기준이다 |

## 2. 다음 구현 단계

**문항 검토가 끝나기 전에는 시작하지 않는다.** 아래 순서는 승인 뒤의
순서다.

| 순서 | 할 일 | 왜 이 자리인가 |
|---|---|---|
| 1 | 문면 수정 반영 | 검토에서 나온 것을 은행에 넣고 검사를 다시 돌린다 |
| 2 | V3 채점 코드 | 축 수준 · 확인 개수 · 묶음 판정. `v3:persona` 의 검산과 **같은 값**이 나와야 한다 |
| 3 | 응시 화면 배선 | 격자 한 화면 · 보기 넷 · 학위 장면 · 이어보기 |
| 4 | 결과지 renderer | 결과 절 열 개. 자리마다 입력이 있는 것을 `v3:items` 가 이미 센다 |
| 5 | 팩 층 배선 | 산업 하나 · 역할 하나 · 설명 순서만 바꾼다 |
| 6 | 상품과 등급 | `products` 에 ME_V3 세 등급. ME_V2 는 읽기 전용 |
| 7 | 홈페이지 | V3 가 내놓는 것만 적는다. `claims:check` 에 네 갈래를 더한다 |
| 8 | 본 파일럿 | 일곱 가지를 잰다. 가장 큰 가정은 대학원 경험 번역의 정확도다 |

**2번과 3번 사이에 DB 작업이 하나 있다.** 석사 이상에 전공계열이 없으면
응시가 시작되지 않게 막는 제약이고, `db/schema_v3_arch.sql` 에 적어만
두었다. 화면이 지키게 두지 않는 까닭은 화면이 늘어나고 늘어난 화면 하나가
빠뜨리기 때문이다.

**아직 하지 않는 것.** UI 전면 수술과 홈페이지 전면 개편, 공고 자동수집,
구독과 월간 리포트, 반복결제는 이 순서에 없다. 2번에서 4번까지가 끝나야
V3 로 한 사람을 끝까지 돌릴 수 있고, 그 전에 밖을 건드리면 되돌릴 자리가
늘어난다.
