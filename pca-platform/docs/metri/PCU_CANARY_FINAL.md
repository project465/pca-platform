# PCU PRODUCTION CANARY FINAL

> **지금 판정.** `LOCAL PASS` · `PRODUCTION UNVERIFIED` · `PCU CANARY BLOCKED`
>
> 아홉 걸음을 **실제 운영에서** 사람이 한 번 밟기 전까지 이 세 줄을 바꾸지
> 않는다. Humanization 과 Copy Rewrite 와 Visual Rebuild 는 이 아홉이 전부
> PASS 한 뒤에 `PCU HUMANIZATION PASS` 로 따로 시작한다.

이 문서가 하는 일은 하나다. **사업주가 운영에서 아홉 걸음을 밟고 그 자리에서
PASS 와 FAIL 을 적을 수 있게 하는 것.** 걸음마다 주소와 누를 것과 정상이라면
무엇이 보이는지와 FAIL 로 적을 선을 적어 두었고, 화면으로 가려지지 않는
자리는 운영 컨테이너에서 한 줄로 대어 볼 수 있게 짝을 지어 두었다.

## 3. 곁에서 대어 볼 것 (**사람이 운영 컨테이너에서**)

Railway → 서비스 → ⋯ → Shell. **아래는 전부 읽기만 한다**(마지막 한 줄만 쓴다).

| | 명령 | PASS | FAIL 이면 |
|---|---|---|---|
| 3-1 | `npm run ops:check` | 열두 줄에 `UNKNOWN` 0 · `BLOCKED` 0 | 줄마다 적힌 Railway 자리를 본다 |
| 3-2 | `npm run db:verify` | 핵심 `7 / 7` · ME_V3 `5 / 5` · 내 CareerMatri `5 / 5` | `npm run db:upgrade` 를 한 번 치고 다시 본다 |
| 3-3 | `npm run pcu:diag test001` | 발급 계정과 응시 계정이 같은 줄로 적히고 브라우저가 뜨고 제 주소로 다시 들어간다 | 적힌 걸음(`browser` · `open` · `render`)이 2절 7번의 까닭이다 |
| 3-4 | `npm run pcu:open` | 열린 자리가 `PCU26_BIZ` 한 자리다 | 열린 자리가 더 많으면 아홉 걸음을 밟기 전에 범위가 넓어진 것이다 |
| 3-5 | `npm run pcu:org` | 기관 `PCU` 한 줄과 담당자 하나가 있다 | 없으면 2절 9번이 빈 화면으로 선다. `APPLY=yes` 로 한 번 만든다 |
| 3-6 | `APPLY=yes ROTATE=yes npm run pcu:students rotate test001` | 새 비밀번호가 화면에 한 번 선다 | **이 줄만 쓴다.** 바꾸는 칸은 비밀번호 하나이고 학과와 응시와 결과는 그대로다 |

**컨테이너의 `package.json` 은 저장소 것과 다르다.** `Dockerfile` 이
`deploy/ops/package.json` 을 `/app/package.json` 으로 덮으므로, 저장소에만 있는
이름을 여기 적어 두면 급한 날에 `Missing script` 를 받는다. 지키는 자리는
저장소에서 도는 `runbook:check` 이고, 이 절에 적힌 여섯 줄이 운영 이미지의
`package.json` 에 있는지 매번 대어 본다.

## 4. 적는 법

| 적는 말 | 뜻 |
|---|---|
| `PASS` | 그 걸음을 운영에서 직접 보았고 정상 칸과 같았다 |
| `FAIL` | 그 걸음을 운영에서 직접 보았고 FAIL 칸에 걸렸다 |
| `UNKNOWN` | 아직 밟지 않았거나 밟을 수 없었다 |

아홉이 전부 `PASS` 이고 `P0 = 0` 일 때만 판정 세 줄을 바꾼다. 그때 적는 것은
`PCU CANARY PASS` 이고, 그 뒤에 `PCU HUMANIZATION PASS` 를 따로 시작한다. **그
회차에도 Freeze 는 그대로다**: scoring · item id · item count · result
decision · Evidence decision · Gap decision · registry · `student_open`.

## 5. 이 회차에 고친 것과 고치지 않은 것

고친 것은 앞 절(`PCU_CANARY_P0.md` 의 마지막 절)에 있다. 고치지 않고 적어 둔
자리 둘을 다시 적는다.

- `eligible()` 이 학부 전공을 `"ME"` 로 못 박아서, 경영학 학부를 거친 경영학과
  대학원생이 `NON_ME_GRADUATE` 로 거절된다. 응시 자격 정책을 바꾸는 일이라
  사업주 확인을 받는다
- 학교가 발급한 계정이 쿠키 없이 `/v3/start` 를 직접 치면 개인 응시가 열린다.
  집계와 등급이 함께 바뀌는 결정이라 사업주 확인을 받는다
