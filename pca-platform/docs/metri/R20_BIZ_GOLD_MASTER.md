## ROUND 2 · DELETE / KEEP / MERGE / REBUILD

| 판정 | 자리 | 무엇을 했나 |
|---|---|---|
| **DELETE** | 8 / 4 / 4 센 수 셋(`.rs-stat`) | 걷었다. 상태를 말하는 일은 아래 영역 줄이 맡는다 |
| **DELETE** | 기술영역 카드 셋(`.rs-tile`) | 걷었다 |
| **DELETE** | 적는 차례 가로 strip(`.rs-step`) | 걷었다 |
| **DELETE** | 닫는 자리의 가짜 5단 흐름(`.rs-flow`) | 걷었다 |
| **DELETE** | 비어 있는 `남긴 기록` 절 | 적어 둔 것이 있을 때만 선다 |
| **REBUILD** | 현재 상태와 지금 할 일 | 세 마디 한 이야기로. 가운데에 다리 문장 한 줄이 선다 |
| **REBUILD** | 영역 상태 | 두 묶음의 줄(`.rs-cs`)로. 쓸 수 있는 쪽은 남은 결과물 이름, 채울 쪽은 그 자리에서 적기로 간다 |
| **REBUILD** | 적을 과제 고르기 | 고르는 줄(`.rs-pk`)로. 누르면 그 영역이 경험 추가 1단에 들어간 채로 열린다 |
| **REBUILD** | 영역별 할 일 목록(`.rs-when`) | label / value 를 걷고 영역 이름을 문장 위 작은 한 줄로 |
| **MERGE** | `그 밖에 할 일` | 고르는 줄에 합쳤다. 긴 문장은 `고르고 나면 무엇을 적나요` 안이다 |
| **MERGE** | 긴 설명 넷 | 펼침 두 자리(`고르고 나면 무엇을 적나요` · `… 쪽에서 지금 할 수 있는 한 걸음`)로 |
| **KEEP** | Hero · 캐릭터 그림 · 큰 경험 문장 | 그대로 |
| **KEEP** | 근거 절의 여는 경험과 곁근거 | 그대로 |
| **KEEP** | 닫는 자리의 짙은 면과 단추 하나 | 흐름 strip 만 걷고 나머지는 그대로 |

| BEFORE | AFTER |

고르는 줄 넷은 처음에 네 줄 모두 `그때 직접 정한 것을 적어 두기` 로 섰다.
`actionHeadKo` 가 할 일의 **종류**로 고르는 말이라 네 영역이 같은 종류면
글자까지 같아진다. 적을 것은 그 줄에서 **무엇을 적는가**이고 그것은 축이
들고 있다(`needKo`). 그래서 지금 넷이 전부 다르다.

### Desktop 에서 구조적으로 바뀐 점

- 현재 상태가 `1fr / 19rem` 비대칭 두 단이고 두 단이 서로 늘어나지 않아 빈 면이 사라졌다
- 영역 줄이 두 단(`지금 꺼내 쓸 수 있는 곳` / `한 줄이 비어 있는 곳`)으로 가로를 쓴다
- 첫 화면에 Hero 와 현재 상태와 영역 줄 셋이 함께 서고, 면을 가진 자리는 CTA 하나다
- 고르는 줄이 `이름 | 적을 것 | 적기` 세 칸이라 1440px 가로가 한 줄에 다 쓰인다

### Mobile 390 에서 구조적으로 바뀐 점

- `order: -1` 을 걷어 서사가 바로 섰다: 경험 → 그런데 → 그래서 지금 → 영역 줄
- 첫 창에 서는 것이 둘이다: 내가 어떤 사람인지(Hero)와 무엇이 남아 있는지(칩)
- 영역 줄이 한 단으로 쌓이고 묶음 이름이 그 자리를 가른다
- 접힌 기본 상태가 창의 6.5배이고(전에는 `남긴 기록` 빈 절을 포함해 더 길었다) 펼침은 참고 자료다
