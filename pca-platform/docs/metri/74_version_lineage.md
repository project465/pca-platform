# 74 · 판본 내력

파일럿 참가자의 결과를 나중에 **다시 만들 수 있어야** 한다. 그러려면 어느
판본이 무엇을 바꿨고 그 변화가 응시자의 결과에 닿았는지가 적혀 있어야
한다. 이 문서는 기록이고, **여기서 판본을 바꾸거나 되돌리지 않는다.**

응시 한 줄에 판본이 열둘 적힌다(`v3_snapshots`). 그 가운데 **결과를
바꿀 수 있는 것은 셋**이고, 나머지 아홉은 그때 어떤 화면과 문장으로
받았는지를 되짚는 값이다.

| 판본 | 지금 값 | 결과에 닿는가 |
|---|---|---|
| 문항 은행 | `ME_V3_ITEM_BANK_V2.4` | **닿는다** |
| 채점 | `me-v3-scoring.5` | **닿는다** |
| 결과 모델 | `me-v3-result-model.4` | **닿는다** |
| 결과지 문장 | `me-v3-result-copy.6` | 글자만 |

| 작업공간 문장 | `careermatri-workspace-copy.2` | 닿지 않는다 |

**V2.4 는 보기 수만 늘었고 판정은 그대로다.** `band()` 가 처음부터
다섯 값을 받는 자였다(1~2 낮음 · 3 가운데 · 4~5 높음). 화면이 셋만
내놓고 있어서 가운데 값이 저장될 길이 없었던 것이고, 옛 응답
(`5` · `1` · `잘 모르겠다`)은 같은 값으로 남아 같은 묶음으로 간다. 옛
스냅샷이 글자까지 같은 것을 `npm run v3:scale` 이 센다. 그래서 채점
판본(`me-v3-scoring.5`)을 올리지 않았다. 가린 자리와 되돌아보는 표는
`docs/metri/80_scale_gate.md`.

**V1 과 V2 는 올린 것이 아니라 다른 검사다.** V1 파일은
`sites/pca-platform/content/me-v3-*.json` 에 그대로 있고 `bank-lock.json`
이 지문을 계속 대조한다. 두 판본의 결과를 **합치지 않는다.**

달라질 수 있는 자리가 그 둘이다.

## 3 · 결과 모델: `.1` 에서 `.4` 까지

| 판본 | 커밋 | 무엇이 바뀌었나 |
|---|---|---|
| `me-v3-result-model.1` | `ce89e9b` | 스냅샷을 읽는 차례로 묶는 층. 새 판단을 하지 않는다 |
| `me-v3-result-model.2` | `837aec0` | 일곱 절에서 아홉 절로. 산업과 직무와 지역이 한 이야기로 이어졌다 |
| `me-v3-result-model.3` | `d72f222` | 받아 두고 읽지 않던 일곱 갈래를 결과지에 세웠다 |
| `me-v3-result-model.4` | `0eafe4a` | 할 일 차례를 급한 순에서 **할 수 있는 때**로, 경험 입력 일곱 칸 반영 |

**모델은 판정을 다시 하지 않는다.** `npm run v3:result` 가 묶음과 축
상태와 까닭 코드를 스냅샷과 글자까지 대조한다. 그래서 모델 판본이 올라도
**같은 스냅샷에서는 같은 판정이 나온다**. 달라지는 것은 그 판정을 어떤
차례로 몇 절에 담는가다.

## 4 · 되짚는 자리

- 응시 한 줄이 그때의 판본 열둘을 들고 있다(`v3_snapshots`)
- 굳은 결과는 `v3_snapshots.result_model` 에 통째로 적혀 있어 **엔진이
  바뀌어도 그때 낸 결과지가 달라지지 않는다**
- 문항 은행은 여덟 파일의 지문으로 잠겨 있다(`bank-lock.json`).
  문면을 고치면 `npm run v3:all` 이 걸린다
- 사람 열두 벌의 **지문**(golden)이 `personas.json` 에 있다. 규칙을
  일부러 바꿀 때만 `GOLDEN=update` 로 다시 적는다

## 5 · 파일럿 전에 정할 것

**파일럿 참가자는 한 판본 안에서만 받는다.** 지금 값 셋
(`ME_V3_ITEM_BANK_V2.4` · `me-v3-scoring.5` · `me-v3-result-model.4`)을
Wave 0 가 끝날 때까지 올리지 않는 것이 맞다. 중간에 올리면 앞사람과
뒷사람의 결과를 같은 표에서 읽을 수 없고, 스무 명에서 서른 명이라
나누면 둘 다 분석이 안 된다.

올려야 할 일이 생기면 **그 wave 를 끊고 다음 wave 로 센다.** 올린
판본과 까닭을 이 문서에 한 줄 더 적는다.

**V2.4 는 Wave 0 가 시작되기 전에 올린 것이다.** 초대를 한 통도 보내지
않았고 참가자 응답이 0건이라 끊을 wave 가 없다. 참가자가 들어온 뒤라면
이 변경도 다음 wave 로 밀었다.
