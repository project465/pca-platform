# 전공과 경험을 조직의 성과로 옮기는 엔진

검사가 "기계설계가 앞에 있습니다" 까지만 말하면 읽는 사람은 그래서 무엇을
하라는 것인지 모른다. 이 층이 하는 일은 그 뒤를 잇는 것이다.

```
ME_V2 응답 → 경험 → 쓴 도구 → 전공지식 → 실제 업무 → 기술 판단
          → 산출물 → 성과 기준 → 조직 가치 → 지금 가진 증거
          → 아직 번역되지 않은 경험 → 비어 있는 증거 → 다음에 만들 경험
```

## 1. 점수를 만들지 않는다

여기서 나오는 것은 전부 **사슬과 단계와 근거**다. 관심·경험·결정 소유·업무
방식·학습 의향은 한 값도 건드리지 않는다. 조직 유형을 바꿔도 그 다섯은
그대로고 ValuePath 만 갈린다. `npm run value:check` 8번과
`npm run v2:flow` 가 매번 확인한다.

**도구 개수를 세지 않는다.** 도구 열 개를 적은 사람이 두 개를 적은 사람보다
앞에 오면, 그 줄은 적는 부지런함을 잰 줄이 된다.

## 2. 증거 사다리 여섯 칸

| | 묻는 것 | 무엇이 있어야 켜지는가 |
|---|---|---|
| E0 활동 | 무엇을 했는가 | 경험의 제목이나 한 일 |
| E1 판단 | 무엇을 직접 정했는가 | `직접 고른 것`, 도구의 `무엇을 판단했는가` |
| E2 산출물 | 무엇을 남겼는가 | 결과물, 도구의 `무엇이 남았는가` |
| E3 성과 | 어떤 기준과 견주었는가 | 숫자나 기준이 들어간 결과, 도구의 `무엇과 견주었는가` |
| E4 조직 가치 | 어디에 쓰였는가 | 쓰인 자리, 그래서 달라진 것, 발주처가 있는 과제 |
| E5 반복 가능성 | 다시 쓸 수 있는가 | 같은 방법이 두 경험 이상, 반복해 썼다고 적은 도구 |

**칸을 건너뛰지 않는다.** 아래가 비어 있으면 위 칸은 확정으로 올리지 않고
'일부' 로 둔다. ANSYS 를 썼다는 말만으로 성과까지 가면 그 줄이 거짓이 된다.

**학위로 올리지 않는다.** 석사라서 E2, 박사라서 E3 로 두면 그 줄은 아무것도
재지 않은 줄이 된다. `value-engine.js` 는 학위 값을 아예 읽지 않고,
`value:check` 가 그 파일에 학위를 가리키는 말이 없는지 본다.

**'잘 됐습니다' 는 성과가 아니다.** E3 로 올라가려면 숫자나 기준이 함께
있어야 한다. 소감과 성과를 가르지 않으면 모두가 E3 가 된다.

## 3. 도구는 맥락이지 역량이 아니다

도구마다 네 칸을 더 받는다.

```
도구 → 어디에 썼는가 → 무엇을 판단했는가 → 무엇이 남았는가 → 무엇과 견주었는가
```

```
ANSYS Mechanical
사용 경험     확인
연결된 경험   브래킷 경량화 캡스톤
어디에 썼는가 설계안 응력·변형 비교
무엇을 판단    형상안 선택
무엇이 남았나  해석 결과 · 설계 검토자료
```

**모자라다고 적지 않는다.** "ANSYS 가 없습니다" 가 아니라 "ANSYS 를 쓰셨는데
모델 설정·검증·설계 판단과 이어진 내용이 아직 없습니다" 로 적는다. 셋은
다른 상태다: 그 도구를 안 써 봤다 · 써 보기만 했다 · 그 직무에 걸리는 증거가
있다.

## 4. 아직 성과 언어로 번역되지 않은 경험

겪으셨는데 아직 적지 않으신 칸이 있는 경험을 따로 모은다. **경험 부족이라고
쓰지 않는다.** 비어 있는 칸마다 되묻는 말이 붙고 '경험 보완하기' 로 이어진다.

그리고 **다 채우신 분에게는 이 절이 뜨지 않는다.** 빈 절을 띄우면 없는
문제를 만들어 보이게 된다.

## 5. 조직 유형 일곱

민간기업 · 정부출연연구기관 · 대학/연구실 · 싱크탱크 · 위탁집행형 공공기관 ·
규제/기술지원기관 · 엔지니어링 컨설팅.

같은 열전달 지식이 조직마다 다른 결과로 읽힌다.

| | 결과물 | 성과 기준 |
|---|---|---|
| 민간기업 | 제품 냉각 성능과 그 설계 근거 | 온도 · 신뢰성 · 소비 전력 · 원가 |
| 출연연 | 열·유동 기술 과제 산출물 | 과제 목표 · 기술성 · 이전 가능성 |
| 대학 | 논문과 방법론, 데이터 | 새로움 · 재현성 · 학술적 기여 |
| 규제·기술기관 | 안전·기술 검토 보고서 | 정확성 · 추적성 · 기준 부합 |

**특정 기관의 평가 지표를 지어내지 않는다.** 여기 적힌 것은 유형이 대체로
무엇을 결과로 치는가이고, 어느 기관의 KPI 가 아니다. 기관별 지표는 확인된
자료가 있을 때만 `target_organization` 쪽에 따로 담는다. 지금은 비어 있다.

**조직 유형은 적합도를 바꾸지 않는다.** 고르지 않으셔도 되고, 고르지 않으면
네 유형을 나란히 보여 드린다.

## 6. 참조 자료

고칠 곳은 전부 `sites/pca-platform/content/` 다.

| 파일 | 무엇이 들었나 |
|---|---|
| `me-knowledge.json` | 전공지식 28갈래 · 그 지식이 쓰이는 업무·판단·산출물·성과 |
| `me-tools.json` | 도구 8갈래 54개 · 어느 직무군과 지식에 걸리는가 |
| `me-value-paths.json` | 직무군 16 × 가치 사슬 + 조직별 차이 |
| `org-types.json` | 조직 유형 7 · 임무 · 결과물 · 성과 기준 |

`npm run value:build` 가 이 넷을 `data/value-data.js` 하나로 묶는다. 화면이
fetch 를 쓰지 않아서(정적 배포에서 `file://` 과 추가 요청을 둘 다 피한다)
전역에 담아 둔다. **생성물은 직접 고치지 않는다.**

## 7. 상품마다 깊이가 다르다

| | BASIC | STANDARD | PRO |
|---|---|---|---|
| 전공지식의 실무 전환 | 상위 1개 | 상위 3개 | 상위 5개 |
| 증거 사다리 | 경험 2건 | 4건 | 10건 |
| 번역 안 된 경험 | 2건 | 4건 | 4건 |
| 도구 증거 | 채워진 칸만 | 채워진 칸만 | 빈 칸까지 전부 |
| 같은 전공 다른 조직 | | 있음 | 있음 |
| 비어 있는 증거 표 | | 있음 | 있음 |
| 가치 사슬 묶음 | | | 있음 |
| 반복 가능성 | | | 있음 |
| 자기소개서·면접 | | | 있음 |

**PRO 는 문장이 더 많은 상품이 아니다.** 같은 경험을 더 깊게 번역한다.
절 수로는 10 → 14 → 19 다.

## 8. 지원 준비는 증거로 한 번 더 막는다

'지원 준비 단계' 는 서류와 면접에서 꺼낼 것이 있다는 말이다. 준비도
신호(수강·도구)는 그 일을 해봤을 법하다까지만 말해 준다. 그래서 증거
사다리가 **산출물(E2)** 에 닿지 않으면 지원 준비로 올리지 않고 근거
만들기로 내린다.

**올리는 쪽으로만 막는다.** 다른 판정은 건드리지 않는다. 그리고 **경험을
안 적으신 분은 깎지 않는다**: 사다리가 없는 것과 낮은 것은 다르다. 그때는
지원 준비 대신 직무 비교로 둔다.

규칙은 `assessment/ME_V2/decision-rules.json` 의 `apply_gate` 에 있다.
코드에 if 를 쌓지 않는다.

## 9. 검사

```bash
npm run value:check   # 번역 엔진 25가지 (브라우저 없이)
npm run v2:flow       # 실제 브라우저로 끝까지 (조직 가치 다리까지)
```

규격이 요구한 열 가지 경우가 전부 들어 있다. 재료역학 수강만 → 학문 노출 /
도구 이름만 → E0 / 두 설계안 비교 → E1 / 해석 보고서 → E2 / 실험값과 비교
→ E3 / 실제 설계 변경에 쓰임 → E4 / 같은 방법 반복 → E5 / 조직을 바꿔도
FIT 동일 / 박사 논문 다수 + 제품 경험 없음 → 제품 성과는 올리지 않음 /
포닥 제안서·마일스톤·지도 → 전달 가능성만 켜고 과제 책임자라고 하지 않음.

## 10. 아직 안 한 것

- **특정 기관 분석.** 유형까지만 한다. 기관별 평가 지표는 확인된 자료가
  없으면 넣지 않는다
- **Global Country Layer.** 목표 국가를 아직 묻지 않아 나라별 층이 비어 있다
- **다른 전공.** 참조 자료가 전부 기계공학이다. 지식 28갈래와 직무군 16은
  기계공학에서만 맞는다
- **12개월 전략.** PRO 의 365일 계획은 아직 `plan()` 의 일반 문장이고,
  ValuePath 와 이어지지 않는다
- **채용공고 대조.** 목표 기관의 공고에 적힌 도구와 내 도구를 맞춰 보는
  자리는 공고 데이터가 있어야 한다
