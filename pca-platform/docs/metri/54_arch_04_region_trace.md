# I. Region Layer schema · J. 결과 trace

## 1. Region Layer 가 답하는 질문

> **내가 가려는 기술영역과 역할을 그 지역에서 실제로 수행하는 조직이
> 있는가. 있으면 어떤 유형이고 몇 곳인가. 없으면 가장 가까운 대안은
> 무엇인가.**

여섯 축이다.

```
직무(TD × RF) × 산업 × 지역 × 조직유형(OC) × 정주 의향 × 이동 가능성
```

## 2. 직무 판단과 섞지 않는다

읽는 것과 절대 쓰지 않는 것을 계약으로 적는다.

| 읽는다 | 쓰지 않는다 |
|---|---|
| 결과의 Z1 · Z2 영역 목록 | 영역 묶음을 바꾸는 것 |
| 역할 선호와 조직환경 선호 | 축 수준을 올리거나 내리는 것 |
| 희망 지역과 이동 범위 | 관심과 학습 의향 |
| 산업팩이 고른 산업 | 다음 행동의 내용 |

규칙 넷이다. 지역을 직무 판단에 넣지 않는다 · 지역 때문에 영역을 권하지
않는다 · 자료가 없으면 비운다 · **기업 이름을 추천으로 적지 않는다**
(보유한 신고는 직업정보제공사업 하나다).

검사로 센다. **지역만 바꾸면 결과 아홉 항목이 전부 같아야 한다.**

## 3. 표 여섯

`db/schema_v3_arch.sql` 3절에 적었고 **아직 적용하지 않았다.**

| 표 | 무엇 | 1차 |
|---|---|---|
| `regions` | 지역 코드 · 상위 권역 · 인접 지역 · 출처 | 채운다 |
| `industries` | 산업 코드 · 표준산업분류 · 상위 갈래 | 채운다 |
| `region_industry` | 지역 × 산업의 사업체 수와 종사자 수와 기준 연도 | 채운다 |
| `industry_td_demand` | 산업 × 기술영역의 요구 강도 · **표본 수** · 근거 등급 | **비운다** |
| `org_registry` | 지역 × 조직유형의 기관 수 | 채운다 |
| `region_notes` | 지역마다 사람이 읽는 한 줄과 출처 | 일부 |

**`industry_td_demand` 가 가장 약한 자리다.** 공고를 모아 세는 일은
저작권과 이용약관을 따지고 시작해야 하므로 1차에서는 줄이 없다. 표본 수와
근거 등급 칸을 스키마에 먼저 두는 까닭은, 나중에 채울 때 **근거 없는 강도만
들어오는 것**을 막으려는 것이다.

표마다 `source` 와 `base_year` 가 필수다. 출처 없는 줄을 넣을 자리가 없다.

### 3-1. 가능성 판정 다섯

| 판정 | 조건 |
|---|---|
| 확인 | 그 지역에 해당 산업 사업체가 있고 조직유형도 확인된다 |
| 부분 | 산업은 있고 그 영역의 역할 자료가 약하다 |
| 인접 | 희망 지역에는 없고 이동 가능 범위 안에 있다 |
| 범위 밖 | 이동 가능 범위 밖에만 있다 |
| 자료 없음 | 교차 자료가 없다 |

## 4. J. 결과 trace

결과 아홉 항목은 `53_v3_05_result_trace.md` 에 입력 키까지 적었다. 여기에
이번 구조로 더해지는 입력 셋을 적는다.

| 입력 | 어디서 | 읽는 결과 항목 |
|---|---|---|
| `industry_pack` | 깊게 본 산업 하나 | B · F · G · I · J |
| `role_pack` | 깊게 본 역할 하나 | E · G · I · J |
| `region.home` · `region.range` | 기본정보 | 지역 절(별도) |

### 4-1. 산업과 역할이 결과를 바꾸는 방식

| 결과 항목 | 산업·역할이 바꾸는 것 | 바꾸지 않는 것 |
|---|---|---|
| A 강하게 드러난 영역 | 없음 | 영역 목록과 축 개수 |
| B 비교가 필요한 영역 | 어느 둘을 먼저 견주는지 | 어느 영역이 묶이는지 |
| E 직접 해본 판단 | 그 산업 말로 다시 읽어 주는 문장 | 고른 판단 항목 |
| F 이미 있는 근거 | 그 산업에서 무엇으로 읽히는지 | 근거 묶음 자체 |
| G 부족한 근거 | 비어 있는 축을 설명하는 순서 | 비어 있는 축 목록 |
| I 다음 행동 | 먼저 권하는 축과 산출물 | 30일에 할 수 있는 범위 |
| J 비교할 직무 | 그 산업의 공고 직무명 | 경계와 가르는 질문 |

**A 가 바뀌지 않는 것이 이 표의 요점이다.** 산업을 바꿔도 확인된 축이
바뀌지 않는다.

### 4-2. 되짚기 부록에 적히는 것

| 적는다 | 왜 |
|---|---|
| 문항 번호와 그 응답 | 다시 채점해 볼 수 있어야 한다 |
| 축마다 어느 입력에서 그 수준이 나왔는지 | 자기보고와 체크리스트가 어긋난 자리를 본인이 본다 |
| 돌아간 모듈과 판본 | `module_versions` 그대로 |
| 산업과 역할이 바꾼 자리 | 위 표의 어느 줄이 적용됐는지 |
| 못 하는 것 목록 | 숙련도 · 합격 가능성 · 규준 없음 |
