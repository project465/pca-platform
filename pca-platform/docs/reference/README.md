# 참고 자료 원본

소개 사이트 원고의 근거가 된 문서들이다. 코드가 아니라 **출처**로 둔다.
원고를 고칠 때, 특히 숫자나 정책 이름을 건드릴 때 여기서 확인한다.

| 파일 | 무엇 | 어디에 쓰였나 |
|---|---|---|
| `ACADEMIX-PCA-제안서.pdf` | ACADEMIX 의 PCA 제안서 | `CLAUDE.md` 의 "제안서에서만 확인된 사실" 표. 브랜드 구성, 분석 3축, 15–20페이지 리포트, 개발 근거 표본 수 |
| `교육부-보도자료-앵커-2026-04-02.pdf` | 교육부 보도자료 「지역성장 인재양성체계(앵커) 추진방안」 (2026.4.2) | `CLAUDE.md` 앵커사업 절, 한국판 `/anchor` 페이지의 21,403억·약 4,000억·2,000억·17개 지방정부 |
| `교육부-별첨-앵커-추진방안.pdf` | 위 보도자료의 별첨 추진방안 전문 | 평가 항목(예산 나눠먹기·소통·학생 고려), 성과지표, 5극3특 |

## 쓸 때 지킬 것

- **정책 수치에는 출처를 화면에 함께 적는다.** 지금 원고의 출처 문구는
  "교육부 「지역성장 인재양성체계(앵커) 추진방안」 보도자료 (2026.4.2)" 다
- **지역정주 취업률을 PCA 가 산출한다고 쓰지 않는다.** 졸업 후 취업 통계로
  확정되는 지표다. 자세한 이유는 `CLAUDE.md` 앵커사업 절에 있다
- 제안서와 실제 사이트(academix.co.kr)가 어긋나는 곳은 **실제 사이트를 따른다.**
  어긋나는 항목은 `CLAUDE.md` 의 "확인된 사실" 표에 정리해 뒀다

이 문서들은 대외 공개용이 아니다. 레포가 비공개인지 확인하고 쓸 것.
