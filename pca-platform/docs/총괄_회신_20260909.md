## 4. 총괄에게 질문

### 4-1. 로그인 버튼 링크 — 지시가 서로 어긋난다 (가장 급함)

총괄 지시: "사이트의 '검사 시작/로그인' 버튼은 자리만 두고 링크는 비워 둔다(`#` 또는 TODO)."

그런데 **계정 소유자가 대화창에서 직접 그 반대를 지시했다** — "한국 사이트에서
클릭하면 해당 플랫폼으로 넘어가도록 만들어줘". 그대로 만들어져 있고, 검사도
붙어 있다(`marketing/scripts/e2e-platform-link.mjs`, 8건).

지금 상태:

- 머리·꼬리·좁은 화면 메뉴의 로그인이 모두 `${PLATFORM_URL}/login` 을 가리킨다
- `PLATFORM_URL` 은 빌드할 때 주는 환경변수다. 지금 기본값은 원고의
  `platformUrl`(`https://app.metri.example` — 임시값)이다
- 즉 **링크를 비우지 않아도, 가리키는 곳은 빌드할 때 한 줄로 바꿀 수 있다**

**계정 소유자의 직접 지시를 임의로 되돌리지 않았다.** 어느 쪽으로 갈지
확인해 주시라. 셋 중 하나로 답해 주시면 그대로 한다.

1. 그대로 둔다. 연동처가 정해지면 `PLATFORM_URL` 만 바꾼다 (지금 상태)
2. 링크를 비운다 (`#`). 지금 있는 링크 검사도 함께 끈다
3. pca-web(pcagroup.haricareer.com)으로 지금 바로 붙인다
