## 3. 커밋 `e1d6c36` — 어느 플랫폼으로 이었나

✅확인함 — **어느 쪽도 아니다. 임시값(placeholder)으로 이어 두었다.**

`marketing/src/lib/platform.ts`:

```ts
export function platformUrl(site: SiteContent): string {
  const base = process.env.PLATFORM_URL || site.platformUrl;
  return base.replace(/\/+$/, "");
}
```

원고 세 곳의 `platformUrl` 은 지금 전부 이 값이다.


- `app.metri.example` 은 **존재하지 않는 주소**다 (리브랜딩 전에는 `app.pca.example`)

- 실제 주소는 빌드할 때 `PLATFORM_URL` 환경변수로 정한다. **빌드 시점이어야
  한다** — 소개 사이트 페이지는 정적으로 미리 만들어지므로 실행 시점에 주면
  효과가 없다
