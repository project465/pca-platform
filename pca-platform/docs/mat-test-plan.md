# MAT 운영 확인 순서표 (공개 전 · 미리보기 계정) · v0.1 (2026-11-02)

MAT_PUBLIC · PARTNERS_PUBLIC 을 **끈 채로** 운영에서 확인합니다. 끝나면 테스트 세션이 결과를 올리고,
대표님이 공개 승인 문장을 직접 입력합니다.

## 0. 준비 (운영자 · 대표님 화면)

1. 운영 반영 확인: "MAT 연동 묶음" 배포가 끝났고, 배포 설정 세션이 `npm run db:upgrade` 를 돌렸다.
   `/admin/partners` 가 열리고 잡인더스트리 · 커리어피크 칸에 "상태 꺼짐" 이 보이면 표가 선 것이다.
2. 시험 계정 만들기(대표님): 개인 계정 A(이용권 없음), 학교 학생 B(학교 MAT 좌석 열림), 이용권 없는 계정 C.
3. `/admin/partners` → **MAT 미리보기 계정**에 A 를 넣는다(B 는 좌석이 있어 넣지 않아도 보인다. C 는 넣지 않는다).
   흐름 1 의 `이용권 → MAT 홈` 은 같은 칸의 **`시험 이용권 30일`** 로 넣는다(주문 없음 · 감사 기록 · 매출에 안 잡힘).
   **테스트 세션은 실제 결제를 하지 않는다.**
4. 같은 화면에서 잡인더스트리 · 커리어피크를 각각 `시험` 으로 바꾸고 **시험 키**를 만든다.
   키는 화면에 한 번만 보인다. 채팅 · 메일 본문에 적지 않고, 시험 호출을 할 사람에게 정한 경로로만 전한다.

## 1. 홈페이지(www) → 가입 · 로그인 → 좌석 없음 → 이용권 → MAT 홈 (계정 A)

| 단계 | 할 일 | 통과 기준 |
|---|---|---|
| 1-1 | 로그아웃 상태로 `https://app.careermatri.com/mat/start?from=www` 를 연다 (홈페이지 단추는 공개 전이라 숨어 있으므로 주소로 연다) | 로그인 화면, 주소에 `next=/mat/start` |
| 1-2 | A 로 로그인 | `/mat/pass` 이용권 화면(30일 ₩9,900 · 90일 ₩24,900, 90일 기본) |
| 1-3 | 운영자가 A 에 `시험 이용권 30일` 을 넣은 뒤 `/mat/start` | MAT 홈 `/mat` |
| 1-3a | (대표님만) 본인 결제 수단으로 30일권 1건 결제 → `/admin/orders` 에서 주문 확인 → `/admin/refunds` 에서 전액 환불 → 이용권이 닫혔는지 확인 | 결제 · 환불 · 이용권 닫힘이 각각 1건씩 기록 |
| 1-4 | `/admin` 또는 DB 조회로 유입 경로 | A 의 유입 경로에 `www` 한 줄 |

## 2. 학교 학생 → 좌석 → 결과가 이어진 MAT 홈 (계정 B)

| 단계 | 할 일 | 통과 기준 |
|---|---|---|
| 2-1 | B 로 로그인 → `/mat/start` | 바로 `/mat` (이용권 화면을 거치지 않음) |
| 2-2 | MAT 홈 | 지금 단계 · 한 줄 진단 · 이번 주 할 일이 B 의 검사 결과로 채워짐(다시 묻지 않음) |
| 2-3 | `/mat/pass` | "○○대학교 제공 · 날짜까지" 와 학교 칸 |
| 2-4 | `/mat/jobs` → 공고 하나 `바로 분석` | 맞는 점 · 보완할 점 · 마감 전 할 일, 줄마다 근거 칩 |

## 3. 잡인더스트리 시험 키 → 한 번 쓰는 링크 → 연결 동의 → MAT 홈 → 맞는 공고

`docs/partner/api.md` 의 curl 예시로 시험 키를 써서 부른다(`member_id` 는 시험용 값, `posting_id` 는 모아 둔 잡인더스트리 공고 번호 하나).

| 단계 | 할 일 | 통과 기준 |
|---|---|---|
| 3-1 | API 호출 | `201` 과 `url` · `expires_in: 300` |
| 3-2 | 로그아웃 브라우저로 `url` 열기 | "잡인더스트리 계정과 연결" · 넘겨받은 항목 그대로 · 받지 않는 항목 안내 · 약관 칸 |
| 3-3 | 필수 동의 → `동의하고 시작` | `/mat/jobs?from=…` 맨 위에 "잡인더스트리에서 보던 공고" |
| 3-4 | 같은 `url` 을 다시 열기 | "링크가 끝났습니다" |
| 3-5 | 새 호출로 받은 `url` 을 6분 뒤 열기 | "링크가 끝났습니다" |
| 3-6 | 같은 `member_id` 로 새 호출 → 열기 | "MAT으로 이어 갑니다" · `계속` 한 번 |
| 3-7 | 같은 nonce 로 다시 호출 / 시각을 10분 틀리게 | `409 replay` / `422 stale_timestamp` |
| 3-8 | `/admin/partners` 최근 7일 호출 | 201 · 409 · 422 가 까닭 코드와 함께 |

## 4. 커리어피크 — 3 과 같은 순서

주소의 `jobindustry` 를 `careerpeak` 로, 키는 커리어피크 시험 키. 추가로:

| 단계 | 할 일 | 통과 기준 |
|---|---|---|
| 4-1 | 잡인더스트리 키로 커리어피크 주소 호출 | `401 bad_key` |
| 4-2 | 연결 뒤 | `/mat` (공고 번호를 보내지 않았으므로 홈) |

## 5. 막히는 것 · 학교 담당자 화면

| 단계 | 할 일 | 통과 기준 |
|---|---|---|
| 5-1 | 계정 C 로 `/mat` · `/mat/pass` · `/mat/jobs` | 모두 404 |
| 5-2 | 계정 C 로 `/mat/start` | 앱 홈으로(공개 전) |
| 5-3 | 학교 담당자로 학생 명단 | MAT 연 학생 · 최근 30일 사용 · 상담 수는 **합계만**, 5명 미만 칸은 숨김. 학생 개인 MAT 내용(질문 · 공고 · 초안)은 보이지 않음 |
| 5-4 | 학교 담당자가 학생 한 명 `MAT 닫기` | 그 학생 `/mat` 404, 감사 기록 1건 |
| 5-5 | 학교 **학생** 계정으로 `/login` 로그인 | 학생 홈(`/me`)으로 감. 담당자 화면(`/org`)은 열리지 않음 |
| 5-6 | 학교 **담당자** 계정으로 `/login` 로그인 | 담당자 화면으로 감(학생으로 들어가지 않음). 같은 브라우저에서 학생으로 들어가도 담당자 로그인이 풀리지 않음 |

## 6. 끝나면

- 테스트 세션이 표마다 통과 · 걸림을 올린다.
- 시험이 끝난 제휴는 `/admin/partners` 에서 `꺼짐` 으로 되돌리고 시험 키를 폐기한다.
- 공개는 대표님 문장으로만: 예) "MAT 공개 승인 (MAT_PUBLIC=true, PARTNERS_PUBLIC=true)"
