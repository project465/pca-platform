# 세종 사업장 기업·기관 1차 자료

파일: `src/sejong/content/orgs.preview.json` (`sejong-orgs.0`, **PREVIEW_ONLY**, 조사일 2026-10-20). 앱이 이 파일을 묶어 읽으므로 여기로 옮겼다

## 먼저 알아 둘 한계

- **공식 사이트 원문을 직접 열지 못했다.**
  - 이 컨테이너의 프록시가 거절했다: alio.go.kr, dart.fss.or.kr, sejong.go.kr, sjtp.or.kr, factoryon.go.kr, nrc.re.kr, 기업·기관 누리집.
  - 모든 "확인"은 공식 페이지의 **검색 발췌**에서 나왔다. 대부분 도메인을 지정해 검색했다. 발췌된 페이지의 게시일은 알 수 없다.
- 그래서 줄마다 두 칸을 더 적었다.
  - `access: "SEARCH_EXCERPT"`
  - `display_ready: false`
  - 사람이 원문을 열어 주소·소재지를 다시 확인하기 전에는 **어느 줄도 결과지에 내지 않는다.**
- **채용 여부는 확인하지 않았다.** 35줄 모두 `hiring.status = "UNVERIFIED"` 다. `추천` 은 규칙 문장 한 곳에만 있다.
- 재무·신용 자료와 개인정보는 담지 않았다.

## 다시 확인할 것

- 번지가 디렉터리 자료에만 있는 곳
  - 원익머트리얼즈: 번지 미확인
  - 타이슨푸드코리아
  - 보쉬전장
  
  세종시청 자료는 산업단지 입주 사실만 확인해 준다.
- 콜마비앤에이치: 2026년 콜마 주주 안내에 본사 건물이 "舊 콜마비앤에이치"로 적혀 있다. 법인 상태를 다시 확인해야 한다.
- KDI·STEPI·NYPI: 페이지마다 우편번호·층·전화가 다르다.
- 삼성전기 세종사업장 위치는 **연동면**이다. 흔히 적히는 연서면이 아니다.
- 세종시설관리공단 누리집은 `sjfmc.or.kr` 이다.
- ALIO 대조는 KRIVET(옛 이름), KIPF(ALIO 채용 공고)에서만 됐다. 국토연구원은 시 단위까지만 확인됐다.
- DART 는 직접 읽지 못했다. 삼성전기·포스코퓨처엠은 회사가 자기 누리집에 올린 사업보고서로 확인했다.
  본체 가지 `3c67c09d` 가 OpenDART 공식 대조를 시작했으므로, CR-4 뒤에는 그 도구로 다시 대조한다.

## 다음 확인 방법

공식 사이트에 닿는 환경에서 사람이 다음 순서로 확인한다.
1. ALIO 기관 정보에서 연구기관과 공공기관을 확인한다.
2. OpenDART 기업개황과 사업보고서의 사업장 현황으로 상장·외감 법인을 확인한다.
3. 팩토리온에서 공장 등록 주소로 산업단지 입주 기업을 확인한다.

확인한 줄만 `display_ready: true` 로 바꾸고 `sources[].checked_on` 을 고친다.
