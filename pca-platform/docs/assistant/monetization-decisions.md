# MAT 수익화: 대표 결정 기록 (2026-11-03)

수익화 작업(정기결제 · 무료 범위 · 영어 · Paddle · 수치 · 연구자 플랜 · 잡인더 입구)을 만들 때 이 목록을 기준으로 한다.
**정해지지 않은 값은 만들지 않거나 설정값으로 비워 둔다.** 배포와 운영 DB 변경은 대표 승인 문장 뒤에만 한다.

## 순서

진흥원 분야 → 정기결제 규정 페이지 → 학과별 카드 → 메뉴 · 문구 → 수익화(아래 전부)

## 결제사 · 통화

| 고객 | 결제사 | 통화 |
|---|---|---|
| 국내(한국 카드) | NHN KCP (정기결제 빌링키, PortOne 채널) | 원화 |
| 해외(해외 카드) | Paddle (개발은 sandbox 먼저) | 달러 |

- 국내 유학생이 한국 카드로 내면 KCP · 원화, 해외 카드면 Paddle · 달러
- 국내 고객이 해외 결제창으로 가지 않게 나라를 가른다(가입 국가 · 접속 국가 · 카드 발급국)
- Paddle 가입 · 열쇠 발급은 대표가 직접. 열쇠는 Railway 에만(채팅 · 저장소 금지)

## 가격

국내(그대로):

| 상품 | 30일 | 90일 | 추가 이용권 |
|---|---|---|---|
| 기본 | 9,900원 | 24,900원 | 4,900원(1회 결제) |
| 연구자 | 19,900원 | 미정(설정값 비움, 시안에는 30일의 약 2.5배 예시) | 미정 |

해외 30일(나라 묶음 3단계, 설정값 `나라 → 가격대 → 금액`):

| 가격대 | 기본 | 연구자 | 처음 배정(설정에서 바꿈) |
|---|---|---|---|
| 1군 | $9.99 | $19.99 | 미국 · 일본 · 유럽 · 호주 등 고소득국. **목록에 없는 나라도 1군** |
| 2군 | $6.99 | $13.99 | 중국 · 튀르키예 · 동남아 일부 |
| 3군 | $4.99 | $9.99 | 카자흐스탄 · 필리핀 · 인도 등 |

- 해외 90일 · 추가 이용권은 미정: 같은 비율 예시만 시안에
- 기간권 30일 · 90일은 **자동 갱신 구독**. 추가 이용권은 1회 결제

## 정기결제 운영 규정 (확정, /legal/subscription)

- 결제 화면에서 다음 결제일 · 금액을 먼저 보이고 동의 후 결제
- 자동 결제 **7일 전** 이메일(결제일 · 금액 · 해지 방법)
- 금액 인상 · 내용 변경은 30일 전 알리고 다시 동의. 동의 없으면 자동 결제 안 함
- 해지: [내 정보 › 이용권] 버튼 하나 + 고객지원 이메일. 남은 기간은 끝까지 사용
- 환불: 결제 후 7일 안 + 그 회차 유료 기능 안 씀 → 전액 / 그 밖 → 일할(원 미만 버림), 위약금 없음 / 회사 사유 → 전액.
  확인일부터 3영업일 안에 KCP 취소 요청
- 결제 실패: 바로 알림, **3일 동안 하루 한 번** 재시도, 그래도 안 되면 멈춤, 밀린 금액 청구 안 함

## 무료 범위 (대표가 테스트 방에 맡김, 테스트 방 판단)

- 무료: 검사 · 결과 · PDF 전부 + MAT 맛보기
  - 내 결과에 맞는 공고 목록(회사 · 직무 · 마감, 갯수 표시)
  - 공고 1개 AI 분석 1회(충족 / 부족 요건, 내 경험 근거). 검사 없이도 1회, 검사를 끝내면 1회 더. 계정당, 재가입 악용 막기
  - 이번 주 할 일 1개
- 유료: 공고 분석 나머지 · 지원서 초안 · 면접 연습 · 파일 읽고 반영 · 마감 알림 · 할 일 전체
- 학교 · 기관 이용권이 있는 학생은 그대로 전부
- 개인은 **검사 없이 가입해 MAT 바로 사용**(경험 · 파일 · 공고로 분석). MAT 홈 · 분석 결과에 '검사하고 더 정확하게' 안내.
  **근거 없는 숫자(00% 더 정확) 금지**(표시광고법). 달라지는 것을 구체적으로 적고, 나중에 쓸 숫자(검사 전후 분석 근거 수)는 집계만 남긴다
- 결제 입구: 무료 분석 결과 바로 아래('나머지 N개 공고도 분석') · 결과 화면의 맞는 공고 칸 · PDF 마지막 장 링크 ·
  학교 · 기관 6개월 끝나기 30일 전 개인 구독 안내(기관에는 개인 결제 여부 안 보임)

## 연구자 플랜

- 기본 플랜과 연구자 플랜 둘, 누구나 고름(학위로 나누지 않음)
- 연구자 = 논문 · 긴 PDF 넓게 읽기, 연구 경력 기술서 · 연구계획서 · 영문 CV 초안, 연구직 면접,
  연구소 · 기업 연구소 · 박사급 · 대학원 · 연구실 공고를 따로 모아 논문 · 연구 경력과 맞춰 분석
- 파일 한도는 개수가 아니라 페이지 수. 한도와 AI 비용 최악 값을 기본 플랜처럼 계산해 시안에
- 만들지 않을 것(미정): 연구실 단위 결제

## 해외 · 언어

- 1단계 대상: 한국 취업을 원하는 국내 유학생 · 외국인. 유입은 계약 대학 국제처 · 유학생 지원센터
- 영어 화면: 잡인더 한국 공고를 영어 요약으로, 공고 분석은 영어, 지원서 초안은 한국어 자기소개서 + 영어 대조본,
  면접 연습은 한국어 · 영어 선택
- 언어: 영어 → 일본어. 문구 파일 구조에 ja 자리. 언어는 사용자 선택 + 브라우저 언어 기본값. AI 답은 사용자 언어로
- 검사 문항 번역은 기계 번역 그대로 쓰지 않고 사람 검토본 목록 파일로(영어 · 일본어 같은 방식)
- 영어 공개 전 필수: 영어 개인정보처리방침 · 이용약관 · 정기결제 규정 · 환불정책 · 영어 문의 창구
- 범위 밖: 유럽(GDPR) · 튀르키예(KVKK)

## 잡인더 입구

- 잡인더 공고 페이지의 '이 공고, 내 경험과 맞춰 보기' 버튼 → `/mat/from/jobindustry?posting=공고ID` 같은 주소
- 비회원: 가입(검사 없이) → 그 공고 무료 분석 1회 → 결제 입구. 잡인더 회원: 서버 간 API 열쇠 · 일회용 링크 · 시각 + nonce · IP 허용 목록 자동 로그인
  (지금 코드는 HMAC 없이 열쇠 해시 + TLS. HMAC 이 필요하면 열쇠 저장 방식을 바꿔야 한다: 협의안에 두 방식)
- 잡인더 경로 결제는 유입 표시(20% 배분 정산용), 공고 ID · 유입 경로별 집계
- 잡인더 쪽에 넘길 연동 명세 초안: 버튼 위치 · 주소 형식 · 로그인 연동 · 넘기는 최소 정보 · 정산 데이터
- 협의는 대표가 직접. 만들지 않을 것(미정): 10억 기준(부가세)

## 공고 가져오기 (탐방 묶음 바로 다음, 2026-11-03 대표 "잡인더에서 가져와")

- 잡인더스트리(www.jobindustry.co.kr) · 커리어피크(www.careerpeak.co.kr)는 **우리 회사 사이트**(같은 사업자, 아임웹).
  외부 협의 · 20% 배분은 필요 없을 수 있음(대표 확인 중). **유입 경로 집계는 그대로**(사이트별 전환 측정)
- 잡인더: 모든 게시판 · 모든 쪽(채용공고 /job-normal · 대학원 /488 · 기업 R&D · 공공기관 · 교원 임용 · 연구비 /research-funding 등).
  아임웹 오픈 API 에 게시판 조회가 있으면 그것(열쇠는 대표가 발급해 Railway 에만), 없으면 목록 화면을 전부 읽기
- 카드의 분류 · 분야 · 학위 표시('석사·박사' 등) · 마감일 · 지역을 칸으로 저장. 마감 지난 공고 · 제목 없는 공고 빼기
- 커리어피크 '정출연 채용 캘린더'(매일 아침 7시, 학위 · 직군 · 고용 형태 · 날짜를 원문에서 확인한 공고)도 가져온다
- 연구자 플랜 공고 묶음: 대학원 · 교원 임용 · 기업 R&D · 박사급(정출연 캘린더 포함)
- MAT 입구(아임웹 편집으로 붙임): `/from/jobindustry?board=<게시판>&idx=<공고 idx>` (서버가 상세 주소를 만든다)

## 수치 (운영자 화면, 개인 정보 없이 집계만)

가입 → 검사 완료 → 무료 분석 → 결제 → 갱신 · 해지, 유입 경로(잡인더 · 학교 · 직접)별

## AI 비용 최악 값 (2026-11-03 계산, 코드 값 기준)

한도는 `src/lib/assistant/ai-budget.ts`(PASS_CAPS · REFILL_ADDS · INTERVIEW_TURNS), 연구자 한도는
`src/lib/pricing/config.ts`(RESEARCH_LIMITS: 30일 600쪽 · 파일당 100쪽 · 30일 30건), 단가는 `ai-budget.ts` 의 PRICES
(달러 / 백만 토큰: Opus 5.5 입력 4 · 출력 20 · 캐시 쓰기 5, Sonnet 5.5 입력 2 · 출력 10 · 캐시 쓰기 2.5),
모델은 `claude.ts` 의 DEFAULT_MODEL(공고 · 메모 · 파일 · 자료 · 자유 질문 = Sonnet, 지원서 문장 · 면접 연습 = Opus)이다.

가정(전부 비싼 쪽으로 잡았다)

- 한국어 글은 1자 = 1토큰, PDF 한 쪽 = 입력 3,000토큰(글 + 쪽 그림)
- 시스템 글(문체 규칙 포함) 2,000토큰, 전공 보기 목록 4,000토큰, 질문하기 자료 묶음 8,000토큰
- 부를 때마다 캐시를 새로 쓴다(캐시 읽기 할인 없음). 출력은 늘 `max_tokens` 까지(생각 토큰 포함)
- 입력 상한: 공고 12,000자 · 메모 4,000자 · 파일 10쪽 · 자료 60쪽(연구자 100쪽) · 질문 1,200자
- 환율 1달러 = 1,400원(비교용). 주간 브리핑(`mat.brief`)은 칸이 없어 빼고, 서버 하루 총액 `MAT_AI_DAILY_USD`(기본 20달러)가 따로 묶는다

읽는 법

- **기본 30일 · 90일은 최악 값이 판매가보다 크다.** 가장 큰 몫은 자료 읽기 10건($4.45)과 면접 연습 24턴($2.04)이다.
  모든 부름이 상한까지 차는 일은 드물지만, 원가를 판매가 아래로 묶으려면 자료 읽기 건수(PASS_CAPS.research)나
  자료 쪽 수(RESEARCH_MAX_PAGES 60)를 먼저 줄이는 것이 효과가 크다. **대표 결정 전이라 한도는 바꾸지 않았다**
- 연구자 30일은 판매가와 거의 같다. 쪽 수 한도(600)가 자료 몫을 묶는다
- 해외 2군 · 3군은 같은 한도에서 판매가가 더 낮다. 한도를 가격대별로 나눌지는 미정

## 수익화 구현 메모 (2026-11-03, 브랜치 `claude/monetize`)

- 무료 범위의 정본: `src/lib/mat-access.ts` 의 FREE_SCOPE. 무료 분석은 `mat_free_claims` 가 사람 열쇠(소셜 번호 ·
  정규화 메일 · 제휴 회원 번호의 해시)에 붙인다. 새 메일 주소로 오는 것까지는 막지 못한다(휴대폰 본인확인이 없다).
  `FREE_SCOPE.requireVerified` 를 켜면 메일 확인 · 소셜 가입 계정에만 무료를 연다(지금은 꺼 둠)
- 값의 정본: `src/lib/pricing/config.ts`. 비어 있는 값(null)은 요금 화면이 숨기고 결제가 받지 않는다
- 정기결제는 `SUBSCRIPTIONS_ENABLED=1`(운영 밖) · `SUBSCRIPTIONS_LIVE=1`(운영, 대표 승인 전에는 넣지 않음)일 때만 판다
- 환경변수(이름만. 값은 Railway 에만): `SUBSCRIPTIONS_ENABLED`(운영 밖에서 정기결제 열기) · `SUBSCRIPTIONS_LIVE`(운영 청구 허락,
  대표 승인 전에는 넣지 않음) · `PORTONE_BILLING_STORE_ID` · `PORTONE_BILLING_CHANNEL_KEY` · `PORTONE_BILLING_API_SECRET` ·
  `PORTONE_BILLING_MODE`(`test`) · `PORTONE_BILLING_API_BASE`(시험에서만) · `PADDLE_ENV`(`sandbox`) · `PADDLE_API_KEY` ·
  `PADDLE_WEBHOOK_SECRET` · `PADDLE_CLIENT_TOKEN` · `MAT_FUNNEL_DEMO`(로컬 시험에서 시연 계정도 수치에 셈)
- Paddle 웹훅 주소: `/api/payments/paddle`(서명 검증). 잡인더스트리 공고 입구: `/from/jobindustry?board=<430|439|486|487|488>&idx=<숫자>`
