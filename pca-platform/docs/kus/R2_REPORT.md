## 1. KUS-CR-03 (P0)

`docs/kus/cr/README.md` 에 요청서, patch, 회귀 근거가 있다. 요지:

- 학교 단위 플래그 `allow_unsupported_accounts`(기본 꺼짐). 켠 학교에서만 Core 없는 자리가
  `core_code: ""` · `unsupported: true` 맥락으로 계정을 받는다. **다른 Core 를 고르게 하지 않는다.**
- 응시는 서버 두 자리가 막는다(`/v3/start` 액션 · `openAttempt`). 응시 줄이 생기지 않는다.
- 배재대 117자리 · 전주대 10자리 판정 변화 **0**. KUS 는 바뀐 자리 22개가 전부 Core 없는 자리.
- **KUS 쪽은 이미 준비했다(공통 파일 아님):** 그 학생은 홈 · 검사 안내에서 `검사 이용 불가` 와
  "다른 전공 검사로 대신 재지 않습니다" 를 읽고, 첫 할 일이 탐방 기록이며, 탐방은 직무·영역 코드 없이
  적은 말만 받아 `core_code = NULL` 로 저장된다. patch 가 없는 지금은 이 길이 열리지 않아 화면이 전과 같다.

- 보고서 목록이 `PRO · BIZ_CORE_V1` 을 적었다(학교 진입은 등급을 고르지 않는다) → `경영 검사`. `여덟 장` 이라 적었는데 실제 7~9쪽 → 수를 뺐다.
- 실행 계획 머리 `할 일 전체(결과 모델)` · 빈 시기 문구 `이 때에 낸 할 일이 없습니다` → 학생 말로.
- 이 종류가 돌아오지 않게 `next-shots` 가 **모든 화면에서** Core 코드 · 학과 코드 · 요청서 번호 · 문서 경로 · 상태 영문값을 센다.
  PDF 의 `근거와 한계` 표는 되짚는 자리라 판본 코드를 이름 뒤 괄호로 남긴다.

**캡처를 읽을 때 알아 둘 것:** 손전화 전체 쪽 그림(`*-mobile.next.jpg`)의 중간에 아래 메뉴 띠가 한 번 찍힌다.
`position: fixed` 띠를 Playwright 의 전체 쪽 캡처가 첫 화면 자리에 남기는 것이고, 실제 화면에서는 늘 창 바닥에 붙어 있다.
