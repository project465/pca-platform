# 잡인더스트리 × CareerMatri MAT 연동 키트 · 초안 v0.1 (2026-11-02)

잡인더스트리 개발 담당자가 이 묶음 하나로 붙일 수 있게 정리했습니다. API 자세한 내용은 `api.md`, 단추 모양은 `button.html`.

## 1. 정해진 값

| 항목 | 값 |
|---|---|
| 제휴 이름(주소에 들어감) | `jobindustry` |
| API | `POST https://app.careermatri.com/api/partner/jobindustry/session` |
| 단추 글자(기본) | 공고 화면: `AI 취업비서 MAT로 이 공고 분석` · 마이페이지: `AI 취업비서 MAT 시작` |
| 넘겨받는 항목 | 이름 또는 별명 · 관심 직무 · 관심 지역 · 학력(학교 · 전공 · 졸업연도) · 자격증(이름 · 취득연월) · 경력 요약(기간 · 직무) |
| 받지 않는 항목 | 연락처 · 주소 · 사진 · 생년월일 · 회사 이름 |
| 결제 · 정산 | 결제는 CareerMatri. 잡인더스트리 유입 회원 결제액의 20%(계약서로 확정) |

## 2. 붙일 자리

1. **공고 상세 화면** — `지원하기` 단추 옆(PC), 손전화는 화면 아래 고정 바에 `is-block` 단추. 이 단추는 `posting=` 에 그 공고의 게시판 번호(`idx`)를 붙입니다. CareerMatri 가 이미 모아 둔 공고이면 MAT 이 그 공고와 회원 경험을 바로 비교합니다.
2. **마이페이지** — 첫 카드 영역에 `is-line` 단추 하나(공고 번호 없이).

로그인하지 않은 방문자에게는 단추를 보이지 않거나, 누르면 잡인더스트리 로그인을 먼저 거치게 해 주세요(회원 번호가 있어야 연결됩니다).

## 3. 잡인더스트리 서버에서 할 일 (한 곳)

단추의 `href` 는 **잡인더스트리 서버의 주소**(예: `/mat-start`)입니다. 그 주소에서:

1. 로그인한 회원인지 확인하고, 회원 번호(바뀌지 않는 값)와 **회원이 동의한 항목**을 모읍니다.
2. `api.md` 대로 CareerMatri API 를 부릅니다(키는 서버 환경 변수에만).
3. `201` 이면 응답의 `url` 로 302 리디렉션. 그 밖이면 "잠시 뒤 다시 시도해 주세요" 안내.

PHP 예시는 `api.md` 3절에 있습니다. 단추마다 링크를 미리 만들어 두지 말고 **누른 순간** 부르세요(링크는 5분 · 한 번).

## 4. 시험 순서

1. CareerMatri 운영자가 운영자 화면(`/admin/partners`)에서 잡인더스트리 연동을 `시험` 으로 켜고 **시험 키**를 만듭니다. 키는 화면에 한 번만 보이며, 정한 안전한 경로로만 전합니다(채팅 · 메일 본문 금지).
2. 허용 IP 를 쓰려면 잡인더스트리 서버의 고정 IP 를 알려 주세요.
3. 시험 서버에서 확인할 것
   - 단추 → 동의 화면 → MAT 홈 → (공고 화면에서 눌렀으면) 그 공고가 맨 위
   - 같은 링크를 다시 열면 "링크가 끝났습니다"
   - 5분 지난 링크도 같은 화면
   - 두 번째부터는 동의 없이 `계속` 한 번
4. 확인이 끝나면 운영 키를 받고, CareerMatri 대표 승인 뒤 `운영` 으로 바꿉니다.

시험 상태에서 만든 계정은 MAT 공개 전에도 MAT 화면을 볼 수 있게 저절로 시험 계정이 됩니다.

## 5. 돌아오는 링크

MAT 공고 카드의 `공고 원문 보기` 는 잡인더스트리 공고 화면으로 갑니다. 주소에 `utm_source=careermatri&utm_medium=mat` 이 붙습니다.
