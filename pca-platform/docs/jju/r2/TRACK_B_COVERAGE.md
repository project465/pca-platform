# Track B — 트랙 × 검사 적합성과 AI 커버리지 (문항 번호 기준)

`npx tsx scripts/jju-coverage.ts` 가 만든다. **손으로 고치지 않는다.** 묶는 규칙은 스크립트의 `CAPS` 에 드러나 있다.

세 층을 섞지 않는다: **측정**(판정 문항 `axis_level` 이 직접 묻는다 · 문항 번호를 적는다) · **자기보고만**(격자·체크리스트·경험 기록에만 나온다 · 판정 근거가 아니다) · **교육과정만**(공식 과정이 다루지만 문항이 없다 · 추천으로만 쓴다).
