## 보내기 전에 채워야 하는 것

**아래가 비어 있으면 자료를 내보내지 않는다.** 값을 정하지 못한 채로
숫자를 지어내는 것이 영업에서 가장 비싸게 치르는 실수다.

| 비어 있는 것 | 왜 필요한가 | 누가 정하나 |
|---|---|---|
| 1인당 단가 (선불) · 최소 계약 규모 | 학과는 예산 편성 때문에 이것부터 묻는다 | 대표 |
| 건당 단가 (건당 정산) | 산학협력단·진흥원·고용노동부 위탁은 건당으로 간다 | 대표 |
| 사업자 정보 (상호·대표·주소·등록번호) | 견적서와 계약서에 들어간다 | 대표 |
| 개인정보 보호책임자 | 학교 개인정보 담당이 반드시 확인한다 | 대표 |
| 도메인 | 메일 서명과 링크에 쓴다 | 대표 |
| 위탁처 (호스팅 · 메일) | 처리방침 4절과 계약서 부속에 들어간다 | 정해지는 대로 |
| 응시 소요 시간 | 학과가 수업 시간에 넣을지 판단하는 기준 | 문항 확정 뒤 |

`src/content/privacy.ts` 의 `⟨…⟩` 도 같은 값들이다. 한 군데서 정하면
그쪽도 함께 채운다.

## 검사 구조 숫자는 쓰지 않는다 (2026-09-09 확정)

검사 구조가 개편 중이다. 새 용어는 **계열(큰 묶음) → 분야(=전공) →
영역(분야 안의 직무영역)** 이고, 계열별 분야 목록과 분야별 영역 수는
**아직 회의 중**이다 (총괄 결정 R015).

그래서 자료에 **"직무 영역 10개" 같은 숫자를 적지 않는다.** 예전 원고에
있던 그 열 개는 사실 경영학과 하나의 영역 목록이었다. 전 학과에 파는
자료에 한 학과의 목록을 전체인 것처럼 적으면 첫 미팅에서 걸린다.

**지금 써도 되는 것 (불변 요소)**

| | |
|---|---|
| 업무 성향 | 6축 — 독립 · 협력 · 도전 · 안정 · 속도중시 · 품질중시 |
| 성향 문항 | 120개 |
| 결과지 | 8장 52절 |
| 다국어 | 한 검사, 여러 언어 |

결과지 "8장 52절" 은 확정된 값이지만, 소개 사이트의 결과지 목차 화면은
아직 옛 구성(11탭)이라 숫자를 나란히 쓰면 서로 어긋난다. **8장 목차를
받은 뒤에 함께 고친다.**

## 대상은 전 학과다

"공과계열에 판다" · "첫 대상은 기계공학과" 는 옛 서술이다. 라이브 플랫폼에
들어 있는 것만 해도 열두 학과다 — 경영 · 기계 · 전기전자 · AI · 산업디자인 ·
심리 · 생명바이오 · 스포츠 · 간호 · 보건의료복지 · 식품영양 · 외식조리.

## 지역 기업 연계는 한국 전용이다

결과지 9장(지역 기업 연계)은 한국판 모듈이다(R005). 글로벌·카자흐스탄
자료에서 핵심 차별점으로 내세우지 않는다. 대전 184곳 수치도 **한국 예시**
라고 밝히고 쓴다.

## 정산 방식은 두 가지다

상대가 어느 쪽인지에 따라 첫 제안이 달라진다.

| | 선불 | 건당 |
|---|---|---|
| 이럴 때 | 학과가 자체 예산으로 산다 | 예산을 미리 태우기 어렵다 |
| 상대 | 학과, 취업지원처 | 산학협력단, 지역 일자리·경제진흥원, 고용노동부 위탁사업 |
| 말하는 법 | "N명분을 계약하시면" | "쓰신 만큼만 월 단위로 청구합니다" |
| 무엇을 센다 | 산 응시권 | **제출을 마친 응시 한 건** |

건당에서 강조할 것 — **시작만 하고 만 건은 청구하지 않는다.** 검수에서
가장 먼저 묻는 지점이고, 여기서 신뢰가 갈린다. 사업 예산이 정해져 있으면
건수 상한을 걸어 두면 그 수를 넘겨 응시가 시작되지 않는다.

**결제 수단을 묻거든**: 기관 계약은 세금계산서 후불이다. 카드 결제(PG)는
개인 진단을 열 때 붙이는 것이고 기관 계약에는 쓰지 않는다.

## 쓰지 않을 것

- **지역정주 취업률을 PCA 가 올린다고 쓰지 않는다.** 졸업 후 취업 통계로
  확정되는 지표다. PCA 가 대는 것은 그 앞단의 과정 데이터다
  (`CLAUDE.md` 앵커사업 절)
- **다른 검사와 이름을 대고 비교하지 않는다.** 비교표는 상대가 반박 자료를
  만들어 오게 만드는 가장 빠른 길이다
- **취업률·합격률 같은 성과를 약속하지 않는다.** 아직 근거가 없다
- `docs/reference/` 의 원본 PDF 는 대외 공개용이 아니다. 그대로 보내지 않는다
