# 계약 검토 체크리스트

학교의 계약 담당·개인정보 담당이 확인하는 항목이다. **답할 수 있는 것과
아직 없는 것을 나눠 적었다.** 없는 것을 있다고 말하면 검토 단계에서
드러나고, 그 자리에서 끝난다.

---

## 개인정보

| 물어보는 것 | 지금 답할 수 있는 것 |
|---|---|
| 처리방침이 있는가 | 있다. `/privacy` 에 공개. **다만 법률 검토 전 초안이다** |
| 무엇을 수집하는가 | 이름, 학번, 비밀번호, 검사 응답. 학과가 요구하면 학교 이메일 |
| 동의를 어떻게 받는가 | 등록 화면에서 필수 체크. 미리 체크해 두지 않는다 |
| 동의 기록이 남는가 | 남는다. 누가·무엇에·언제·어느 판에 |
| 개인정보 보호책임자 | ⟨미정 — 대표가 지정해야 한다⟩ |
| 보유 기간 | ⟨미정⟩ |
| 파기 절차 | 계약 종료 뒤 삭제. 본인 요청 시 즉시 |
| 제3자 제공 | 없다. 법이 요구하는 경우만 |
| 국외 이전 | ⟨호스팅을 정해야 답할 수 있다⟩ |
| 위탁처 | ⟨호스팅 · 메일 발송 사업자 미정⟩ |
| 암호화 | 비밀번호는 단방향 해시. 전송은 HTTPS |
| 접근 통제 | 역할별 분리. 학생은 본인 것만, 담당자는 소속 기관만 |
| 접속 기록 | 마지막 로그인 시각을 남긴다. IP·기기는 남기지 않는다 |
| 만 14세 미만 | 대상이 아니다 (대학 재학생) |

**정직하게 말할 것** — 처리방침은 초안이고 법률 검토를 받지 않았다.
학교가 검토를 요구하면 그 전에 변호사 확인을 받아 다시 보낸다.

## 정보보안

| 물어보는 것 | 지금 답할 수 있는 것 |
|---|---|
| 서버 위치 | ⟨호스팅 결정 후⟩ |
| 백업 | ⟨호스팅 결정 후⟩ |
| 사고 대응 절차 | ⟨미정 — 문서로 만들어야 한다⟩ |
| ISMS 인증 | 없다 |
| 취약점 점검 | 받은 적 없다 |
| 학생 결과 열람 통제 | 담당자가 공개하기 전에는 학생도 못 본다 |
| 담당자의 열람 범위 | 소속 기관만. 남의 기관 링크·결과에 접근할 수 없다 (서버에서 막는다) |

> ISMS 나 취약점 점검을 요구하는 학교가 있다. **없다고 말한다.**
> 국립대·대형 사립대의 본부 계약에서는 이것이 진짜 걸림돌이 될 수 있으므로,
> 학과 단위 또는 센터 사업으로 먼저 시작하는 편이 현실적이다.

## 계약

| 물어보는 것 | 준비 상태 |
|---|---|
| 사업자등록증 | ⟨필요⟩ |
| 통장 사본 | ⟨필요⟩ |
| 계약서 양식 | 학교 양식을 따르는 것이 빠르다 |
| 견적서 | 인원·정산 방식이 정해지면 낸다 |
| 세금계산서 | 발행. 카드 결제(PG)는 기관 계약에 쓰지 않는다 |
| 정산 주기 | 선불은 계약 시. 건당은 월 단위 후불 |
| 검수 자료 | 건당은 월별 실적 집계를 그대로 제출할 수 있다 |
| 중소기업 확인서 / 직접생산확인 | ⟨해당 여부 확인 필요⟩ |
| 나라장터 등록 | ⟨미등록 — 공고 참여가 필요하면 먼저 해야 한다⟩ |

## 서비스 수준

| 물어보는 것 | 답 |
|---|---|
| 응시 소요 시간 | ⟨문항 확정 후⟩ |
| 동시 접속 한도 | 부하 시험을 하지 않았다. 학과 단위(수십~수백 명)는 문제없다 |
| 장애 시 연락 | ⟨연락처 미정⟩ |
| 응답 시간 약속(SLA) | 하지 않는다. 지킬 근거가 없다 |
| 결과지 재발급 | 학생이 언제든 다시 볼 수 있다 |
| 응시 중 이탈 | 문항마다 즉시 저장된다. 이어서 볼 수 있다 |

## 접근성 · 기타

| 물어보는 것 | 답 |
|---|---|
| 모바일에서 되는가 | 된다 |
| 웹 접근성 인증 | 없다. 키보드 조작과 화면낭독기는 고려해 만들었으나 인증받지 않았다 |
| 다국어 | 화면 구조는 다국어를 전제로 만들었다. 지금 완성된 것은 한국어다 |
| 외국인 유학생 | 학번 형태 조건을 안 걸면 등록된다. 문항은 한국어다 |

## 이 표를 쓰는 법

학교가 물어보기 전에 이 표를 먼저 보낸다. 없는 것을 미리 밝히면
"검토가 꼼꼼한 회사" 가 되고, 감추다 들키면 "숨긴 회사" 가 된다.
같은 사실인데 순서만 다르다.
