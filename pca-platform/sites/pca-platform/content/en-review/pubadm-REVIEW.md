## How to review

1. Read the Korean and the English in each row.
2. The English must ask about the same behavior as the Korean. Do not make frequency or ownership words stronger or weaker.
   The scoring separates "I decided it myself" (직접 정했다) from "I received it and did it" (받아서 했다).
3. If the row is right, change `[ ]` to `[x]` in the last column.
4. If the row is wrong, write the fix in the English draft JSON, then mark `[x]`.
5. The "check" column lists places where the meaning could shift. Read those rows first.

The four answer options for experience items are the same in every core (already reviewed in `../en/`):

| Korean | English |
|---|---|
| 해 본 적 없다 | Never done it |
| 남이 정한 대로 하거나 남이 한 것을 받아 썼다 | Followed set conditions or reused someone else's result |
| 내가 직접 했다 | Did it myself |
| 내가 정했고, 그 결정대로 다음 일이 진행됐다 | I decided it, and the next work followed that decision |
