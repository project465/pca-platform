# 잡인더스트리에 AI취업지원도우미 붙이기 — 설치 순서

대표님 컴퓨터가 연결되면 이 순서대로 진행한다. **비밀번호는 대표님이 직접 친다.**
화면을 맡은 쪽은 관리자 로그인 칸에 아무것도 적지 않는다.

## 붙이는 것 셋 (위에서부터 하나만 해도 된다)

| 차례 | 무엇 | 어디에 | 손님이 얻는 것 |
|---|---|---|---|
| 1 | 떠 있는 단추 **한 줄** | 사이트 공통 하단(또는 머리) 코드 칸 | 모든 화면 오른쪽 아래 `AI취업지원도우미`. 공고 화면에서 누르면 **그 공고를 MAT 이 바로 읽고 내 경험과 비교한다** |
| 2 | 메뉴 링크 | 상단 메뉴 · 마이페이지 | 글자 링크 하나 |
| 3 | 소개 카드 | 메인 또는 석·박사 공고 목록 위 | `mat-button.html` 카드 |

### 1. 떠 있는 단추 (가장 효과가 크다)

```html
<script src="https://app.careermatri.com/embed/jobindustry.js" defer></script>
```

- 단추 글자를 바꾸려면 `data-label="AI 취업 도우미"`, 왼쪽에 두려면 `data-side="left"` 를 단다
- 끄려면 그 줄을 지우거나 `data-off` 를 단다
- 단추 모양·동작은 CareerMatri 쪽 파일(`public/embed/jobindustry.js`)을 고치면 바로 바뀐다. 다시 붙일 일이 없다

### 2. 메뉴 링크

```
https://app.careermatri.com/from/jobindustry
```

### 3. 소개 카드

`mat-button.html` 내용을 HTML(코드) 블록에 그대로 붙인다.

## 사이트 도구별로 코드 칸을 찾는 곳 (연결한 뒤 실제 화면을 보고 고른다)

| 사이트 도구 | 공통 코드 칸 |
|---|---|
| 아임웹 | 환경 설정 → SEO/고급 → 코드 삽입 → 바디 코드(</body> 앞) |
| 카페24 | 디자인 관리 → 디자인 편집 → 공통 레이아웃(footer) HTML |
| 그누보드·영카트 | 관리자 → 환경설정 → 기본환경설정 → 하단 추가 스크립트 (또는 테마 `tail.php`) |
| 워드프레스 | 외모 → 테마 파일 편집기 `footer.php` 또는 코드 삽입 플러그인 |
| 직접 만든 사이트 | 공통 footer 템플릿 파일 (개발자에게 한 줄 전달) |

## 붙인 뒤 확인 (휴대폰과 PC 둘 다)

1. 잡인더스트리 아무 화면 → 오른쪽 아래 `AI취업지원도우미` 단추가 보인다
2. 단추가 메뉴·채팅 단추·`맨 위로` 단추를 가리지 않는다 (가리면 `data-side="left"`)
3. **공고 하나를 열고** 단추를 누른다 → `잡인더스트리 AI취업지원도우미` 소개 쪽이 열리고 "보시던 공고를 기억해 두었습니다" 가 뜬다
4. 로그인(또는 가입 · 무료 검사) → `보던 공고와 비교하기` → `이 공고와 비교하기` → 공고의 요구 항목과 내 경험이 나란히 뜬다
5. 공고가 아닌 화면에서 누르면 소개 쪽만 열린다(정상)

3·4에서 "공고 화면을 열지 못했습니다" 가 뜨면 잡인더스트리가 바깥 서버의 접속을
막는 것이다. 그때는 잡인더스트리 서버 설정에서 CareerMatri 서버의 접속을
허용하거나, 공고 API 를 열어 주면 된다(키는 Railway Variables 의 `JOBINDUSTRY_API_KEY`).

## 지키는 것

- 단추는 쿠키를 읽지 않고 아무것도 보내지 않는다. 누를 때 그 화면 주소 하나만 넘어간다
- CareerMatri 서버는 **잡인더스트리 주소만** 연다. 다른 주소는 열지 않는다
- 가져온 공고 본문은 저장하지 않는다. 읽어 낸 요구 항목만 그 사람의 MAT 에 남는다
- 잡인더스트리 회원 정보와 CareerMatri 계정은 섞이지 않는다. 로그인은 CareerMatri 한 곳이다
