공유하는 것은 공학 활동 8축(해석·계산 / 설계·구상 / 제작·실험 / 구현·프로그래밍 / 현장·설비 / 개선·효율 / 탐구·이론 / 조율·관리)과 업무 성향 6축(독립↔협력 · 도전↔안정 · 속도중시↔품질중시), 그리고 채점 산식이다. 가중치는 코드가 아니라 테이블에 있다.

이공계만 다룬다. 기계·전기전자·컴퓨터·화공·신소재·산업·건설환경·바이오의공학 여덟이고, 경영·경제·인문·예체능은 다루지 않는다. 좁힌 것이 손해가 아니라, 공학 직무는 나라가 달라도 같은 역량을 요구하기 때문에 그대로 해외로 나갈 수 있는 근거가 된다.

02 실제로 도는 것

아래는 전부 실제 PostgreSQL 로 한 바퀴 돌려 확인한 것이다. 화면만 있고 뒤가 비어 있는 것은 이 표에 넣지 않았다.

흐름확인 명령상태

과목 처방 — 계열마다 다른 과목이 나가는가npm run metri:prescribe통과

학과 — 계약 → 회차 → 명단 → 공개 → 단체 리포트npm run metri:org통과
개인정보 익명화 — 무엇이 지워지고 무엇이 남는가npm run metri:erase통과

04 산식이 사람을 갈라내는가

숨은 성향을 심어 둔 가상 응시자 500명에게 문항을 풀리고, 엔진이 그 성향을 되찾아 내는지 봤다. 불성실 응답자도 일부러 섞었다. 두 검사지를 따로 돌린다.

시뮬레이션이 설계 오류 네 개를 잡아냈고 전부 고쳤다. ① 활동 축마다 몇 개 분야에서 오는지가 달라 특정 직무가 사람과 무관하게 유리해지던 것 ② 신뢰구간이 근거 없는 상수 ±6 이던 것 ③ 고교판에서 축을 한 번 거치자 전기·전자를 좋아하는 학생의 1순위가 컴퓨터공학으로 나오던 것 ④ 성실도 확인 3문항 중 2개를 틀려도 정상으로 통과하던 것. ④는 대학판에도 있던 구멍이라 함께 막혔다.

다만 가상 응시자는 우리가 만든 모형대로 답한 것이다. 현실을 맞히는지는 실제 학생 100명이 말해 준다. 규준(norm)도 첫 학교 도입 이후에 만들어진다.

05 메트리 플러스가 새로 낸 것

“기계공학이 앞에 있습니다” 로 끝나면 학생이 다음 주에 할 일이 없다. 결과지가 두 칸 더 내려간다.

과목에서 출발해 직업을 붙이면 “물리학을 들으면 엔지니어가 될 수 있어요” 라는, 어느 과목에나 붙는 빈말이 된다. 직무에서 출발해 내려오면 따질 거리가 생긴다. 이런 줄기가 계열 8 × 직무 2 × 요구 3 = 48개 들어 있다.

과목 처방 — 2022 개정 교육과정

채점이 “1군에 기계공학과 신소재공학이 있고 우열을 못 가린다” 고 말해 놓고 처방이 한쪽 과목만 내면 앞뒤가 안 맞는다. 그래서 세 덩어리다 — 먼저 듣습니다(1군 전부에 걸리는 과목), 여기서 갈립니다, 여유가 되면. 고1이 지금 하나로 좁힐 이유가 없다.

지키는 것왜
학년 정원 52학점상한이 없으면 계열이 안 갈린 학생에게 3학년 17과목 68학점짜리 목록이 나간다. 신청할 수 없는 목록은 처방이 아니다
선수과목을 따라 올라감미적분Ⅱ 만 적어 놓고 미적분Ⅰ 을 빠뜨리면 학생은 그 신청서를 낼 수 없다
줄마다 “왜” 한 줄이유 없는 목록은 학부모가 먼저 안 믿는다. 문장은 데이터에서 오고 코드가 짓지 않는다
계열 요구와 대학 권장을 안 섞음“기계공학과 수업이 전제한다” 와 “서울대가 밝혔다” 는 근거가 다르다. 대학이 이름을 걸고 밝힌 것만 담는다

07 아직 안 되는 것

파는 쪽이 안 되는 것을 먼저 말해야 상대가 계획을 세울 수 있다. 코드 밖에서 막는 것과 아직 안 만든 것을 갈라 적는다.

밖에서 막는 것

  • 도메인. metri.io 는 주차 페이지, metri.kz·metri.com.tr 은 이미 다른 사람이 쓰고 있고, metri.co.kr 은 미등록, app.metri.io 는 DNS 자체가 없다. 확보되면 코드에서 고칠 것은 네 줄이다
  • PG 가맹점 심사 — PortOne + 카드사. 영업일 3~10일. 해외카드 채널은 별도 심사
  • 통신판매업 신고 — 관할 구청 3~5일. 사업자등록증·구매안전서비스 확인증 필요
  • 사업자 정보 — 상호·대표자·주소·전화·사업자등록번호. 지어내지 않았고, 비어 있으면 푸터에 금색 “확인 필요” 로 찍힌다

아직 안 만든 것

  • 전기전자·컴퓨터 대학판 문항 — 기계공학 한 벌만 있다
  • 화공·신소재·산업·건설환경·바이오의공학의 스킬트리 — 생기면 사슬이 대학판과 한 줄기가 된다
  • 학교가 실제로 여는 과목 — 편제표를 받아야 “이 학교엔 없는 과목” 을 표시할 수 있다
  • 마이스터고·특성화고의 자격·NCS 처방, 중학생의 “어느 고등학교” 처방
  • 메트리 플러스 튀르키예어 문항 — 중·고등학생은 국내부터다
  • 사슬의 현직자 검수 — 지금 장면은 공개된 직무기술서와 공학 교육과정에서 왔다
  • 단체 리포트 PDF 내보내기, 보유기간 만료 자동 파기

이 문서의 숫자는 2026-09-12 기준 저장소와 데이터베이스에서 직접 읽은 값이다. 시뮬레이션 수치는 가상 응시자 500명의 결과이며 실제 학생 표본이 아니다.

메트리 플러스의 예시 결과지와 직무 장면은 해당 분야에서 실제로 일어나는 일을 압축한 것이고, 특정 회사의 사례나 실제 응시자의 결과가 아니다.
