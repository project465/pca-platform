# 아임웹 설정 원고 · 커리어메트리 (한국)

**절 원고는 여기 없습니다.** `sites/careermetri/imweb/` 의 위젯 파일이
원고입니다. 같은 글을 두 곳에 두면 한쪽만 고쳐지고, 사이트에 남는 것은 안
고쳐진 쪽입니다. 그래서 이 문서는 **위젯으로 만들 수 없는 것만** 담습니다 —
아임웹 설정 화면에 사람이 직접 타이핑하는 값들입니다.

| 찾는 것 | 있는 곳 |
|---|---|
| 각 절의 문장 | `sites/careermetri/imweb/01-hero.html` 부터 `16-screens.html` |
| 붙이는 순서와 페이지 배치 | `sites/careermetri/imweb/README.md` |
| 약관 · 개인정보 · 환불 | `sites/careermetri/legal/` |
| 아임웹 화면을 누르는 순서 | `docs/metri/26_imweb_site.md` |

---

## 1. 사이트 정보 (기본 설정 > 사이트 정보 설정하기)

```
사이트 이름
커리어메트리

사이트 설명 (검색 결과와 카톡 공유에 그대로 뜹니다. 80자 안쪽)
대학 공학계열 재학생 직무적합 진단. 전공 안의 직무를 재고 준비 방법까지
개인 리포트로 냅니다.
```

## 2. SEO (환경설정 > SEO)

```
페이지 제목 (홈)
커리어메트리 | 대학 공학계열 직무적합 진단

메타 설명 (홈)
공학계열 재학생 253문항 진단. 직무영역 10개와 업무성향 6개를 재고, 개인
결과 리포트와 의뢰 기관 분석 리포트를 발급합니다. 이공계 14개 학과.
```

페이지마다 제목을 따로 둡니다. 전부 같은 제목이면 검색 결과에서 한 줄로
겹칩니다.

```
진단        측정 항목과 문항 구성 | 커리어메트리
결과 예시    개인 결과 리포트 8개 섹션 | 커리어메트리
제공 학과    제공 학과 이공계 14개 | 커리어메트리
지역 연계    지역 기업·기관 연계 | 커리어메트리
도입 안내    이용 요금과 도입 절차 | 커리어메트리
문의        도입 문의 | 커리어메트리
```

**쓰지 않는 말.** `추천 기업` · `취업 보장` · `상위 몇 %`. 앞의 둘은 직업안정법
때문이고(신고로는 정보 제공까지입니다), 마지막은 규준 표본이 아직 없어서
입니다.

## 3. 메뉴 (디자인 모드 > 메뉴 설정)

```
홈   진단   결과 예시   제공 학과   지역 연계   도입 안내   문의
```

**메뉴는 코드로 만들지 않습니다.** 아임웹 메뉴 설정으로 만들어야 모바일
햄버거와 현재 위치 표시가 알아서 붙습니다.

## 4. 문의 양식 (아임웹 폼 위젯)

`12-contact` 위젯 아래에 폼 위젯을 놓고 칸을 이렇게 만듭니다.

```
기관명 *
담당자 성함 *
연락처 *
이메일 *
검토 중인 학과
예상 인원
문의 내용
```

머리글은 위젯이 이미 갖고 있으니 폼에는 칸만 둡니다. **코드로 만든 양식은
받는 곳이 없어 눌러도 아무 일이 일어나지 않습니다.**

접수 알림을 받으려면 `성장하기 > 메일발송 설정하기` 를 먼저 켜야 합니다.

## 5. 하단 필수정보 (전자상거래법 제10조)

아임웹의 **[하단 필수정보]** 기능으로 넣습니다. 그쪽이 법이 요구하는 항목을
칸으로 갖고 있어서 빠뜨릴 일이 없습니다.

```
상호                (확인 필요)
대표자              (확인 필요)
사업자등록번호       (확인 필요)
통신판매업 신고번호   (확인 필요)
주소                (확인 필요)
전화                (확인 필요)
이메일              (확인 필요)
개인정보 보호책임자   (확인 필요)

직업정보제공사업 신고 J1700020220007호
```

**빈칸을 빈칸으로 두지 않습니다.** 값을 채우기 전에는 "확인 필요" 라고 찍어
둡니다. 빈칸은 눈에 안 띄고, 눈에 안 띄면 그대로 공개됩니다. **결제를 받으려면
이 여덟 칸이 다 채워져 있어야 합니다.**

## 6. 올릴 이미지 셋

`sites/careermetri/img/` 에 있습니다. 아임웹 이미지로 올린 뒤 위젯 코드의
자리표시자를 올라간 주소로 바꿉니다.

| 자리표시자 | 파일 | 쓰는 위젯 |
|---|---|---|
| `IMG_TEST` | `test.png` | `04-measure` · `16-screens` |
| `IMG_REPORT` | `report.png` | `05-result` · `16-screens` |
| `IMG_ORG` | `org.png` | `06-cohort` · `16-screens` |

셋 다 우리 플랫폼에서 실제로 뽑은 기계공학 화면입니다. 제안서의 결과 예시
이미지는 경영학과라서 쓰지 않았습니다.

## 7. 올리기 전 마지막 확인

```
npm run metri:legal    약관 셋에 빈칸과 빠진 조항이 있는지
npm run copy:audit     원고에서 기계로 쓴 냄새를 세기
npm run domains:check  코드가 가리키는 주소에 남이 있는지
```
