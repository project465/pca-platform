# 약관 셋 · 아임웹에 넣는 곳

세 문서가 있어야 결제를 켤 수 있습니다. 아임웹은 칸을 갖고 있지만 **내용은
비어 있고**, 기본 템플릿은 일반 쇼핑몰용이라 우리 상황(검사 결과지, 무료
시용 구간, 응시 응답이라는 민감한 자료)에 맞지 않습니다.

| 문서 | 아임웹에서 넣는 곳 |
|---|---|
| `01-terms.md` 이용약관 | 관리자 > 기본 설정 > **약관 설정하기** > 이용약관 |
| `02-privacy.md` 개인정보처리방침 | 같은 화면 > 개인정보처리방침 |
| `03-refund.md` 청약철회·환불 | 같은 화면 > 취소·환불 규정 (칸이 없으면 이용약관 제12조가 이미 담고 있습니다) |

## 비워 둔 칸

**대괄호로 묶인 곳은 값이 없어서 비워 둔 것입니다.** 지어내면 전자상거래법
제10조 위반이 되고, 틀린 사업자등록번호는 통신판매업 신고 심사에서 바로
걸립니다.

```
[상호]  [대표자]  [사업자등록번호]  [통신판매업 신고번호]
[주소]  [전화]    [이메일]          [개인정보 보호책임자]
[시행일]
```

`grep -n "\[" *.md` 로 남은 칸을 셉니다.

## 근거

법에서 끌어온 문장들입니다. 바꿀 때 근거를 함께 보십시오.

| 조항 | 어디서 |
|---|---|
| 청약철회 제한에 시용 제공이 필요 | 전자상거래법 제17조 제6항 · 시행령 제21조의2 |
| 사업자 정보 표시 | 전자상거래법 제10조 |
| 결제·공급 기록 5년 보존 | 전자상거래법 시행령 제6조 |
| 보유기간 끝나면 지체 없이 파기 | 개인정보보호법 제21조 |
| 만 14세 미만은 법정대리인 동의 | 개인정보보호법 제22조의2 |
| 직업정보 제공의 범위 | 직업안정법 (알선은 별도 등록) |

환불선은 `src/lib/refund.ts` 가 실제로 그렇게 동작하고 `npm run metri:refund`
로 확인합니다. **약관 문장과 코드가 갈리면 둘 다 고쳐야 합니다.** 한쪽만 고치면 남은 쪽이
거짓말이 됩니다.
