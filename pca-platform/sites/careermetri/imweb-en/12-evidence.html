What it rests on

For each role we first wrote down what has to be confirmed before someone can explain that work, and the items were derived from those areas. Scores are computed from published weights, so the same answers always produce the same result and a department can re-score an answer sheet.

What we can show
  • Which item loads on which role, and by how much, is visible in the data
  • The same answers always produce the same scores
  • We will re-score an answer sheet on request
