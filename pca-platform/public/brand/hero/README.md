# Result Hero 의 공식 그림

이 폴더에 **`student-desk.png`**(또는 `student-desk.webp` ·
`student-desk.jpg`)를 두면 결과지 첫 화면의 오른쪽 자리가 그 파일을 세운다.

**그림은 밖에서 받는다.** 이 저장소의 코드가 Hero 그림을 그리지 않고,
파일이 없으면 그 칸을 아예 세우지 않는다(글이 hero 폭을 다 쓴다).
자리를 메우려고 임시로 그린 그림을 두지 않는 것이 일부러다: 한 번 두면
그것이 상용 화면으로 읽히고, 그 상태로 PASS 가 적힌다.

**코드를 고치지 않는다.** 파일을 넣는 것이 곧 교체이고, 지우면 그림 칸이
다시 사라진다. 받은 그림 자체는 자르거나 다시 그리지 않고, 조정하는 것은
크기와 좌우 균형과 간격과 `object-fit` / `object-position` 뿐이다.

- 비율은 그대로 선다(`object-fit: contain`). 찌그러뜨리지 않는다
- 인물과 소품이 잘리지 않게 **여백이 포함된 그림**을 넣는다
- 배경은 투명(PNG·WebP)이 가장 잘 섞인다. 흰 바탕이면 hero 의 옅은 색면
  위에 흰 네모로 떠 보인다
- 가로 1400px 안팎이면 넉넉하다. 2MB 를 넘기지 않는다
